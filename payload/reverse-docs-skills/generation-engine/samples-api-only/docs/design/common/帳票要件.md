## §1 本書の位置づけ

**この節の位置づけ: 仕様**

本書はシステムが備える帳票の一覧と、各帳票が満たすべき出力要件を記す。出力の条件・契機・様式は帳票一覧マニフェストと各帳票基本設計書から観測できる。一方、その帳票を誰が何のために使うかは実装コードから導けないため、§2（観測事実）には観測できた事実だけを書き、実装コードから導けない事項は本節に確定できなかった事項として明記する。

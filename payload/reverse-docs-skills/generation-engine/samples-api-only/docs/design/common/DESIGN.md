本書は複数のレガシー画面から共通して観測されたスタイル・数値の記録です。既存コードに実際に存在する共通のデザイントークン（テーマ変数・共通スタイルシート等）をそのまま転記する。個別画面の `../画面/詳細設計/DESIGN.md` はここからの **差分（画面固有の逸脱）のみ** を持ち、同じ値を重複して書いてはならない。

画面が対象外である根拠（実測値・出典）は判定の記録 `excluded-kinds.json` を正とし、本書は参照だけを持つ。

# 上書きの前に読む決まり

## 概要

取り消しの効かない操作を実行する前に、対象と影響の範囲を確かめる取り決め。

取り消せる操作と取り消せない操作を、同じ手続きで扱わない。取り消せる操作は実行してから結果を見て判断できるが、取り消せない操作は実行前にしか判断の機会がない。

## 規則

| 規則 | 内容 | 根拠 | 検査 |
|---|---|---|---|
| 上書きの前に既存を読む | 既にファイルシステム上に存在するファイルへ Write で書き込む前に、対象ファイルを Read で読んでおく | 読まずに上書きすると、既存の内容を確認しないまま消すことになり、取り消しの効かない情報の消失に実行時点で気づけない | 静的解析: PreToolUse(Write) で書き込み先が既存ファイルのとき、同一セッションの transcript 内に対象 file_path への Read の tool_use が記録されているかを走査する |

## 違反時の手順

書き込みが止められた場合、書き込み先のファイルをまず読む。読んだうえで、上書きしてよいかを判断する。既存の内容を残す必要があれば、書き込む内容へ取り込んでから改めて書き込む。

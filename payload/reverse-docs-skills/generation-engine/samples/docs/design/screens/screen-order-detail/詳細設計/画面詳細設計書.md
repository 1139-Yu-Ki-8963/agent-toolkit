# 注文詳細 画面詳細設計書

## §1 画面概要

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 画面名 | 注文詳細 |
| 目的 | 個別注文の明細・配送先を確認し、ステータスを更新する |
| ルート | /orders/:id |
| 遷移元 | 注文一覧 |
| 遷移先 | 注文一覧（一覧へ戻る操作時） |

### 1.2 業務上の位置づけ

注文一覧から個別注文を選んだ後の確認・処理段階に位置し、ステータス更新によって後続の出荷業務や経理処理を進める役割を持つ。

---

## §2 機能一覧

### 2.1 機能一覧表

| キー | 機能名 | 概要 | 優先度 |
|---|---|---|---|
| 詳細-明細確認 | 注文明細確認 | 注文に含まれる商品・数量・単価を確認する | 必須 |
| 詳細-配送確認 | 配送先情報確認 | 配送先住所・配送方法を確認する | 必須 |
| 詳細-ステータス更新 | 注文ステータス更新 | 注文の進行状況を次の段階へ更新する | 必須 |

### 2.2 機能間の関係

ステータス更新は明細・配送先の確認が完了していることを前提として実行される想定であり、確認機能と更新機能は連続して利用される。

## §4 業務ルール（条件付き：業務モード・権限制御がある画面のみ）

### 4.1 業務モードと切替条件

| モード | 切替条件 | UI の変化 |
|---|---|---|
| 通常編集モード | ステータスが下書きまたは確定の場合 | ステータス更新操作を活性化する |
| 閲覧専用モード | ステータスが出荷済またはキャンセルの場合 | キャンセルへの更新操作を無効化する |

### 4.2 業務判断ポイント

現在のステータスによって次に選択できるステータス（確定・出荷済・キャンセル）が変化する。

### 4.3 業務フロー内の前後画面との関係

注文一覧から受注番号を受け取り表示する。更新完了後は一覧へ戻り、更新結果が反映された一覧を再表示する。

### 4.4 権限別の UI 制御

| ロール | ステータス更新実行ボタン | 配送先情報 |
|---|---|---|
| 出荷担当者 | 表示 | 表示 |
| 受注担当者 | 表示 | 表示 |

## §6 データフロー

### 6.1 初期表示シーケンス

1. URL パラメータ取得（受注番号）
2. ストア初期化（AuthContext から利用者権限を取得）
3. API 呼び出し（§9 参照）
4. データ変換（§6.5 参照）
5. 画面状態を ready に更新

#### 6.1.1 起動時初期化（URL パラメータ → ストア書き戻し）

id パラメータを受注番号として order 取得APIの呼び出し引数に用いる。ストアへの書き戻しは行わない。

### 6.2 依存連鎖

order.status が変化すると availableNextStatuses が再算出される。

### 6.3 ユーザー操作確定時の処理フロー

1. バリデーション（§14 参照）
2. 確認ダイアログ表示（ステータス更新実行時）
3. API 呼び出し
4. 成功時: order を更新し statusHistory に追記
5. 失敗時: エラー表示（§14 参照）

### 6.4 データ更新トリガーの分類

| トリガー | 種別 | 処理概要 |
|---|---|---|
| ステータス更新実行ボタン押下 | ユーザー操作 | 選択された次ステータスへ更新APIを呼び出す |

### 6.5 データ変換（API レスポンス → 画面表示用データ）

| 変換名 | 入力型 | 出力型 | 変換概要 |
|---|---|---|---|
| formatOrderDetail | 注文詳細APIレスポンス | 画面表示用の注文詳細 | 金額の3桁区切り変換、ステータスコードの表示ラベル変換、明細行の小計算出を行う |

### 6.6 画面状態の遷移

| 状態 | 遷移条件 | UI の表示 |
|---|---|---|
| loading | 初期表示・更新処理中 | ローディング表示 |
| empty | 該当データなし | 空状態メッセージ |
| error | API エラー | エラーメッセージ（§14 参照） |
| ready | データ取得・更新成功 | メインコンテンツ |

## §7 ロジック

### 7.1 分岐

| キー | 条件 | 真の場合 | 偽の場合 |
|---|---|---|---|
| 編集可否分岐 | order.status が下書きまたは確定か（§4.1・§5.5 isEditable） | ステータス更新操作を活性化する | キャンセルへの更新のみ許可し他の更新操作を無効化する |
| 遷移先妥当性分岐 | 選択した更新後ステータスが現在のステータスから遷移可能な区分か（§13.2 STATUS_TRANSITION_MAP・§14.1） | 更新API呼び出しへ進む | 遷移不可エラーを表示する（§14.2） |
| 競合検出分岐 | 注文ステータス更新APIが409を返したか（§9.3） | 競合エラーを表示し最新状態を再取得する | 通常の成功・失敗処理を行う |

### 7.2 繰り返し

| キー | 対象 | 継続条件 | 打ち切りの条件 |
|---|---|---|---|
| 商品明細描画 | OrderItemTable の明細行（§6.5 items）の各要素 | 明細行が残っている間 | 表示上限件数（100件、§16.1）に達したとき、または明細行をすべて描画し終えたとき |
| ステータス変更履歴描画 | statusHistory（§5.3）の各要素 | 履歴が残っている間 | 履歴をすべて描画し終えたとき（§17.2 の新しい順ルールに従う） |

### 7.3 判定表

| キー | 入力の組み合わせ | 結果 |
|---|---|---|
| 更新実行ボタン活性判定 | 更新後ステータス選択済み かつ 現在ステータスから遷移可能 | ボタン活性化 |
| 更新実行ボタン活性判定 | 未選択、または現在ステータスから遷移不可 | ボタン非活性 |
| 配送先情報表示判定 | 利用者権限＝出荷担当者 または 受注担当者（§4.4） | 配送先情報とステータス更新実行ボタンを表示 |

## §8 疑似コード

ステータス更新実行ボタンを押したとき、選択した次ステータスが現在のステータスから遷移可能かを確認する。遷移可能な場合は確認ダイアログを表示する。確認ダイアログで承認された場合は注文ステータス更新APIを呼び出す。呼び出しに成功した場合は注文情報を更新し履歴に追記する。競合が検出された場合は競合エラーを表示し最新状態を再取得する。

一覧へ戻るボタンを押したとき、直前の検索条件を維持したまま注文一覧へ遷移する。

## §9 API 通信仕様（条件付き：API を呼ぶ画面のみ）

### 9.1 API 一覧

| No | API 名 | メソッド | エンドポイント | 呼び出し契機 |
|---|---|---|---|---|
| 9.2 | 注文詳細取得API | GET | /api/orders/:id | 初期表示時 |
| 9.3 | 注文ステータス更新API | PATCH | /api/orders/:id/status | ステータス更新実行時 |

### 9.2 注文詳細取得API

| 項目 | 内容 |
|---|---|
| 概要 | 指定した受注番号の注文詳細を取得する |
| エンドポイント | GET /api/orders/:id |
| 呼び出し契機 | 初期表示時 |

**リクエスト**

```
{ id（パスパラメータ）; }
```

**レスポンス**

```
{ orderId; customerName; items（明細の配列）; shippingAddress; status; statusHistory; }
```

**エラーと画面側の扱い**

| ステータス | 画面の挙動 | メッセージ ID |
|---|---|---|
| 401 | ログイン画面へ遷移 | — |
| 404 | 該当注文なしメッセージ表示 | MSG-ORDER-003 |
| 500 | システムエラーメッセージ表示 | MSG-COMMON-500 |

### 9.3 注文ステータス更新API

| 項目 | 内容 |
|---|---|
| 概要 | 注文のステータスを次の段階へ更新する |
| エンドポイント | PATCH /api/orders/:id/status |
| 呼び出し契機 | ステータス更新実行時 |

**リクエスト**

```
{ nextStatus; comment; }
```

**レスポンス**

```
{ status; updatedAt; statusHistory（更新後の配列）; }
```

**エラーと画面側の扱い**

| ステータス | 画面の挙動 | メッセージ ID |
|---|---|---|
| 400 | 遷移不可エラー表示 | MSG-ORDER-004 |
| 409 | 競合エラー表示・最新状態を再取得 | MSG-ORDER-005 |
| 500 | システムエラーメッセージ表示 | MSG-COMMON-500 |

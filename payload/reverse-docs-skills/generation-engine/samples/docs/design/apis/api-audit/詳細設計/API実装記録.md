### 4.1 関数と役割

| 関数 | 役割 |
|---|---|
| list_audit_logs | 監査の記録を頁で区切って返す |
| export_audit_logs | 監査の記録の全体を書き出しへ流す |
| get_user_audit | 利用者を指定して監査の記録を返す |
| list_alerts | 監査の警告を重大度で絞って返す |
| get_retention_policy | 記録を保持する期間の設定を返す |

### 4.2 関数単位の契約

対象は、当該 API のエントリーポイント、ならびに実装読解で追跡した 2 段以内の同一プロジェクト内の関数です。公開・非公開を問わず、定義を確認した関数をすべて 1 関数につき 1 行で記録します。外部ライブラリ、フレームワーク、および定義を確認できない呼び出し先は対象外とし、必要なら空欄のままとする。

| 関数 | 公開範囲 | 引数 | 戻り値 | 前提条件 | 副作用 | 例外・エラー |
|---|---|---|---|---|---|---|
| list_audit_logs | 公開 | database,page,page_size | items,page,pageSize を持つ辞書 | 監査の記録の表が存在すること | なし | データベースが送出する実行時の誤り |
| export_audit_logs | 公開 | database,writer | 書き出しの完了の結果 | 書き出し先が開かれていること | 書き出し先へ全行を書く | 書き出し先が送出する入出力の誤り |
| get_user_audit | 公開 | database,user_id | userId,items を持つ辞書 | 監査の記録の表が存在すること | なし | 記録が1件も無いとき見つからない旨の誤り |
| list_alerts | 公開 | database,severity | 警告の並び | 警告の表が存在すること | なし | データベースが送出する実行時の誤り |
| get_retention_policy | 公開 | config | retentionDays,archiveEnabled を持つ辞書 | 設定が読めること | なし | 独自の誤りを定めない |

### 4.5 設計判断とその理由

実装で選ばれている方式と、その選択理由を 1 つの判断につき 1 行で記録する。
「記述区分」は、実装のコードコメントが現在の実装と理由を直接結び付けている場合だけ `観測（コードコメント）` とする。
コメントの存在を観測したことを表す区分であり、コメントの主張が現在も妥当であることを保証する区分ではない。
実装構造から理由を導いた場合は `推定（実装構造）` とし、確からしさを `medium` または `low` で記録する。

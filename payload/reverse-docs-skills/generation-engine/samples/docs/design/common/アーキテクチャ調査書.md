## §4 ディレクトリ責務マップ

対象は決定的走査（find/ls）で確認した実在ディレクトリに限る。根拠のないディレクトリ追加は禁止。例外として、複数ディレクトリから import・参照される共有ファイル（共通スタイル定数・テーマ定義ファイル等、単一ディレクトリの責務に還元できないファイル）に限り、ディレクトリ列に当該ファイルの相対パスをそのまま置ける。この場合、責務列は「共有ファイル（<N>ディレクトリから参照）」の形式とし、参照先列は検出に使った決定的コマンドと実測件数を示す。該当する共有ファイルが無いプロジェクトでは本行を追加しない（空行・プレースホルダのまま残すことを禁止する）。

| ディレクトリ | 責務 | 参照先 |
|---|---|---|
| `src/pages` | 画面単位のルートコンポーネント（44件） | `find src/pages -name "*.tsx" \| wc -l` → 44 |
| `src/components` | 画面横断で使う共通コンポーネント | `grep -rl "from '@/components/common'" src \| wc -l` → 39ファイルから参照 |
| `src/hooks` | 画面固有・共通の状態管理フック | `find src/hooks -name "use*.ts"` |
| `src/stores` | Zustand によるドメイン別状態管理ストア | `grep -rl "zustand" src/stores` |
| `server/routes` | Express のリソース別ルーティング定義（62件） | `find server/routes -name "*.ts" \| wc -l` → 62 |
| `server/batch` | 日次・月次で実行されるバッチ処理（9件） | `find server/batch -name "*.ts" \| wc -l` → 9 |
| `server/webhooks` | 決済・配送等の外部サービスからの Webhook 受信処理 | `find server/webhooks -name "*.ts" \| wc -l` → 4 |
| `server/reports` | 帳票出力処理（5件） | `find server/reports -name "*.ts" \| wc -l` → 5 |
| `db/migrations` | テーブル定義のマイグレーションファイル（26件） | `find db/migrations -name "*.sql" \| wc -l` → 26 |
| `src/styles/tokens.ts` | 共有ファイル（39ディレクトリから参照） | `grep -rl "from '@/styles/tokens'" src \| wc -l` → 39 |

# 機能要件一覧（リバース版）

## §1 本書の位置づけ

本書はシステムが備える機能の一覧と、各機能が満たすべき要件を記す。機能の存在・構成・分類は機能一覧マニフェストと各機能設計書から観測できる。一方、各機能が業務上なぜ必要か、誰のための要件かは原本コードから導けないため、§2（観測事実）と確定できなかった事項を分ける。確定できなかった事項は根拠を記録する資料へ記録する。

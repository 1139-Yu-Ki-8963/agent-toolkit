## §1 本書の位置づけ

**この節の位置づけ: 仕様**

本書はシステムが備える機能の一覧と、各機能が満たすべき要件を記す。機能の存在・構成・分類は機能一覧マニフェストと各機能設計書から観測できる。一方、各機能が業務上なぜ必要か、誰のための要件かは原本コードから導けないため、§2（観測事実）には観測できた事実だけを書き、原本コードから導けない事項は本節に確定できなかった事項として明記する。

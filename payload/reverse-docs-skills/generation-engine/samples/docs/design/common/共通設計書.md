# 共通設計書（リバース版）

本書は複数のレガシー画面から抽出した、システム共通の実装済み挙動の記録です。往復検証の原則「正は既存挙動の忠実再現であり、あるべき仕様ではない」に従い、あるべき共通仕様を新たに設計するのではなく、既存コードに実際に存在する共通挙動のみを扱います。各画面詳細設計書の §14（共通仕様への準拠）は、本書を比較先として準拠状況・逸脱を記録する。

> 昇格規則: 複数画面の §14 に同一の逸脱が並んだら、本書へ昇格して共通挙動とし、各画面の §14 から当該行を削除する（逸脱の多数派は「記録されなかった仕様変更」である可能性が高い。三点照合で確定させる）。

## 本書に書かないもの

| 書かない内容 | 正の置き場 |
|---|---|
| 数値・色・フォント（共通） | `./DESIGN.md`（本フォルダ内。共通デザイン値の正） |
| 数値・色・フォント（画面固有差分） | 各画面の `../画面/詳細設計/DESIGN.md` |
| 画面固有の挙動 | 各画面詳細設計書の該当章 |
| UI 文言 | `./メッセージ定義書.md` |
| 実装の詳細（状態変数・DOM 構造） | 実装コード |

## §1 共通画面状態の規則（実測）

> 区分: 仕様

複数画面で共通して観測された 4 状態の実装済み挙動。各状態の「見せ方」の数値は各画面の `./DESIGN.md` を参照する。

| 状態 | 実装済みの見せ方 | 操作可否（実装済み） |
|---|---|---|
| loading | `DataTable` にスケルトン行を3行表示 | 検索・フィルタ操作を disabled 化 |
| empty | 「該当するデータがありません」の文言と、検索条件クリアの導線を表示 | 検索条件の変更のみ可 |
| error | トースト表示。文言は `./メッセージ定義書.md` を参照 | 再試行ボタンのみ操作可 |
| ready | 通常状態 | 全操作可 |

## §2 共通操作規則（実測）

> 区分: 仕様

### キーボード・フォーカス移動

| 規則 | 実装済みの内容 |
|---|---|
| フォーカス移動 | Tab キーでヘッダー → サイドナビ → メインコンテンツの順に移動する。逆順は Shift+Tab |
| フォーカストラップ | ダイアログ表示中は `ConfirmDialog` 内の要素のみを Tab 移動対象とする（`focus-trap` ライブラリを使用） |
| フォーカス可視性 | 各画面 DESIGN.md のアクセシビリティ節を参照（フォーカスリングは共通コンポーネントのスタイルに準拠） |

### 確認ダイアログを出す実装済み条件

| 条件 | 実装済みの内容 |
|---|---|
| 破壊的操作（削除・一括変更） | `ConfirmDialog` を表示し、対象件数を文言に含める |
| 入力内容の破棄 | 未保存の変更がある状態で画面遷移すると `ConfirmDialog` を表示する |
| 取り消せない操作 | 文言に「この操作は取り消せません」を含める（`./メッセージ定義書.md` 参照） |

## §3 共通レイアウト原則（実測）

> 区分: 仕様

数値（幅・高さ・余白）は各画面の `./DESIGN.md` を参照する。本節は複数画面で共通して観測された構造の原則のみを持ちます。

| 要素 | 実装済みの原則 |
|---|---|
| ヘッダ | 全画面共通。ロゴ・検索・通知アイコン・アカウントメニューを配置する |
| ナビゲーション | サイドバーによる共通ナビゲーション。折りたたみ状態は `localStorage`（キー: `sidebar-collapsed`）に保持する |
| メインコンテンツ | 各画面詳細設計書の §3 が構造を定義する |
| フッタ | 全画面共通。著作権表示とバージョン番号のみを表示する |

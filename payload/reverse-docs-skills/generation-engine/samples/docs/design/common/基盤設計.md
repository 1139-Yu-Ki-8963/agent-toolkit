# 基盤設計書

本書はシステムの基盤構成を整理した設計書である。フレームワーク・ビルド・デプロイ・認証の各構成を扱う。

## 本書に書かないもの

| 書かない内容 | 正の置き場 |
|---|---|
| 技術スタック・ビルドコマンドの詳細 | `./アーキテクチャ調査書.md`（§2〜§3） |
| ディレクトリ・ファイルの命名規則 | `./規約/どこに何を置くかの決まり.md` |
| コーディングスタイル | `./規約/コードの書き方と分割の決まり.md` |
| 画面固有のビルド差分 | 各画面詳細設計書 |

## §4 ディレクトリ構成方針

| ディレクトリ | 構成意図 |
|---|---|
| `src/pages` | 画面単位のルートコンポーネントを配置 |
| `src/components/common` | 画面横断で使用する共通コンポーネント |
| `src/stores` | Zustand によるドメイン別状態管理ストア |
| `server/routes` | Express のリソース別ルーティング定義 |
| `server/batch` | 日次・月次で実行されるバッチ処理 |
| `server/webhooks` | 決済・配送等の外部サービスからの Webhook 受信処理 |

---

## §5 環境変数管理

| 項目 | 内容 |
|---|---|
| 環境変数定義の所在 | `.env.development` / `.env.production` / `.env.test` の 3 ファイルに分離 |
| 環境別の分離方式 | Vite の `import.meta.env` 経由で読み込み、ビルド時にモード別ファイルを注入 |

---

## §6 認証セッション・ストレージ方式

| 項目 | 方式 | 保存先（cookie/localStorage/sessionStorage/メモリ） | 有効期限・失効契機 |
|---|---|---|---|
| アクセストークン | Zustand ストア（`authStore`）でメモリ保持。リロードで消失 | メモリ | 有効期限 15 分。リフレッシュ失敗時に失効 |
| リフレッシュトークン | HTTPOnly Cookie で保持 | cookie | 有効期限 14 日。ログアウト操作時にサーバー側で失効 |
| テーマ設定 | localStorage（キー: `theme-preference`） | localStorage | 有効期限なし（明示的な変更まで保持） |
| 下書き自動保存 | localStorage（キー: `draft-<screenId>`） | localStorage | 保存後 24 時間で自動破棄 |

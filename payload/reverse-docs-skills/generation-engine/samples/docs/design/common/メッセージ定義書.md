# メッセージ定義書

## 概要

エラー・警告・確認等、画面表示メッセージの一覧と文言規則を定義する。

## メッセージ分類

- エラー: 処理継続不可を示す
- 警告: 処理は継続するが注意喚起が必要
- 確認: ユーザーの意思決定を要する

## 文言規則

- 語尾は「です・ます」調に統一する
- エラーメッセージには原因と対処方法を含める

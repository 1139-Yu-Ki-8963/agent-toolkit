# UI共通設計書

本書はUI設計方針を俯瞰する設計書です。デザインシステム・共通コンポーネント・レイアウト・テーマ管理・アクセシビリティの方針を扱います。

## 本書に書かないもの

| 書かない内容 | 正の置き場 |
|---|---|
| 共通状態・操作規則の詳細（loading/empty/error 等） | `./共通設計書.md`（§1〜§3） |
| 数値・色・フォント（共通） | `./DESIGN.md` |
| 数値・色・フォント（画面固有差分） | 各画面の `../画面/詳細設計/DESIGN.md` |
| UI 文言 | `./メッセージ定義書.md` |
| コンポーネント実装規則（props 命名・分割方針等） | `./規約/部品の分け方と依存の決まり.md` |
| 画面固有のレイアウト | 各画面詳細設計書 |

---

## §1 デザインシステム

> 区分: 仕様

| 項目 | 内容 |
|---|---|
| 使用ライブラリ・デザインシステム | 独自実装のコンポーネントライブラリ（社内製 `@ec-admin/ui`） |
| バージョン | 2.4.0 |

---

## §2 共通コンポーネント一覧

> 区分: 仕様

| コンポーネント | 用途 | 使用画面数（頻度） |
|---|---|---|
| DataTable | 一覧画面の表形式表示（ソート・ページング内蔵） | 22/44 |
| ConfirmDialog | 確定・削除等の破壊的操作前の確認ダイアログ | 18/44 |
| StatusBadge | 注文・請求・会員等の状態値をバッジ表示 | 30/44 |
| Toast | 操作結果の通知トースト表示 | 44/44 |

---

## §3 レイアウト方針

> 区分: 仕様

| 要素 | 実装済みの原則 |
|---|---|
| グリッドシステム | CSS Grid による 12 カラム構成 |
| ブレークポイント | 768px（タブレット）/ 1280px（デスクトップ）の 2 段階 |

---

## §4 テーマ・スタイル管理

> 区分: 仕様

| 項目 | 内容 |
|---|---|
| CSS 設計方針 | CSS Modules（コンポーネント単位で `*.module.css` を併置） |
| テーマ切替の有無 | ライト/ダークの 2 テーマ切替あり |
| レスポンシブ対応方針 | 管理画面のためデスクトップファースト（モバイル最適化は対象外） |

---

## §5 アクセシビリティ方針

> 区分: 仕様

| 項目 | 内容 |
|---|---|
| WAI-ARIA 対応 | モーダル・トーストに `aria-live` / `aria-modal` 属性を付与 |
| キーボード操作対応 | Tab キーによるフォーカス移動、Esc キーでモーダルを閉じる（詳細は `./共通設計書.md` §2 参照） |

---

## §6 画面横断 UI 状態

> 区分: 仕様

| 状態名 | 保持場所（store/context等） | 影響範囲（画面・コンポーネント） | 初期値 |
|---|---|---|---|
| テーマ設定 | localStorage（キー: `theme-preference`） | 全 44 画面の共通レイアウト | light |
| 通知トースト | Zustand ストア（`toastStore`） | 全画面共通ヘッダー配下の Toast コンポーネント | 空配列 |
| モーダル開閉状態 | `ModalContext`（React Context） | 一覧・編集系の約 20 画面 | closed |
| サイドバー開閉 | localStorage（キー: `sidebar-collapsed`） | 全 44 画面の共通レイアウト | false（展開） |

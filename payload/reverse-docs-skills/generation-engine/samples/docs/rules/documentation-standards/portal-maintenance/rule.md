# 生成した文書を直接編集しない決まり

## 概要

ポータルと一覧の HTML を保守するときの取り決め。

これらの HTML は定義から生成される派生物である。人が直接編集する対象ではない。

台帳による検知については定義と生成物の分け方の決まりが定める。

## 規則

| 規則 | 内容 | 根拠 | 検査 |
|---|---|---|---|
| HTML を直接編集しない | `project-portal/` 配下の HTML と一覧ページは生成物である。表示を見て気付いた誤りも HTML 側では直さない | 直接編集すると次の生成で失われ、直したはずの内容が消える | 静的解析: 生成物 HTML の内容ハッシュを台帳と突合し、一致しないファイルを検出する |

## このプロジェクトの規則

| 規則 | 内容 | 根拠 | 検査 |
|---|---|---|---|
| 未解析 | この規約に対応する実装の慣行は、まだ観測していない。リバース解析を実行して対象コードを分析すると、その結果からこの節へ規則が起こされる。解析を待たずに規則を決めたい場合は、この節へ直接書き足してよい | 未解析: リバース解析が未実行であり、対象コードの観測結果がない | 不可: 観測の有無は解析の実行結果に依存し、静的解析で判定できない |

## 違反時の手順

書き込みが止められた場合、直したい内容を生成の元（定義ファイルやテンプレート）へ書き、生成をやり直す。表示の誤りに気付いても、生成物の HTML を直接書き換えない。

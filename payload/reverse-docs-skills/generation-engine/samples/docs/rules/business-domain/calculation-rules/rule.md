# 金額と数量の計算の決まり

## 概要

金額・数量・日付の計算の手順と、その根拠の取り決め。

計算の誤りは結果が出るため、動いていないという形では現れない。式・端数の扱い・計算の順序を確定し、設計書とコードで同じ式を持つ状態にする。

## 規則

| 規則 | 内容 | 根拠 | 検査 |
|---|---|---|---|
| 式を設計書へ書く | 計算の式を設計書へ書き、実装だけが式を持つ状態にしない | 実装だけにある式は、正しいかどうかを実装を読んで判断することになる | 静的解析: 基本設計書に計算の式の記述が実在するかを走査する ／ レビュー: 設計書の式が実装の式と一致しているかを確認する |
| 端数の扱いを式ごとに決める | 切り上げ・切り捨て・四捨五入と、丸める位を式ごとに決める | 端数の扱いは既定に任せると、処理系ごとに違う | 静的解析: 計算の記述に丸めの方法と丸める位の指定が式ごとにあるかを走査する |
| 計算の順序を明示する | 複数の計算が続く場合、どの順で計算するかを書く | 順序が違うと、端数の処理の位置が変わって結果が変わる | 静的解析: 計算の式の記述に順序を示す番号または並びがあるかを走査する |
| 金額を小数で扱わない | 金額の計算に、誤差の出る小数の型を使わない | 誤差の出る小数の型は10進の値を正確に表せず、加算のたびに誤差が積み上がる | 静的解析: 金額を扱う項目の型に、誤差の出る小数が使われていないかを走査する |
| 単位を式と項目に付ける | 数量と金額の単位を、式の記述と項目の名前の両方へ書く | 単位の違う値どうしの計算は、型の検査を通り抜ける | 静的解析: 数量を扱う識別子に単位を示す語が含まれているか、計算の式の記述にも単位を示す語が含まれているかを走査する |
| 根拠を式に添える | 各式について、何を根拠にその式にしたかを添える | 根拠の無い式は、変えてよいかどうかを誰も判断できない | 静的解析: 計算の式の記述に根拠の欄が埋まっているかを走査する |
| 境界の値で確かめる | 0・上限・下限・端数が出る値で、計算の結果を確かめる試験を置く | 境界の誤りは、通常の値では現れない | 静的解析: 計算を行う処理に、境界の値を用いた試験が存在するかを走査する ／ テスト: 0・上限・下限・端数が出る値で計算を実行し、期待した結果になることを確かめる |

## 違反時の手順

書き込みが止められた場合、金額を扱う項目の型を、誤差の出ない型（整数や10進の固定小数点の型）へ書き直してから改めて書き込む。金額と無関係な項目がたまたま金額らしい語を含んでいた場合は、識別子の名前を紛らわしくない語へ変える。

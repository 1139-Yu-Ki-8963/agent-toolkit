# 業務の言葉の決まり

## 概要

業務で使う言葉と、コードの中の識別子の対応の定義。

同じものを別の名前で呼ぶと、設計書とコードの間で対応が取れなくなる。言葉を1つに決め、設計書・画面の表示・コードの識別子のすべてで同じ語を使う。

語彙そのものは用語辞書の成果物が持つ。本書は語をどう決め、どう保つかを定め、語の一覧は持たない。

## 規則

| 規則 | 内容 | 検査 |
|---|---|---|
| 1つの概念に1つの語を決める | 業務の1つの概念へ、日本語の正式な呼び名を1つ決め、別名を作らない | 判定不能: 同じ意味を持つかどうかは意味の同一性の判断を要し、静的解析では判定できない ／ レビュー: 用語の一覧に同じ意味を持つ複数の見出しが無いかを確認する |
| 語ごとに識別子を対応させる | 各語へ、コードで使う識別子を1つ対応させる | 静的解析: 用語の一覧の各項目に、対応する識別子の欄が埋まっているかを走査する |
| 定義を1文で書く | 各語の意味を1文で書き、他の語との違いが分かる書き方にする | 静的解析: 用語の一覧の各項目に定義の欄が埋まっているかを走査する ／ レビュー: 定義が1文で書かれ、他の語との違いが分かる書き方になっているかを確認する |
| 使ってはいけない語を明示する | 過去に使っていた語と紛らわしい語を、使わない語として一覧へ残す | 静的解析: 用語の一覧に使わない語の区分が存在するかを走査する ／ レビュー: その区分に、過去に使っていた紛らわしい語が実際に列挙されているかを確認する |
| 表示の文言と語を揃える | 画面と帳票に出す文言を、用語の一覧の正式な呼び名と揃える | 静的解析: 画面の文言に、用語の一覧で使わないと定めた語が使われていないかを走査する |

## 違反時の手順

書き込みが止められた場合、用語の一覧の表へ「使わない語」の区分を見出しまたは列として足し、過去に使っていた紛らわしい語をそこへ移してから改めて書き込む。使わない語が実際に存在しない場合は、区分だけを空の状態で用意する。

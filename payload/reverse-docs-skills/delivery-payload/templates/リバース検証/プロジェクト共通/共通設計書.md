# 共通設計書（リバース版）

<!-- INTRODUCTION_GUIDANCE: 冒頭案内は delivery-payload/references/設計書様式.md §9 の記入規則に従う。読み手が各節で何を見て何をするかを示す。複数節では「節｜内容｜読み手へのお願い」の3列表を置き、本文の節ごとに1行を対応づける。作る側の判断の理由・保管方法・作業の経緯・文書作成の方針・件数の内訳は書かない。 生成する本文の自由記述は敬体（です・ます）で書く。 -->

本書は複数のレガシー画面から取り出した、システム共通の実装済み挙動の記録です。往復検証の原則「正は既存挙動の忠実再現であり、あるべき仕様ではない」に従い、あるべき共通仕様を新たに設計するのではなく、既存コードに実際に存在する共通挙動のみを扱う。各画面詳細設計書の §14（共通仕様への準拠）は、本書を比較先として準拠状況・逸脱を記録する。

> 昇格規則: 複数画面の §14 に同一の逸脱が並んだら、本書へ昇格して共通挙動とし、各画面の §14 から当該行を削除する（逸脱の多数派は「記録されなかった仕様変更」である可能性が高い。三点照合で確定させる）。

## 本書に書かないもの

| 書かない内容 | 正の置き場 |
|---|---|
| 数値・色・フォント（共通） | `./DESIGN.md`（本フォルダ内。共通デザイン値の正） |
| 数値・色・フォント（画面固有差分） | 各画面の `../画面/詳細設計/DESIGN.md` |
| 画面固有の挙動 | 各画面詳細設計書の該当章 |
| UI 文言 | `./メッセージ定義書.md` |
| 実装の詳細（状態変数・DOM 構造） | 実装コード |

| 状態 | 実装済みの見せ方 | 操作可否（実装済み） |
|---|---|---|

## §4 関連資料

他文書の所在はこの節へまとめる。参照先は文書内の節または関数単位の契約に限定し、対象コードの位置は記録しない。

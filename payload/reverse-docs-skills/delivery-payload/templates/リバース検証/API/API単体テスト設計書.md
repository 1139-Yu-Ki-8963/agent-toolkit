## §1 テスト観点

§1は正常・異常・境界を含む全観点の一覧です。
§5と§6は、§1のうち異常と境界の観点を列ごとに詳しく述べる部分集合です。
§5と§6では新しい観点キーを作らず、§1と同じ観点キーを使います。
実行する全ケースは§2だけに記載し、§1の全観点へ1件以上のケースを対応させます。
実行するテストの件数は§2のデータ行数だけで数えます。

観点は詳細設計書の§2 メソッド設計・§3 ロジック設計・§6 エラー処理から起こす。API詳細設計書では、それぞれ§12.2 関数単位の契約・§5 ロジック・§10 エラーを対応する情報源として扱う。

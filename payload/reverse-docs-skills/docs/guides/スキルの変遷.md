# スキルの変遷

## 1. この文書は何か

この文書は、既存のコードから設計書を起こす一連のスキルが、どのように増え、どのような役割を持つようになったかを示す。

はじめはコードから設計書を起こす 6 本だけだった。現在は 52 本があり、設計書の生成のほかに、一覧の作成、ポータルの組み立て、規約の提案、用語の管理までを扱う。

以降は、数の推移、役割が加わった順序、現在の内訳の順に示す。

## 2. 数の推移

スキルの数は、次の 7 つの段階を経て 6 本から 52 本になった。

| 段階 | スキル数 | 何が加わったか |
|---|---|---|
| リバース系の移設 | 6 | コードから設計書を起こす 6 スキルを 1 か所に集めた（起点） |
| 一覧生成の分割 | 17 | 一覧の生成を 6 つの種別へ分けた |
| 基本設計と基盤ページ | 25 | 基本設計、共通の設計書、基盤となるページ 5 本、コードの計測 |
| ポータル種別の拡張 | 34 | 交差して見るページと、ポータルが扱う 8 つの成果物の種別 |
| 改善課題の登録 | 37 | 改善すべき点を登録するスキル |
| 6 種別の設計を揃える | 51 | 6 つの種別すべてに基本設計と詳細設計を揃えた |
| 要件定義の追加 | 52 | 要件定義を起こすスキル |

起点は 6 本で、次の段階で 17 本になった。最初の一段で約 3 倍に増えている。51 本から 52 本の間は増えていない。

## 3. 役割が広がった順序

役割が加わった順序を、代表的なスキル名とともに示す。表の並びが加わった順である。

| 加わった役割 | 代表的なスキル |
|---|---|
| コードから設計書を起こす、一覧を作る、環境をそろえる（起点） | rebuilding-code-from-docs, generating-screen-list-for-reverse-docs, syncing-reverse-env |
| 基本設計と共通の設計書を作る | generating-reverse-basic-design, generating-reverse-common-docs |
| ポータルと図を作る、環境とコード量を調べる、用語を集める | generating-er-diagram-for-reverse-docs, counting-code-lines, generating-glossary-for-reverse-docs |
| ポータルが扱う成果物の種別を広げる | generating-design-system-for-reverse-docs, generating-icon-catalog-for-reverse-docs |
| AI が読む設定資産を索引にする | generating-agent-config-index-from-repo |
| 用語の管理を独立させる | maintaining-semantic-glossary, managing-semantic-glossary |
| 納品先へ渡す規約を提案する | generating-rule-proposals-for-reverse-docs |
| 開発の進め方そのものを組み立てる | orchestrating-ai-development-setup |

はじめに備わったのは、コードから設計書を起こす役割だけだった。そこへ一覧、基本設計、ポータルという、作れる成果物の種類を増やす役割が加わった。その後に、規約と用語の管理という、生成の前提を扱う役割が加わっている。

## 4. 現在の姿

52 本のスキルを役割ごとに数えた内訳である。

| 役割 | 本数 | スキル名（代表 3 件） |
|---|---|---|
| 設計書の生成（基本設計・詳細設計・事実の抽出） | 21 | generating-reverse-basic-design, extracting-unit-facts-from-code, rebuilding-code-from-docs |
| 一覧の生成 | 10 | generating-screen-list-for-reverse-docs, generating-api-list-for-reverse-docs, generating-test-case-list-for-reverse-docs |
| ポータルと図の生成 | 11 | generating-design-system-for-reverse-docs, generating-er-diagram-for-reverse-docs, generating-icon-catalog-for-reverse-docs |
| 調査と改善の管理 | 4 | counting-code-lines, surveying-local-environment, prioritizing-improvement-tasks-from-images |
| 用語の管理 | 3 | generating-glossary-for-reverse-docs, maintaining-semantic-glossary, managing-semantic-glossary |
| 規約 | 2 | generating-rule-proposals-for-reverse-docs, generating-agent-config-index-from-repo |
| 開発の進め方の取りまとめ | 1 | orchestrating-ai-development-setup |

設計書の生成、ポータルと図の生成、一覧の生成の 3 つで 42 本を占める。成果物を作る役割が中心である。

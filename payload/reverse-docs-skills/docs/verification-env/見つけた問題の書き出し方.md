# 見つけた問題の書き出し方

## 書き出す形

問題1件につき、次の4つを書いてください。

| 項目 | 書く内容 |
|---|---|
| 現象 | 何が起きたかです。実際に見たものだけを書きます |
| 修正内容 | どう直すべきかです |
| 検収方法 | 直ったことを、どう確かめるかです |
| 完了条件 | どこまでやれば終わりかです |

## 現象の書き方

実際に見たものだけを、書いてください。
推測は、書かないでください。

| 良い書き方 | 悪い書き方 |
|---|---|
| 画面の設計書9件のうち4件に章が無い | 設計書の品質が低い |
| 一覧から設計書へのリンクが2件切れている | リンクが正しくない |
| 生成に12分かかった | 生成が遅い |

数えられるものは、数えてください。
実行したコマンドと、その出力があれば添えてください。

## 検収方法の書き方

機械で確かめられる形に、してください。

| 良い書き方 | 悪い書き方 |
|---|---|
| 〜が0件になる | 〜が改善される |
| 〜が終了コード0を返す | 〜が正しく動く |
| 〜のファイルが実在する | 〜が整備されている |

## 置き場

見つけた問題は、手元に置いてください。
このリポジトリへは、push しないでください。
人が内容を見てから、課題の一覧へ転記します。

# 検証環境向けの案内

## あなたは何をする環境か

ここは、改善された仕組みが実際に使えるかを確かめる環境です。
公開リポジトリから最新の内容を取得します。
取得した内容を、実際のプロジェクトへ適用します。
出来上がった設計書や一覧が、読めるか、使えるかを確かめます。

## 文書の案内

| 文書 | 何が書いてあるか |
|---|---|
| このリポジトリは何か.md | 配られる仕組みの全体像 |
| 検証の進め方.md | 見張り方と、各回の手順 |
| 見つけた問題の書き出し方.md | 問題を書き出す形と、書き方 |

## 最初にやること

1. `このリポジトリは何か.md` を読みます。
2. `検証の進め方.md` に従って、確認を始めます。

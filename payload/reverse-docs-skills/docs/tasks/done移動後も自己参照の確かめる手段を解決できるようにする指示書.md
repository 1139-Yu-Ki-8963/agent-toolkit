# done移動後も自己参照の確かめる手段を解決できるようにする指示書

**状態**: 着手できる
**優先度**: 中
**前提**: `docs/tasks/終了コード2に実行環境の制約とコマンド自身のエラーが衝突する問題を記録する指示書.md`
**元の指摘**: なし

## この指示書は何か

`done/`への移動後も、自己参照する確かめる手段を実行できるようにする指示書である。

## なぜ必要か

移動前の固定パスを参照するコマンドは、`done/`への移動後に対象を開けない。
このとき、コマンド自身の終了コード2を環境制約と誤認するおそれがある。

## やること

1. `docs/tasks/`直下と`docs/tasks/done/`配下の対応記録を全件走査する。
2. 確かめる手段のうち、自分自身の移動前固定パスを参照するコマンドを列挙する。
3. 各対象を、`done/`移動後も解決可能なコマンドへ変更する。
4. 変更後に、各対象の実在パスを指定して
   `bash docs/scripts/judge-task-done.sh --only <対象の実在パス>`を実測する。

例:

```bash
bash docs/scripts/judge-task-done.sh --only 'docs/tasks/done/自己テストの所要時間が規約の件数に追いつかれる問題を片付ける指示書.md'
```

## 完了の判定

1. 対象一覧と、0件を含む件数が対応の記録に残っている。
2. 検出した全対象の参照が、`done/`移動後も解決する。
3. 各対象の`--only`判定に、移動前パス不在由来の終了コード2がない。

## 触らない範囲

- `docs/scripts/judge-task-done.sh`の実装
- 自己参照と無関係な確かめる手段
- 指示書本文の「対応の記録」以外の内容

## 決めていないこと

| 何を決めるか | 既定（迷ったらこれを選ぶ） | 覆すときの条件 |
|---|---|---|
| 直し方 | 固定の旧パスを単に`done/`へ書き換えない。移動前の`docs/tasks/`と移動後の`docs/tasks/done/`の実在パスを解決してから検査する。自己参照をやめ、同じ条件を別の一次情報で測れる場合は自己参照廃止を優先する。 | — |
| 対象が0件の場合 | 走査コマンドと0件を対応の記録に残す。0件でも完了にできる。 | — |

## 他の指示書との関係

- 終了コード2の意味の衝突を記録する指示書の自己参照対応を実施する。
- 判定器の終了コード2の解釈自体は、前提の指示書とは別に扱う。

## この指示書の位置づけ

自己参照する確かめる手段の洗い出しと修正を担当する。
判定器の実装変更は対象としない。

**状態**: 着手できる

## この指示書は何か

配布する検査29件のうち宣言が無い2件、規則に対応する判定が無い1件、配布物外の辞書が無いと不合格へ混ざる1件を直す。

## なぜ必要か

検査本体が違反を検出できても、定義に宣言が無ければ規約変更時の見直し対象から外れる。規則名に対応する判定が無ければ、規約と検査の対応を機械で確認できない。依存する辞書が無い場合を不合格として扱うと、対象内容の欠陥と実行環境の不足を区別できない。

## やること

1. `delivery-payload/references/rule-taxonomy.json` に横断検査の宣言を設け、顧客提示文書と作業指示書の2検査が守る規則を記録する。
2. `check-temp-file-tracked.sh` に「運営文書の置き場を固定する」の静的解析判定と自己テストを追加する。
3. `check-instruction-writing.sh` で辞書欠落を `[UNKNOWN]`・終了コード2として区別し、自己テストを追加する。
4. 指定された3検査、辞書欠落を模した検査、宣言の対応確認、指示書形式検査を実行する。
5. 変更ファイルを個別にstageし、`【バグ修正】規約の宣言と判定の欠けを埋める` でコミットする。

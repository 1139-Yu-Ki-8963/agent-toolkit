# ディレクトリ名の方針が実態と食い違う問題を直す指示書

**状態**: 設計から始める
**優先度**: 中
**前提**: なし
**元の指摘**: なし

## この指示書は何か

配置の定義は「ディレクトリの名前は英数字とハイフンのみ」と定める。
ところが実態は、日本語のフォルダ名を広く使っている。
方針が持つ根拠を確かめたうえで、方針と実態のどちらを正とするかを決める。

## なぜ必要か

実測（2026-08-24）。
一覧の置き場を日本語へ揃える作業の中で、方針と実態の食い違いが見つかった。
この食い違いには、双方に理由がある。

配置の定義（`delivery-payload/references/output-layout.json`）の
`directoryNamePolicy` は、ディレクトリ名を英数字とハイフンに限る方針を持つ。
`reason` には、次の3つの根拠が書かれている。

1. 履歴管理の道具が経路を8進数へ変換して表示するため、
   経路の文字列での絞り込みが一致しない
2. 経路を場所の指定へ埋め込む際に変換が要り、
   変換の有無が食い違うと一致しない
3. 基本ソフトによる文字の正規化の違いで、
   同じ名前が合成済みと分解の2通りで記録されうる

**1つ目の根拠は、実際に踏んだ事例がある。**
公開の作業で、日本語のファイル名がエスケープ表示された。
変更の範囲を確認する際、この表示によって一度取りこぼした。
`.claude/rules/always/publish/complete/rule.md` の手順3が、
この事実をすでに記録している。

一方、`directoryNamePolicy` には `listRootException` という欄が既にある。
一覧系5キー（`unitsRoot`・`unitListDir`・`unitListHtml`・`screenListDir`・
`screenListHtml`）を対象外とし、理由が書かれている。
`portal-catalog.json` の既定と種別別一覧生成スクリプトの出力先が、
既に一覧配下を日本語で統一しているためである。

実測すると、配置キーは全部で60件ある。
そのうち日本語を含むキーは23件である。
**方針を満たしていない箇所は多数ある。**

方針にも、実態にも、それぞれの理由がある。
どちらかが誤っているのではない。
方針の根拠が今も成り立つかを、確かめていないことが問題である。

## やること

1. **3つの根拠それぞれについて、実際に不具合が出るかを実測する。**
   日本語のフォルダを含む経路で再現を試み、出力を記録する。

   | 根拠 | 実測の方法の例 |
   |---|---|
   | 経路の文字列での絞り込みが一致しない | 日本語のフォルダを含む変更を作り、変更の一覧を接頭辞で絞り込めるかを見る |
   | 場所の指定への埋め込みで変換が要る | 日本語のフォルダを含む経路を、表示する側の指定へ埋め込んで開けるかを見る |
   | 文字の正規化の違いで2通りに記録されうる | 同じ名前を合成済みと分解の両方で作り、区別されるかを見る |

2. **実測の結果を見て、方針と実態のどちらを正とするかを決める。**
   3つとも再現しなければ実態を正とし、方針を書き換える。
   1つでも再現すれば、その根拠が及ぶ範囲を英字へ揃える。

3. 決めた側へ揃える。

4. `listRootException` を、決めた内容に合わせて書き換える。
   削除するかどうかは決定の内容による。

5. 決めた内容を機械で確かめる検査を作る。

## 完了の判定

1. 3つの根拠それぞれについて、再現を試みた結果が記録されている
2. 記録に、実行したコマンドとその出力が含まれている
3. 実測の結果に基づいて、方針と実態のどちらを正とするかが決まっている
4. 決めた内容が「判断の記録」へ書かれている

## 触らない範囲

- 一覧の置き場を日本語とした決定を覆さない。利用者が決めたことである
- 設計書の置き場（`docs/design/` 配下。英字である）を、この作業では扱わない

## 他の指示書との関係

`docs/tasks/一覧の置き場が三者三様になっている問題を直す指示書.md` の作業中に見つかった。
あちらは一覧の置き場を日本語へ揃える作業であり、既に片付いている。
本指示書は、その作業で残った方針との食い違いを扱う。

## この指示書の位置づけ

方針には根拠がある。実態にも経緯がある。
どちらかが誤っているのではなく、根拠が今も成り立つかを確かめていないことが問題である。
確かめないまま放置すると、新しく作る場所の名前をどう付けるかが決まらない。
例外を足して回避すると、方針が何を定めているのか読み取れなくなる。

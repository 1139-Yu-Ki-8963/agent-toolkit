## 判定不能: 第1層の全件実走

実行コマンド:

```text
bash generation-engine/scripts/verification/run-layer-machine-checks.sh --timeout 120
```

初回は `Script running with cell ID 8` となった。`wait(cell_id=8)` は終了コードを返さなかった。最後に確認できた行は次のとおりである。

```text
[PASS] generation-engine/scripts/add-sync-entry.sh — 実行 1 件 / 終了コード 0
```

次のwaitは `exec cell 8 not found` だった。

出力を末尾40行へ絞って再実行した。`Script running with cell ID 9` の後、`Script completed` となった。しかし、終了コードと出力本文は返らなかった。`ps` ではwrapper PID 64688と集約本体PID 64716が残っていた。両方が今回のコマンドと一致することを確認し、`TERM` で停止した。停止後の `ps -p 64688,64716` は出力なし、終了コード1だった。

したがって、全件集約の最終集計と終了コードは取得できず、合格・不合格のどちらにも数えない。取得できた個別PASS行も全体合格の根拠には使わない。

# 独自の言葉遣いの洗い出しと判定

`docs/tasks/独自の言葉遣いをなくす指示書.md` の完了判定 1〜3 に対応する記録である。判定の基準は指示書 3.2 節「この場所を知らない人が、その語を初めて見て意味を取れるか」に従う。

対象は `.claude/skills/*/SKILL.md`（52本）と `.claude/skills/*/references/guide.html`（52本）。洗い出しは、指示書に挙がった起点16語に加え、サンプリング通読とkatakana語の機械抽出により23語を追加で発見した。全ファイルを一字一句通読したわけではないため、以下は最良努力の洗い出しであり網羅を保証しない。ただし、判定で「置き換える」となった語は本指示書に付随する検査（3.5節）が全スキル横断で走査し、残存を機械的に検出し続ける。

## 訂正の経緯

初回の洗い出しはサンプル引用1件ずつを根拠にした判定だった。実際の全数を確認した担当者からの指摘により、次の2語は判定を撤回した。

- **周**: 実際の出現はすべて「周回」という複合語（周回ループ・実周回数・1周回あたり等）であり、標準的な日本語（「地球を周回する」等と同じ用法）だった。単独の「周」用法は存在しなかった
- **開通**: `unlocking-reverse-target-screens` スキルで「未開通」「開通済み」「開通対象」「開通記録」「画面開通」等、約30箇所・6ファイルにわたり中核語彙として定着していた。この語はスキル名（unlocking）の概念と対応しており、機械的な置換は文章を壊す。規模と語の一般性（開通は道路・電話回線等で広く使われる通常の日本語）を踏まえ、置き換えを撤回した

| 語 | 出ている場所 | 何を指しているか | 判定 | 残す理由 |
|---|---|---|---|---|
| 正本 | SKILL.md 52件・guide.html 22件 | 複数の対象を持つ「唯一の正しい情報源」（定義文書・規約文書・確定版など文脈により対象が変わる） | 残す（説明を添える） | 単一の言葉で「複数存在する場合の唯一の正しい情報源」という概念を表せる。英語の "canonical source" に相当する必要な概念語であり、置き換えると説明がかえって長くなる。ただし対象が文脈依存で変わるため、初出箇所に「〜の正本（唯一の正しい情報源）」と説明を添える |
| 派生 | SKILL.md 11件・guide.html 52件 | 正本から生成・導出された値やファイル | 残す（説明を添える） | 正本と対になる概念であり、「元になるものから生成されたもの」という一語の概念を表す。初出箇所に説明を添える |
| 台帳 | SKILL.md 25件・guide.html 3件 | 状態や履歴を時系列で記録し続けるファイル（task-ledger.md 等、対象は複数存在） | 残す（説明を添える） | 「継続的に記録し続ける台帳」という一語の概念を表す。実物のファイル名とは異なるため、初出箇所に対象の実際のファイル名を明記する説明を添える |

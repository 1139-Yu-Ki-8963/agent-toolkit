## 1. この指示書は何か

画面検出の自己テストで、一時領域の末尾スラッシュとテンプレート側のスラッシュが重なり、期待値だけに `//` が残る問題を直す指示書である。

## 2. なぜ必要か

import解決側はパスを正規化するため、期待値と実値の文字列表現だけが食い違い、エイリアス解決など5件の機能検査が失敗して見える。機能の判定を弱めず、一時パスの生成を安定させる必要がある。

## 3. やること

`generation-engine/scripts/unit-list/detect-screens.sh` の一時ファイル作成ヘルパーで、`TMPDIR` の末尾スラッシュを除いてからテンプレート名を連結する。置き場の明示、作成失敗時の `[UNKNOWN]`、終了コード2は維持する。

## 4. 完了の判定

1. `bash generation-engine/scripts/unit-list/detect-screens.sh --self-test` が終了コード0を返す。
2. `bash docs/scripts/check-mktemp-placement.sh` が終了コード0を返す。
3. `bash generation-engine/scripts/tests/check-broken-verdict-rows.sh` が終了コード0を返す。

## 5. 触らない範囲

importのBFS順序、共有ディレクトリ境界、他画面境界、最大深さの仕様、および自己テストの期待集合は変更しない。

## 6. 決めていないこと

| 何を決めるか | 既定（迷ったらこれを選ぶ） | 覆すときの条件 |
|---|---|---|
| 末尾スラッシュを除く場所 | `_mktemp_or_unknown` の入口で一度だけ正規化する | 呼び出し元ごとに異なる一時領域を保持する要件が実在した場合 |
| ルート `/` の扱い | `/` は除去せず保持する | `mktemp` がルート直下テンプレートを受理しない環境を実測した場合 |

## 7. 他の指示書との関係

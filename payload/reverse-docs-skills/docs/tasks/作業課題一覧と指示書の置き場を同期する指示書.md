# 作業課題一覧と指示書の置き場を同期する指示書

**状態**: 着手できる
**優先度**: 高
**前提**: なし
**元の指摘**: なし

## この指示書は何か

`docs/tasks/作業課題一覧.md` の 15 件について、指示書の置き場と状態を一致させる。次に指示書が `done/` へ移ったときも食い違いを検出できる検査を追加し、第 1 層から自己テストを実行できるようにする。

## なぜ必要か

2026-08-23 の実測では、台帳の見出し 15 件に対して直下は 3 件、`done/` は 12 件、どちらにも無いものは 0 件だった。しかし、台帳は全件を「着手できる」と記録しており、完了した課題も残件に見える。手作業の更新だけでは同じずれが再発する。

## やること

1. 台帳の各見出しと、`docs/tasks/` 直下および `docs/tasks/done/` の同名ファイルを照合する。
2. `done/` にある 12 件を「完了」へ更新し、直下の 3 件は「着手できる」を保つ。
3. 台帳へ実測日と状態語の選択理由を記録する。
4. 置き場と状態の食い違いを終了コード 1 で返す検査を `docs/scripts/` へ追加する。
5. 検査の `--self-test` を呼ぶ薄いラッパーを `generation-engine/scripts/tests/` へ追加する。

## 完了の判定

1. 検査本体の正常系と食い違い系が通る: `bash docs/scripts/check-task-ledger-sync.sh --self-test`
2. 実際の台帳と置き場の食い違いが 0 件になる: `bash docs/scripts/check-task-ledger-sync.sh`
3. 第 1 層用ラッパーから自己テストが通る: `bash generation-engine/scripts/tests/check-task-ledger-sync.sh`
4. この指示書を含む直下の指示書が形式検査を通る: `bash .claude/rules/always/tasks/instruction-format/check-instruction-format.sh`

## 触らない範囲

- `docs/tasks/` 直下の既存の指示書と `docs/tasks/done/` 配下
- `docs/tasks/指摘改善一覧.md`
- `docs/scripts/judge-task-done.sh` と `docs/scripts/report-progress.sh`
- `generation-engine/scripts/verification/` 配下

## 決めていないこと

| 何を決めるか | 既定（迷ったらこれを選ぶ） | 覆すときの条件 |
|---|---|---|
| 検査スクリプトの名前 | `check-task-ledger-sync.sh` とする | 既存の同名ファイルが実在する場合は、同じ意味を保った別の英字ケバブケース名にする |
| 見出しに対応するファイルが両方またはどちらにも無い場合 | 実態との不一致として終了コード 1 に数える | ファイルシステム自体を読み取れず判定できない場合は `[UNKNOWN]` と終了コード 2 にする |

## 他の指示書との関係

- `作業課題一覧.md` 自体の完了の判定を、直下の件数だけでなく `done/` を含む置き場との照合へ更新する。
- `judge-task-done.sh` の移動判定には手を入れず、移動後の台帳同期だけを独立して検査する。

## この指示書の位置づけ

台帳の 15 件を一度だけ修正する作業と、同じずれを検出する回帰検査を 1 つの変更として扱う。指示書の移動処理そのものへ責務を広げず、台帳と置き場の整合だけに範囲を限定する。

### `build-matrix-data.sh` の根本原因（実測で特定済み）

委任元が実物の一覧の元データで再現し、原因を特定した（2026-08-19・コミット `4c6bdeed` 時点）。


**API 一覧の元データに `method` の欄が無い。** 作成・参照・更新・削除の判定にこの欄を使うため、判定できずに止まる。落ちている 4 件は、この 1 つの原因から連鎖している。**1 件目を直せば残り 3 件も通る見込みが高い。**

#### 直し方の候補

**どちらを採るかは、`method` が本来どこで入るはずだったかを確かめてから決める。**

「一覧の HTML を拡張版から作るようにする」という道もありうる。採らない。

章番号を付け替えたときに、それを探す処理が追従しなかったことが原因である。**同じことは今後も起こる。**

**この判断は実装のときに行う。** 語で探すと同名の見出しが複数ある場合に誤るため、現在のテンプレートに同名の見出しが無いことを先に確かめる。

# 要確認事項の記録先が存在しない問題を直す指示書

**状態**: 着手できる
**優先度**: 高
**前提**: なし
**元の指摘**: 1-223

## 1. この指示書は何か

設計書の様式が「確定できなかった事項は本書の要確認事項一覧へ記録する」と指示している。ところが、その節を持つ様式は1件も無い。指示された先が存在しない。指示の文を、実在する記録先へ向け直す。

## 2. なぜ必要か

実測（2026-08-24）:

- 「要確認事項一覧」へ記録するよう指示する箇所: **63箇所・25の様式**
- 「要確認事項一覧」という節（`## ` で始まる見出し）を持つ様式: **0件**

指示に従おうとした担当は、書く場所を探して見つからない。推測で節を作るか、記録そのものを諦めるかのどちらかになる。どちらも、確定できなかった事項が失われる。

改善課題1-223 は、要確認事項の節を全種別の様式から外し、確定できなかった事項は単位ごとの別資料（根拠を記録する資料）が持つ形へ改めることを定めた。節を外す作業は行われた。**外れたのは節だけで、その節を指す指示の文が残った。**

1-223 の検収は「テンプレート本文の『要確認事項一覧へ移す』の残存は0件」と記録している。この測り方は「移す」という語だけを探しており、「記録する」という語を見落としていた。検収の測り方が狭かったために、63箇所が残った。

## 3. やること

1. 走査して、「要確認事項一覧」を含む箇所を63箇所すべて洗い出す
2. 各箇所の文を、1-223 が定めた記録先へ向け直す。1-223 の定めは「確定できなかった事項は単位ごとの別資料（根拠を記録する資料）が持つ形へ改め、設計書はその所在を1文で示す」である
3. 書き換えの形は、当該様式が既に持つ「関連資料」の節が根拠を記録する資料の所在を示していることを前提に、「確定できなかった事項は根拠を記録する資料へ記録する」とする
4. HTMLコメント（`<!-- ... -->`）の中にある指示文も対象に含める。書き手が読む指示であり、実際の記録先を指す必要がある
5. 完了の判定1・2に使う `docs/scripts/check-confirmation-target.sh` を新設する。判定の式に縦棒（`|`）が入るため、指示書の表へ直接書けない

## 4. 完了の判定

1. `grep -rn '要確認事項一覧' delivery-payload/templates/リバース検証/ | wc -l` が 0 を返す
2. `grep -rn '要確認事項' delivery-payload/templates/リバース検証/ | grep -v '根拠を記録する資料' | wc -l` が 0 を返す
3. `bash generation-engine/scripts/tests/check-design-doc-section-consistency.sh --self-test` が終了コード0を返す
4. `bash docs/scripts/check-sample-placeholders.sh` が終了コード0を返す
5. `bash .claude/rules/always/tasks/instruction-format/check-instruction-format.sh` が終了コード0を返す

## 5. 触らない範囲

- 様式の節（`## ` の見出し）を増減しない。指示の文だけを直す
- 生成済みの見本（`generation-engine/samples/`）を変更しない。様式を直した結果として見本の再生成が要る場合は、別の作業として扱う
- 改善課題1-223 の記録を書き換えない

## 6. 決めていないこと

| 何を決めるか | 既定（迷ったらこれを選ぶ） | 覆すときの条件 |
|---|---|---|
| 節を新設するか指示を向け直すか | 指示を向け直す。1-223 が「節を外す」と決めており、それを覆さない | 納品先から「未確定の事項を設計書の中に置きたい」という判断が新たに示された場合 |
| 記録先の呼び名 | 「根拠を記録する資料」。1-223 と1-199 が使う呼び名に揃える | 1-199 が別の呼び名を確定させた場合はそちらに従う |
| 63箇所を一度に直すか | 一度に直す。同じ書き換えであり、分けると様式ごとに表現が食い違う | なし |

## 7. 他の指示書との関係

改善課題1-223 の積み残しである。1-199（根拠を記録する資料の様式と置き場）が記録先の実体を定める。本指示書は指示の文が実在する先を指すことだけを扱い、記録先の様式そのものは扱わない。

## 8. この指示書の位置づけ

節を外す作業と、その節を指す文を直す作業は別物である。前者だけを終えて後者を残すと、様式は「存在しない場所へ書け」と指示し続ける。検収の測り方が狭いと、この取り残しに気づけない。

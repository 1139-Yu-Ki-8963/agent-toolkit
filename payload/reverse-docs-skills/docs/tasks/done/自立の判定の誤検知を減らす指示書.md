## やること

1. **本物の違反を直す。** `build-rule-proposal.sh` の L89 が呼ぶ外部スクリプトへの依存を外す。外せない場合は、その依存が無いときに機能を落として動く形にする。`RUNBOOK.md` の記述も実態に合わせる

2. **検査器自身を対象から外す。** `generation-engine/scripts/tests/` 配下と `generation-engine/scripts/verification/` 配下のうち、名前が `check-` または `test-` で始まるファイルを走査の対象から外す。これらは検出パターンと自己テストのケースを持たないと動かない

3. **説明文中の言及を対象から外す。** 走査の対象をスクリプトが実際に実行する記述に絞る。次のいずれかに当たる行は対象から外す
   - 行頭から数えて `#` で始まるコメント行
   - Markdown の表の行（行頭が `|`）
   - HTML の本文（`.html` ファイル全体）
   - Markdown の見出し行（行頭が `#` に続く空白）

4. **除外の理由を書き残す。** 何をなぜ対象から外したかを `check-self-contained.sh` の冒頭コメントへ書く。理由が無いと、次に書き換える人が除外を消す

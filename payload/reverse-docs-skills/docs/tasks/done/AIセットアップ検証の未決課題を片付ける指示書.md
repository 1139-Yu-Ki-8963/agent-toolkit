## この指示書は何か

2026-08-11 の AI セットアップ検証（記録は `docs/tasks/work-records/AIセットアップ検証台帳.md`）で見つかった問題のうち、`docs/ledgers/検証で見つかった改修課題.md` に記録されていた未完了6件（未着手1件・見送り5件）を追跡する。台帳の廃止に伴い本指示書へ引き継ぐ。

## なぜ必要か

運転規約の「本リポジトリへの書き込みは一切禁止」という記述が、配布物を受け取る実行側に向けたものか、リポジトリ自身を改善する側にも及ぶのかが明示されていない。2026-08-11 の改修作業でこの区別の判断が必要になった実績があり、放置すると同じ判断を毎回やり直すことになる。残る5件はいずれも仕組みの性質上ゼロにはできない、または実装方式の限界として見送りが既に決まっているが、決定の理由と緩和策を記録として保存しないと、後から同じ論点が再燃したときに過去の検討が失われる。

# 共通シェルの配色と表示を正す指示書

**状態**: 着手できる
**優先度**: 中
**前提**: なし
**元の指摘**: 1-35, 1-49, 1-50

## この指示書は何か

ポータル共通シェル（`delivery-payload/templates/tokens.css`・`delivery-payload/templates/partials/shell-sidebar.html`・`generation-engine/scripts/shell-injection.sh`）が抱える3件の表示上の欠陥（対象: `docs/ledgers/改善課題タスク一覧.md` の 1-49・1-50・1-35）を追跡する。いずれも台帳の記録では「解消」と報告済みだが、台帳の廃止に伴い本指示書へ引き継ぐ。

## なぜ必要か

バッジと補助文字の配色が一般的な可読性の基準（コントラスト比4.5対1）を下回るページが実測された。横スクロールする表のうち一部の様式にだけ続きがあることを示す視覚的な手がかりが無い。パンくずの中カテゴリが固定文字列で、実際のページの所属カテゴリと一致しない。いずれも共通シェルの1か所の欠陥が全ページへ波及する性質を持つ。

## やること

### 1-49. バッジと補助文字の配色が可読性の基準を下回る

**現象（実測事実）**: 実ブラウザで描画し、透過色を実際の背景と合成したうえでコントラスト比を算出した。一覧のバッジ3種が3.61対1・3.64対1・4.36対1、共通のサイドバーの文字が2.05〜4.14対1で、いずれも一般的な可読性の基準（4.5対1）を下回る。一覧の全50行と、7ページのサイドバーで再現した。配色は共通の配色定義から来ており、個別のページの問題ではなく定義側の問題である。

**修正内容**: 該当する配色の組み合わせについて、文字色または背景色を調整し、基準を満たす比を確保する。調整は共通の配色定義で行い、個別のページで上書きしない。

**検収方法**: 生成物を実ブラウザで描画し、バッジとサイドバーの文字について、透過色を合成した実効の背景色でコントラスト比を算出して4.5対1以上であること。明るい配色と暗い配色の両方で確認すること。

**完了条件**: 該当箇所の配色の是正までを本項目の範囲とする。配色体系全体の見直しは範囲外。

### 1-50. 横スクロールする表の視覚的な手がかりが、様式によって有る無しに分かれる

**現象（実測事実）**: 対応表の1つを狭い幅で開くと、34列のうち約6列しか見えず、横に続きがあることを示す手がかりが無い。実測では表示幅866に対し内容の幅が2782で、3倍以上が画面外にある。一方、他の様式では続きがあることを示す仕組みが実装済みで、実ブラウザで切り替わることを確認した。同じ役割の部品が2種類あり、片方にしか手がかりが無い。

**修正内容**: 横スクロールする表の部品を1つに統一する。統一が難しい場合は、手がかりの仕組みを実装済みの側から移植する。

**検収方法**: 列数の多い表を狭い幅で描画し、続きがあることを示す手がかりが現れること。すべて表示できる幅では現れないこと。対応表と一覧の両方の様式で確認すること。

**完了条件**: 手がかりの有無の統一までを本項目の範囲とする。表の列幅の算出方式と固定表示の変更は範囲外。

### 1-35. パンくずの中カテゴリが固定文字列で、ページの所属と一致しない（4回目の指摘）

**現象（実測事実）**: パンくずの中間に表示するカテゴリ名が、すべてのページで同一の固定文字列になっている。同じページが所属カテゴリを表す属性を正しく持っているにもかかわらず、パンくずだけが別の固定値を使う。実測では該当する109枚すべてが同じ表記だった。

**修正内容**: パンくずのカテゴリ名を、ページが持つ所属カテゴリの属性から引く。

**検収方法**: 異なるカテゴリに属する複数のページを生成し、それぞれのパンくずが自身のカテゴリ名を表示すること。

**完了条件**: パンくずのカテゴリ名の参照先の是正までを本項目の範囲とする。パンくずの構成要素の増減は範囲外。

## 完了の判定

1. 生成物を実ブラウザで描画し、バッジとサイドバーの文字について、透過色を合成した実効の背景色でコントラスト比が明るい配色・暗い配色の両方で4.5対1以上になる
2. 列数の多い表を狭い幅で描画すると続きがあることを示す手がかりが現れ、すべて表示できる幅では現れないことを対応表と一覧の両方の様式で確認できる
3. 異なるカテゴリに属する複数のページを生成し、それぞれのパンくずが自身のカテゴリ名を表示する

## 触らない範囲

- 配色体系全体の見直し
- 表の列幅の算出方式と固定表示の変更
- パンくずの構成要素の増減

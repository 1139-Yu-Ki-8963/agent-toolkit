# この場所について

**状態**: 着手できる
**優先度**: 中
**前提**: なし
**元の指摘**: なし

`docs/tasks/` に置かれた指示書のうち、片付いたと機械で確かめられたものを退避する場所である。この説明ファイル自身は指示書ではないため、元の指摘は無い。ここにある指示書は、記録・統合・公開の3条件をすべて満たした状態で移された。読み返す必要が生じたときの参照先として残す。この説明ファイル自身は指示書ではなく、フォルダの説明としてこの場所に置く例外である。

## 3条件の定義がどこにあるか

判定の3条件（記録が済んでいる・main へ入っている・公開が済んでいる）の定義は `docs/design/指示書の片付け方.md` に書く。実際に判定する処理は `docs/scripts/judge-task-done.sh` が持つ。両者がずれた場合はスクリプトの実装を正とする。

## ここが走査に入らない理由

片付き判定を担う `docs/scripts/judge-task-done.sh` は `docs/tasks/*.md` だけを走査する。この glob パターンは非再帰であり、`docs/tasks/done/` 配下のファイルには一致しない。したがって、この場所に置いたファイルが誤って再判定されたり、誤って別の場所へ二重に移されたりすることはない。

## 書き足しが必要になったら

ここへ移した指示書に追記が必要になった場合、この場所のファイルを直接書き換えてはならない。`docs/tasks/` へ戻してから書き足すこと。戻さずに書き換えると、退避場所に「現在進行中の記録」が混在し、この場所が持つ「片付いた」という意味が崩れる。

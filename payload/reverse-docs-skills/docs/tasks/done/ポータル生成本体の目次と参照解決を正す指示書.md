# ポータル生成本体の目次と参照解決を正す指示書

**状態**: 着手できる
**優先度**: 高
**前提**: なし
**元の指摘**: 1-29, 1-31, 1-41

## この指示書は何か

ポータル生成本体（`generation-engine/scripts/build-portal.sh`）が抱える3件の欠陥（対象: `docs/ledgers/改善課題タスク一覧.md` の 1-31・1-29・1-41）を追跡する。いずれも台帳の記録では「解消」と報告済みだが、台帳の廃止に伴い本指示書へ引き継ぐ。

## なぜ必要か

目次生成処理が存在しない要素を参照して例外になり、全ページで章立ての装飾と目次が機能しない欠陥が実測された（章立ての装飾が最初の1つ以降で適用されないという形で現れる）。実ブラウザ検証のテストが自己テストへ配線されておらず、機械検証の対象から漏れていた。本文中の資料参照が対象リポジトリのソースツリー上の名前のままで、ポータル内の資料へ解決されない箇所があった。いずれもポータルの基本機能（ナビゲーション・回帰検知・参照の到達性）に関わる。

## やること

### 1-31. 目次生成が存在しない要素を参照して例外になり、章立てとサイドバー目次が機能しない

**現象（実測事実）**: 文書ページの目次生成処理が特定の識別子を持つ要素を取得して子要素を追加するが、その識別子を持つ要素はどのページにも存在しない。機械検索では当該処理を含むページが109件ある一方、対象の識別子を持つページは0件である。描画を再現して確認したところ、全ページで例外が発生し、章立ての生成が1件目で止まり、サイドバーの目次は常に空になる。以前サイドバーへ統合した際の取り残しであることが、様式定義に残るコメントから読み取れる。

**修正内容**: 目次の差し込み先を現行のサイドバーの要素へ合わせる。対象の要素が存在しない場合は例外にせず、目次の生成を飛ばして本文の描画を続ける。

**検収方法（改訂）**: 見出しを複数持つ文書を生成し、実ブラウザで開いて次をいずれも満たすこと。1. コンソールに例外が出ないこと 2. すべての見出しに章立ての装飾が適用されること（見出しの数と装飾済みの数が一致すること） 3. 目次の項目数が見出しの数と一致すること

**完了条件**: 目次の差し込み先の是正と、要素が無い場合の退避までを本項目の範囲とする。目次の見た目と階層表現の変更は範囲外。

### 1-29. 実ブラウザ検証のテストが自己テストへ配線されておらず、個別実行でしか走らない（3回目の指摘）

**現象（実測事実）**: 実ブラウザを操作して描画と操作を検証するテストが2本存在し、いずれも個別に実行すれば成功する。しかしポータル生成スクリプトの自己テストからは呼ばれておらず、機械検索でも参照が見つからない。自己テストを実行しても、この2本は一度も走らない。横断検収条件が求める「全てのスクリプトの自己テストが成功すること」を、この2本の結果を含めた形では確認できない。あわせて、これらのテストは実行基盤の追加指定が無いと起動時に例外で落ちる。指定の要否がテスト側にも説明書にも書かれておらず、実行者が原因を追いにくい。

**修正内容**: 2本のテストを自己テストの実行対象へ加える。実行基盤の追加指定が要る場合は、テスト自身が指定を補うか、必要な指定を実行時のエラーメッセージで案内する。

**検収方法**: ポータル生成スクリプトの自己テストを追加指定なしで実行し、当該2本が実行され終了コード0になること。実行されたケース数が修正前より増えていること。

**完了条件**: 2本の配線と実行基盤の指定の扱いまでを本項目の範囲とする。テストが検証する機能そのものの是正は範囲外。

### 1-41. 本文中の資料参照が対象リポジトリのツリー表記のままで、ポータル内の資料へ解決されない（4回目の指摘）

**現象（実測事実）**: 設計文書の「関連資料」節に書かれた他資料への参照が、対象リポジトリのソースツリー上の名前のまま出力される。ポータル上の資料は日本語の表題で生成されているため、参照どおりの名前のファイルはポータル内に存在しない。

**修正内容**: 本文中の参照が変換対象の文書を指す場合、ポータル上の生成先の名前と位置へ置き換える。ソースツリー上の名前と生成後の表題の対応は、生成時に把握している情報から引く。対応が取れない参照は書き換えず、そのまま残す。

**検収方法**: 関連資料の参照を持つ設計文書を生成し、参照先がポータル内の実在するページを指すこと。対応の取れない参照が書き換えられずに残ること。

**完了条件**: 変換対象の文書への参照の名前解決までを本項目の範囲とする。参照先が存在しない場合の警告の出力は範囲外。

## 完了の判定

1. 見出しを複数持つ文書を実ブラウザで開き、コンソールに例外が出ず、見出しの数と章立ての装飾が適用された数が一致し、目次の項目数も見出しの数と一致する
2. ポータル生成スクリプトの自己テストを追加指定なしで実行し、実ブラウザ検証の2本が実行されて終了コード0になり、実行ケース数が修正前より増えている
3. 関連資料の参照を持つ設計文書を生成し、参照先がポータル内の実在するページを指す。対応の取れない参照は書き換えられずに残る

# 一覧の遷移導線と出力配置の集計を正す指示書

**状態**: 着手できる
**優先度**: 中
**前提**: なし
**元の指摘**: 1-36, 1-46

## この指示書は何か

一覧生成の様式（`unit-list-template.html`・`screen-list-template.html`・`feature-list-template.html`）と出力配置の集計（`output-layout.sh`・`portal-catalog.mjs`）が抱える2件の欠陥（対象: `docs/ledgers/改善課題タスク一覧.md` の 1-36・1-46）を追跡する。いずれも台帳の記録では「解消」と報告済みだが、台帳の廃止に伴い本指示書へ引き継ぐ。

## なぜ必要か

一覧ページの行をクリックしても対応する個別ページへ遷移できない欠陥が実測された（個別ページが49件・18件生成されているにもかかわらず参照が0件）。出力レイアウトの定義で規約と共通文書の置き場を既定から変更して生成すると、サイドバーのカテゴリ件数が0件になる欠陥も実測された。いずれも読み手のナビゲーション体験に直結する。

## やること

### 1-36. 一覧の行から個別ページへ遷移できない（4回目の指摘）

**現象（実測事実）**: 一覧ページの行をクリックしてもページ内で詳細が開くだけで、対応する個別ページへは遷移しない。実測では、個別ページが49件・18件それぞれ生成されているにもかかわらず、ポータル全体を走査しても一覧から個別ページへの参照が0件だった。

**修正内容**: 一覧の各行に、対応する個別ページへの遷移を設ける。対応する個別ページが存在しない行は遷移させない。

**検収方法**: 個別ページを持つ一覧を生成し、各行から対応する個別ページへ遷移できること。個別ページを持たない行に遷移が設けられないこと。

**完了条件**: 一覧から個別ページへの導線の追加までを本項目の範囲とする。一覧の列構成と並び順の変更は範囲外。

### 1-46. カスタムの出力レイアウトを与えるとカテゴリの件数が0件になる（4回目の指摘）

**現象（実測事実）**: 出力レイアウトの定義で規約と共通文書の置き場を既定から変更して生成すると、ページ自体は正しく生成されるにもかかわらず、サイドバーのカテゴリ件数が0件になる。生成物の中身は正しく、件数の表示だけが0になる。既定のレイアウトで使う限り現れないため、置き場を変えた構成でのみ表面化する。

**修正内容**: カテゴリの件数を数える処理が、出力レイアウトの定義による置き場の上書きを参照するようにする。

**検収方法**: 既定と異なる置き場を指定した出力レイアウトで生成し、サイドバーのカテゴリ件数が生成されたページ数と一致すること。既定のレイアウトでの件数が変わらないこと。

**完了条件**: 件数の算出における置き場の参照までを本項目の範囲とする。レイアウト定義で上書きできる項目の追加は範囲外。

## 完了の判定

1. 個別ページを持つ一覧を生成し、各行から対応する個別ページへ遷移できる。個別ページを持たない行には遷移が設けられない
2. 既定と異なる置き場を指定した出力レイアウトで生成し、サイドバーのカテゴリ件数が生成されたページ数と一致する。既定のレイアウトでの件数は変わらない

## 触らない範囲

- レイアウト定義で上書きできる項目の追加

2件はいずれも「一覧・カタログ層でページ間の参照や件数の算出が正しく行われない」という同一系統の欠陥である。ファイルは異なるが影響範囲が「一覧まわりの表示の正確さ」という同じ関心事に閉じるため、1つの指示書にまとめた。

# 確かめる手段の終了コード2を判定不能とコマンドエラーに区別する指示書

**状態**: 着手できる
**優先度**: 高
**前提**: `docs/tasks/終了コード2に実行環境の制約とコマンド自身のエラーが衝突する問題を記録する指示書.md`
**元の指摘**: なし

## この指示書は何か

確かめる手段の終了コード2を、判定不能とコマンド自身のエラーに区別して実装する。

## なぜ必要か

終了コード2だけでは、実行環境の制約とコマンド自身のエラーを区別できない。
判定器自身の失敗も、確かめる手段の終了結果と分けて扱う必要がある。

## やること

1. `docs/scripts/judge-task-done.sh`の`run_confirm_command`を変更する。
2. 同スクリプトの`judge_measurement`を変更する。
3. 判定器由来と確かめる手段由来を別の内部状態で保持する。
   初出の内部値は`runner`（判定器由来）と`command`（確かめる手段由来）である。
4. 判定器由来の失敗を判定不能にする。
   外部出力には、行頭`[UNKNOWN]`、失敗した操作名、想定原因を含める。
5. 確かめる手段由来の終了コード2は、結合出力の行頭（先頭空白を許可）にある
   `[UNKNOWN]`ラベルで区別する。
   ラベルがあれば判定不能にし、無ければ不合格にする。
6. `out_file`用`mktemp`だけを失敗させる注入口を追加する。
   出力ファイル作成を`create_confirm_output_file`のような専用関数へ分離する。
   `JUDGE_TASK_DONE_TEST_CONFIRM_MKTEMP_FAIL=1`のときだけ専用関数を失敗させる。
   自己テスト自身の一時ディレクトリ作成後に、この変数を子実行へ渡す。
7. 次の6件を既存の自己テストへ追加する。
   判定器の`out_file`用`mktemp`失敗。
   確かめる手段の`exit 2 + 先頭空白可[UNKNOWN]`。
   確かめる手段の`exit 2 + ラベルなし`。
   無関係な文中に`[UNKNOWN]`を含む確かめる手段の`exit 2`。
   `--write`でラベルなしは未着手になり、ラベルありは未確認を維持するケース。
   引数なし全件一覧が判定不能を含んでも完走し、報告成功時に終了コード0になるケース。
8. 既存ケース20と21の期待値を新しい契約へ更新する。
9. `--only`で対象が判定不能なら、行頭`[UNKNOWN]`を出して終了コード2にする。
10. 引数なし全件一覧は対象ごとに判定不能を明示し、一覧生成を完走させる。
    報告処理が成功した場合は終了コード0にする。

## 完了の判定

1. 判定器由来、ラベルあり、ラベルなしの3分岐が実装されている。
2. 判定器由来の失敗が必要な内容を外部へ出力し、`--only`が終了コード2になる。
3. 6件の回帰テストがすべて合格する。
4. `--write`の状態遷移が新しい契約どおりになる。
5. 引数なし全件一覧が判定不能を含んでも完走し、報告成功時に終了コード0になる。
6. `bash docs/scripts/judge-task-done.sh --self-test`が全件合格する。

## 決めていないこと

| 何を決めるか | 既定（迷ったらこれを選ぶ） | 覆すときの条件 |
|---|---|---|
| 内部状態名 | `CONFIRM_ORIGIN=runner`と`CONFIRM_ORIGIN=command`を使う。内部値`runner`は判定器由来、内部値`command`は確かめる手段由来とする。 | 既存の命名規則や実装構造と衝突する場合。 |
| 行頭ラベルの判定 | 先頭空白を許可し、直後のコードブロックを使う。 | 判定不能規約のラベル書式が変わる場合。 |
| 判定器失敗時の出力 | 行頭`[UNKNOWN]`、失敗した操作名、サンドボックスなどの想定原因を出す。 | 判定不能規約の必須項目が変わる場合。 |
| 集約全体の終了コード | `--only`で対象が判定不能なら終了コード2にする。引数なし全件一覧は個別の判定不能を明示して完走する。報告処理が成功した場合は終了コード0にする。 | 呼び出し側が別の終了コード契約を必要とする場合。 |
| `mktemp`失敗の注入口 | 出力ファイル作成を`create_confirm_output_file`のような専用関数へ分離する。自己テスト用環境変数は`JUDGE_TASK_DONE_TEST_CONFIRM_MKTEMP_FAIL=1`とする。自己テスト自身の一時ディレクトリ作成後に子実行へ渡す。 | 既存の命名と衝突する場合は、専用関数と環境変数の名前を変更できる。 |
| 回帰テストの置き場 | 既存の自己テストへ追加する。 | 既存の自己テストでは依存注入ができない場合。 |

行頭ラベルの判定には、次の正規表現を使う。

```bash
grep -qE '^[[:space:]]*\[UNKNOWN\]([[:space:]]|$)'
```

判定不能規約は`[UNKNOWN]`ラベルを要求する。
先頭空白の許可は既存出力との互換方針である。

`--only`は対象1件の結果を呼び出し元へ返すため、判定不能なら終了コード2にする。
引数なし全件一覧は、複数タスクを一度に報告するため、一覧生成を完走させる。

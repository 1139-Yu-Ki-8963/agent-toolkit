# リバース検証の実行記録

この文書は、リバース検証ループを実行するたびに 1 節を追記する台帳である。過去の節は書き換えない。前回との比較のため、古い結果もそのまま残す。

追記は `generation-engine/scripts/verification/record-verification-result.sh` が行う。`## 記録` の見出し直後へ新しい節を差し込むため、新しい記録ほど上に来る。

## 記録の形式

1 回分の記録には、次の項目を含める。省略した項目は「未実行」と記録する。

| 項目 | 内容 |
|---|---|
| 版 | 検証した時点のコミットハッシュを全長で記す。短縮形は使わない |
| 第 1 層 | 対象・成功・失敗・判定不能・途中停止の疑い・打ち切り・宣言済み長時間・総ケース数の集計行 |
| 第 3 層 | 段の総数・成功・失敗・スキップ・生成ファイル数の集計行 |
| 網羅 | 分母・存在・欠落の集計行 |
| 自立 | 対象・適合・違反の集計行 |
| 再現 | 対象・一致・相違・片側のみの集計行 |
| 健全 | 検査器の本数・成功・失敗・判定不能の集計行 |

版の記録について、`docs/design/reverse-verification/設計.md`「検証したスキルの版の記録」が定めるとおり、コミットハッシュを全長で必ず含める。後戻りが起きたときにどの版で合格したのかを辿るためである。

## 本書が検証するもの

結合は2段に分けて定義します。1つの設計単位の中で構成要素が結合した状態を内部結合、複数の設計単位をまたぐ連携を外部結合と呼びます。単位ごとの文書は内部結合までを担い、プロジェクト全体の文書が外部結合を担います。

| 段 | 検証する状態 | 対応する設計書 | 文書 |
|---|---|---|---|
| 単体 | 1つの関数・メソッドの入出力 | 機能設計書 | 機能単体テスト設計書 |
| 内部結合 | 1つの機能の中で関数・メソッドが結合した状態（外部の振る舞い） | 機能設計書 | 機能結合テスト設計書（本書） |
| 外部結合 | 複数の画面・機能・APIをまたぐ連携 | 複数の設計書 | docs/test-cases/結合テスト仕様書.md |

## テスト対象

| 対象 | 確認する内容 | 根拠となる機能設計書の章 |
|---|---|---|
| コード行数計測の一連の流れ | target_dir 確認 → 計測方式決定 → 行数計測 → FE/BE分離 → テスト計測 → code-metrics.json 出力が意図した順序で完走すること | §3 業務フロー |
| 未分類率の警告 | 未分類ファイル数の比率が0.5を超えたときに警告フラグが立つこと | §4 業務ルール、§8 エラーと業務メッセージ |
| 再計測時のprevious記録 | 既存code-metrics.jsonがある場合、previousへ前回値が転記されること | §5 データ |

## テストの粒度と自動化の方針

| 項目 | 方針 |
|---|---|
| テストの粒度 | 1ケースで確認する振る舞いを記入する。 |
| 自動化 | `generation-engine/scripts/validate-code-metrics.sh` による自動検証が可能。手動確認は不要。 |

## §1 テスト観点

**この節の位置づけ: 仕様**

観点は機能設計書の業務フロー・業務ルール・エラーと業務メッセージの各章から起こす。

| キー | 観点 | 由来する機能設計書の章 |
|---|---|---|
| 正常計測完了 | target_dirが実在するとき、Phase1〜6が完走しcode-metrics.jsonが出力される | §3.1 正常系フロー |
| env設定なし分岐 | env_configが存在しないとき、tools.cloc=falseとみなしwc -l方式で進む | §3.2 分岐と例外フロー |
| 未分類率警告 | 未分類ファイル数の比率が0.5を超えたときunclassified.warningがtrueになる | §3.2 分岐と例外フロー、§4.3 計算規則 |
| テスト検出失敗の区別 | 既定パターンで0件かつテストランナー設定・テストディレクトリも不在のとき、testDetectionFailedがfalseのまま区別される | §3.2 分岐と例外フロー |
| target_dir不在エラー | target_dirが実在しないとき、エラー終了し計測を行わない | §8.1 業務エラー一覧 |
| previous転記 | 既存code-metrics.jsonがあるとき、total・tests.count・measured_atがpreviousへ転記される | §5.3 ライフサイクル |

## §2 テストケース一覧

**この節の位置づけ: 仕様**

| キー | 番号 | ケースの名前 | 対応する観点のキー | 区分 |

## §3 入力条件

**この節の位置づけ: 仕様**

| ケースのキー | 入力の項目 | 値 |
|---|---|---|
| 正常計測完了 | target_dir | 実在するディレクトリ |
| env設定なし分岐 | env_config | 未指定（ファイル不在） |
| 未分類率警告 | target_dir配下のファイル構成 | FE/BEいずれのパスパターンにも一致しないファイルが過半数 |
| テスト検出失敗の区別 | target_dir配下 | テストファイル・テストランナー設定・テストディレクトリがいずれも不在 |
| target_dir不在エラー | target_dir | 実在しないパス |
| previous転記 | output_dir配下 | 前回計測済みのcode-metrics.jsonが存在する |

## §4 期待結果

**この節の位置づけ: 仕様**

| ケースのキー | 期待する結果 | 確認の方法 |
|---|---|---|
| 正常計測完了 | code-metrics.jsonが出力され、total/fe/be/file_count/testsが数値で埋まる | validate-code-metrics.shの終了コードが0であることを確認する |
| env設定なし分岐 | methodが"wc"として記録される | code-metrics.jsonのmethodフィールドを確認する |
| 未分類率警告 | unclassified.warningがtrueになる | code-metrics.jsonのunclassified.warningを確認する |
| テスト検出失敗の区別 | testDetectionFailedがfalseのまま記録される | code-metrics.jsonのtestDetectionFailedを確認する |
| target_dir不在エラー | 計測を行わずエラー終了する | 実行結果の終了コードとcode-metrics.json未生成を確認する |
| previous転記 | previous.total・previous.tests_count・previous.measured_atに前回値が入る | code-metrics.jsonのpreviousオブジェクトを確認する |

## §7 網羅基準

**この節の位置づけ: 仕様**

| 観点 | 基準 |
|---|---|
| 条件の網羅 | env_configの有無、未分類率の閾値（0.5）、テスト検出の有無をそれぞれ1件以上のケースで確認する |

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | test-aggregation |
| 機能ID | feat-test-aggregation |
| 大分類 | 生成 |
| 業務対象 | 各設計単位のテスト設計書を横断して集め、テストケース一覧・テスト観点表・結合テスト仕様書を作成します。 |
| 確からしさ | high |
| 判定根拠 | 構成要素スキル3件（generating-test-case-list-for-reverse-docs・generating-test-viewpoint-list-for-reverse-docs・generating-integration-test-spec-for-reverse-docs）のSKILL.mdが、いずれも各設計単位のテスト設計書を横断集約するtransform型スキルであることが一致する |
| 境界の決定元 | build-target（4カテゴリ・17機能モデルにおける「リバースカテゴリ」の集約単位。3つのClaude Codeスキルのディレクトリを1機能へ統合） |

### 1.2 業務上の位置づけ

主体: このツール自身（リバース設計フローの生成担当AIエージェント）です。入力→出力は「各設計単位のテスト設計書 → テストケース一覧・テスト観点表・結合テスト仕様書」です。3つの構成要素はいずれも判定・評価をせず、既に確定した各設計単位のテスト設計書（機能単体テスト設計書・機能結合テスト設計書等）に記載された事実の転記・集約に徹します。テストケース一覧と観点表は`build-unit-list.sh`の派生一覧エンジンへ同じ流儀で乗り、結合テスト仕様書は複数の設計単位をまたぐ連携だけをプロジェクト全体で1冊にまとめます。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの生成担当（AI エージェント） | 本機能を起動し、テストケース一覧.html・テスト観点表.html・結合テスト仕様書.md を得る | `.claude/skills/generating-test-case-list-for-reverse-docs/SKILL.md`、`.claude/skills/generating-test-viewpoint-list-for-reverse-docs/SKILL.md`、`.claude/skills/generating-integration-test-spec-for-reverse-docs/SKILL.md` |

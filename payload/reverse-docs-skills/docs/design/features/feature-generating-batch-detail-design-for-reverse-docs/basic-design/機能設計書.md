# バッチの詳細設計書を作る 機能設計書

**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: §1 機能概要、§2 機能の範囲、§3 業務フロー、§4 業務ルール、§5 データ、§6 構成要素間の状態受け渡し。§7 呼び出し仕様、§8 エラーと業務メッセージ、§9 非機能、§10 共通仕様への準拠、§11 関連資料
- 現行実装: 該当なし
- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-batch-detail-design-for-reverse-docs |
| 機能ID | feat-generating-batch-detail-design-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | バッチ1本ごとに、元の処理の定義を読み解いてバッチ詳細設計書・バッチ実装記録を作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-batch-detail-design-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

バッチ一覧マニフェストと原本コードから、処理の流れ・コミットの単位・排他の制御・リトライ・件数と実行時間の目安を読み解き、詳細設計書へ書き起こします。対象コードのファイルパス・行番号は本文・別資料のいずれにも記録せず、参照先は文書内の節番号または関数単位の契約に限定します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | バッチ一覧が生成済みの状態で、ジョブ単位の詳細設計書・実装記録を作る | .claude/skills/generating-batch-detail-design-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | 4引数の実在、マニフェストの確認、対象ユニットの確定を行う | Phase 2 へ |
| 2 | 進行担当 | 本機能（Phase 2） | 原本コードから処理の流れ・コミットの単位・排他の制御等を抽出し、マニフェストとの整合を確認する | Phase 3 へ |
| 3 | 進行担当 | scaffold-design-unit.sh／本機能（Phase 3） | テンプレートを配置し、コード位置を含めずに各章へ記入する | Phase 4 へ |
| 4 | 進行担当 | 本機能（Phase 4） | 5検査を実行する | 全検査合格でDONE。不合格ならPhase 3へ差し戻し（上限3回） |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| マニフェストとの食い違い | 原本から読み取った内容がschedule等と食い違う | 要確認事項一覧へ記録する | .claude/skills/generating-batch-detail-design-for-reverse-docs/SKILL.md Phase 2 |
| 検査不合格 | Phase 4の5検査のいずれかが不合格 | Phase 3へ差し戻し。3回目も収束しなければstatus=ERROR | .claude/skills/generating-batch-detail-design-for-reverse-docs/SKILL.md ループ設計 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 前提 | generating-batch-list-for-reverse-docs | batch-manifest.ext.json | .claude/skills/generating-batch-list-for-reverse-docs/SKILL.md |
| 姉妹 | generating-batch-basic-design-for-reverse-docs | バッチ基本設計書（業務上の目的） | .claude/skills/generating-batch-basic-design-for-reverse-docs/SKILL.md |

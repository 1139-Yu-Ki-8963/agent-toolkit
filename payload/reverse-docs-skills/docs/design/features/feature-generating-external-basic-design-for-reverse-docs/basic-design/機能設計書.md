本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-external-basic-design-for-reverse-docs |
| 機能ID | feat-generating-external-basic-design-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 外部連携1本ごとに、業務の言葉だけで基本設計書と外部連携結合テスト設計書・外部連携単体テスト設計書を作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-external-basic-design-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

外部連携一覧マニフェストと原本コードから、連携の方式・連携の契機・責任の分界点・正常時と異常時の応答・再送の可否を、業務語彙だけで基本設計書へ書き起こします。電文の項目の定義・変換の処理・タイムアウトといった実装の詳細は詳細設計書側が担い、本機能は扱いません。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 外部連携一覧が生成済みの状態で、外部連携1本ごとの基本設計書・外部連携結合テスト設計書・外部連携単体テスト設計書を作る | .claude/skills/generating-external-basic-design-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | 4引数の実在、マニフェストの確認、対象ユニットの確定を行う | Phase 2 へ |
| 2 | 進行担当 | 本機能（Phase 2） | 外部連携一覧マニフェストと原本コードから業務的な意味を抽出する | Phase 3 へ |
| 3 | 進行担当 | scaffold-design-unit.sh／本機能（Phase 3） | テンプレートを配置し、業務語彙のみで各章へ記入する | frontmatterがauthoredになれば Phase 4 へ |
| 4 | 進行担当 | 本機能（Phase 4） | 基本設計書だけを情報源に外部連携結合テスト設計書を、詳細設計書または入力資料の関数・メソッドを情報源に外部連携単体テスト設計書を執筆する | Phase 5 へ |
| 5 | 進行担当 | 本機能（Phase 5） | 機械検査を実行する | 全検査合格でDONE。不合格ならPhase 3またはPhase 4へ差し戻し（上限3回） |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 出力先の識別子が確定しない | unitIdもunitKeyも空 | status=ERRORで当該ユニットを生成しない | .claude/skills/generating-external-basic-design-for-reverse-docs/SKILL.md 成果物 |
| 対象関数なし | 外部連携単体テスト設計書の対象関数が無い | §1と§2に根拠付きで「該当なし」を記入する | .claude/skills/generating-external-basic-design-for-reverse-docs/SKILL.md Phase 4 |
| 検査不合格 | 機械検査のいずれかが不合格 | テスト設計書関連はPhase 4、それ以外はPhase 3へ差し戻し。3回目も収束しなければstatus=ERROR | .claude/skills/generating-external-basic-design-for-reverse-docs/SKILL.md ループ設計 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 前提 | generating-external-list-for-reverse-docs | 外部連携一覧マニフェスト | .claude/skills/generating-external-list-for-reverse-docs/SKILL.md |
| 後続 | generating-external-detail-design-for-reverse-docs | `外部連携基本設計書`（業務上の目的） | .claude/skills/generating-external-detail-design-for-reverse-docs/SKILL.md |

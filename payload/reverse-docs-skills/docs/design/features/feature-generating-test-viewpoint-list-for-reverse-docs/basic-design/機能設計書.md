## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-test-viewpoint-list-for-reverse-docs |
| 機能ID | feat-generating-test-viewpoint-list-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 各設計単位のテスト設計書（結合・単体）を横断集約し、テスト観点表.htmlを生成します。 |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェスト（docs/manifests/feature-manifest.json）の sourceFile と .claude/skills/generating-test-viewpoint-list-for-reverse-docs/SKILL.md の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

リバース設計フローの生成担当（AIエージェント）が、各設計単位のテスト設計書が1件以上確定した段階で、ポータルにテスト観点表カードを追加するために使う転記・集約系の機能です。観点の妥当性・網羅性は判定せず、由来章・観点文言の事実だけを転記します。テストケース一覧生成機能の姉妹機能であり、同じ派生一覧エンジンを使います。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの生成担当（AIエージェント） | 各設計単位のテスト設計書を横断集約し、テスト観点表.htmlを生成する | `.claude/skills/generating-test-viewpoint-list-for-reverse-docs/SKILL.md` |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 生成担当・aggregate-test-viewpoints | 本機能（Phase 1） | output-layoutの各UnitRootを走査し、テスト設計/にある2設計書（画面は新配置優先・旧観点表fallback）の実在を確認する | 1件以上存在すればPhase 2へ。全種別0件ならSTOPPEDで停止 |
| 2 | 生成担当・aggregate-test-viewpoints | 本機能（Phase 2） | manifest JSONを横断集約し、summaryの件数・種別内訳・画面内訳を確認する | 集約結果を確認できればPhase 3へ（0件でもエラーにしない） |
| 3 | validate-test-viewpoint-manifest | 本機能（Phase 3） | manifestの整合検証を行う | 全項目PASSならPhase 4へ。FAILなら修正し3回まで再実行、それでも失敗なら集約元の見直しへ |
| 4 | 生成担当・build-unit-list | 本機能（Phase 4） | build-unit-list.shでテスト観点表.htmlを生成し、portal_output_dir指定時はbuild-portal.shでポータルへ反映する | HTML生成完了で終了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| テスト設計書全種別不在 | 全種別で2テスト設計書が0件 | HTMLを生成せずstatus=STOPPEDで返却する | SKILL.md Phase 1 Step 2、返却ブロック |
| 確定行0件 | テスト設計書は存在するが集約結果が0件 | 空状態のページを生成しDONEを返す | SKILL.md Phase 4 Step 1、予想を裏切る挙動 |
| 検証3回失敗 | validate-test-viewpoint-manifest.shが3回連続でFAIL | 集約スクリプトの入力の見直しへ差し戻す | SKILL.md Phase 3 |
| portal_output_dir未指定 | ポータル再生成先が指定されない | build-portal.shの実行を省略し完了報告に注記する | SKILL.md Phase 4 Step 2 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 類似機能 | generating-test-case-list-for-reverse-docs | 同じ派生一覧エンジン（build-unit-list.sh）を使う姉妹機能。集約対象・観点は異なる | `docs/design/features/feature-generating-test-case-list-for-reverse-docs/basic-design/機能設計書.md` |

本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-entity-state-for-reverse-docs |
| 機能ID | feat-generating-entity-state-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | データ設計.md §6 状態遷移表をもとに、状態の移り変わりを示す状態遷移図.htmlを機械的に作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-entity-state-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

データ設計.md §6 状態遷移表（generating-reverse-common-docsが書き起こす）をエンティティの状態遷移の正とする。表の各行を機械的にnodes/edgesへ変換して状態遷移図.htmlを書き出します。判定・評価は一切行わず、表に記載のない状態遷移を推測・補完しません。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | データ設計.md §6 状態遷移表が確定済みの状態で、状態遷移図.htmlを作る | .claude/skills/generating-entity-state-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | データ設計.md §6 状態遷移表の実在とデータ行1件以上を確認する | 確認できればPhase 2へ、不在・0件なら停止する |
| 2 | 進行担当 | 本機能（Phase 2） | 表の全行をnodes[]・edges[]へ機械的に変換する | Phase 3 へ |
| 3 | 進行担当 | validate-page-data.sh | 孤児参照検査を含む整合を検証する | 全項目PASSでPhase 4へ |
| 4 | 進行担当 | build-detail-page.sh／build-portal.sh | 状態遷移図.htmlを生成し、portal_output_dir指定時はポータルを再生成する | 完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 状態遷移表不在・0件 | §6状態遷移表が未書き起こし、または行が1件もない | status=STOPPEDで停止する | .claude/skills/generating-entity-state-for-reverse-docs/SKILL.md 完了条件 |
| 整合検証不合格 | validate-page-data.shがFAILを返す | 修正して再実行。同一FAILが2回連続再発でnodes組み立てへ差し戻し | .claude/skills/generating-entity-state-for-reverse-docs/SKILL.md ループ設計 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 前提 | generating-reverse-common-docs（本リポジトリの18本には含まれない） | データ設計.md §6 状態遷移表 | .claude/skills/generating-entity-state-for-reverse-docs/SKILL.md 使用タイミング |

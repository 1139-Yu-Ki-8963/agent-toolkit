- 仕様: §1 機能概要、§2 機能の範囲、§3 業務フロー、§4 業務ルール、§5 データ、§6 構成要素間の状態受け渡し。§7 呼び出し仕様、§8 エラーと業務メッセージ、§9 非機能、§10 共通仕様への準拠、§11 関連資料

本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-api-detail-design-for-reverse-docs |
| 機能ID | feat-generating-api-detail-design-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 接続窓口（API）1本ごとに、原本コードからAPI詳細設計書・API実装記録・API単体テスト設計書を作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

API一覧マニフェストと原本コードだけを情報源とし、対象コードの位置（file:line）を納品物へ一切記録しない詳細設計書とAPI実装記録を作ります。原本を直接読み取る種類のため、往復検証（設計書だけからコードを再生成して原本と突き合わせる検証）の対象にはなりません。品質は8つの機械検査で担保します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | API一覧が生成済みの状態で、エンドポイント単位の詳細設計書・実装記録・単体テスト設計書を作る | .claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | 4引数の実在、マニフェストの確認、言語プロファイル（python/perl）の選択、対象ユニット（endpoint/dispatch-entry）の確定を行う | 対象確定後 Phase 2 へ |
| 2 | 進行担当 | build-implementation-contract-section.sh／本機能（Phase 2） | 実装契約を機械抽出し、抽出できなかった関数だけ原本を読解して補う | 本文材料が揃えば Phase 3 へ |
| 3 | 進行担当 | scaffold-design-unit.sh／本機能（Phase 3） | テンプレートを配置し、コード位置を含めずに各章へ記入する | Phase 4 へ |
| 4 | 進行担当 | 8つの機械検査 | 章の完備・記述規約・プレースホルダ・配置・設計判断・単体テスト粒度・配置・テンプレート一致を検査する | 全検査合格でDONE。不合格ならPhase 3へ差し戻し（上限3回） |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 該当プロファイルなし | files の拡張子がpython/perlどちらにも該当しない | status=ERROR。hintに拡張子の内訳を記録する | .claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md Phase 1 |
| 抽出割合が閾値未満 | implementationContractのreadableArguments/readableReturnsが80%を下回る | 原本読解で補う対象が多いことを示す | .claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md Step 2-1 |
| ディスパッチ表構成 | filesが入口モジュール1本のみでconfidenceが全件low | 中断せず、ディスパッチ表を解いて実装本体まで読む | .claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md 予想を裏切る挙動 |
| 検査不合格 | 8検査のいずれかが不合格 | Phase 3へ差し戻し。上限3回で収束しなければstatus=ERROR | .claude/skills/generating-api-detail-design-for-reverse-docs/SKILL.md Phase 4 |

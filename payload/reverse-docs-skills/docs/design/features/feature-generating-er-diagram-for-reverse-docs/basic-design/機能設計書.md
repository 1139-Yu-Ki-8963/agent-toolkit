## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-er-diagram-for-reverse-docs |
| 機能ID | feat-generating-er-diagram-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 表の一覧と参照関係の定義をもとに、表同士のつながりを表すER図.htmlを機械的に作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

テーブル一覧.htmlに埋め込まれたmanifest（unit_kind=table）をエンティティの正とする。対象リポジトリのマイグレーション/ORMモデル定義から外部キー（FK）を抽出してER図.htmlを書き出します。FKとして検出できた関連のみを転記し、manifestに存在しない参照先は捏造せずunresolved[]へ分離します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | テーブル一覧.htmlが確定済みの状態で、ER図.htmlを作る | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | テーブル一覧manifestの実在を確認し、検出戦略の承認を得る | 確認できればPhase 2へ、不在なら停止する |
| 2 | 進行担当 | 本機能（Phase 2） | entities[]をmanifestから確定し、columnsを付与、FK走査でrelations[]/unresolved[]へ振り分ける | entities[]が0件なら停止、それ以外はPhase 3へ |
| 3 | 進行担当 | validate-page-data.sh | 孤児関連検査を含む整合を検証する | 全項目PASSでPhase 4へ |
| 4 | 進行担当 | build-detail-page.sh／build-portal.sh | ER図.htmlを生成し、portal_output_dir指定時はポータルを再生成する | 完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| エンティティ0件 | テーブル一覧manifestのentities[]が0件 | status=STOPPEDで停止する | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md 設計原則 |
| FK0件 | 検出戦略に沿って走査してもFKが0件 | relations[]を空配列のまま進め、エンティティ一覧のみの俯瞰ページを生成する | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md 設計原則 |
| manifest外参照 | FKの参照先テーブルがmanifestのunits[]に存在しない | 関連として転記せずunresolved[]へ分離する | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md 設計原則 |
| 整合検証不合格 | validate-page-data.shがFAILを返す | 修正して再実行。同一FAILが2回連続再発でFK走査へ差し戻し | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md ループ設計 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 前提 | generating-table-list-for-reverse-docs（本リポジトリの18本には含まれない） | テーブル一覧.htmlに埋め込まれたmanifest | .claude/skills/generating-er-diagram-for-reverse-docs/SKILL.md 使用タイミング |

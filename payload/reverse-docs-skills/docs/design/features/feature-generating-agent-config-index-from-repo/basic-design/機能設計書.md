本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-agent-config-index-from-repo |
| 機能ID | feat-generating-agent-config-index-from-repo |
| 大分類 | 生成 |
| 業務対象 | 対象プロジェクトを調べ、AGENTS.md と CLAUDE.md の前半索引を実在証拠だけから作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-agent-config-index-from-repo/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

対象リポジトリを分析し、作業を担うエージェント向けの案内文書（AGENTS.md・CLAUDE.md）の前半索引を、README・依存定義・実行スクリプト等の実在証拠だけから作ります。AIの振る舞い・承認・委任・停止条件などの規約はコードから発明せず、規約定義が対象リポジトリに存在する場合だけ AGENTS.md の後半へ参照を残します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 対象リポジトリを分析し、AGENTS.md・CLAUDE.md の前半索引を新規生成または差分更新する | .claude/skills/generating-agent-config-index-from-repo/SKILL.md |

## §2 機能の範囲

**この節の位置づけ: 仕様**

### 2.1 構成要素一覧

| 構成要素キー | 種別 | 識別子 | 個別設計書 |
|---|---|---|---|
| build-derived-rules | バッチ（規約索引生成） | generation-engine/scripts/rules/build-derived-rules.sh | docs/design/batches/batch-rules/detail-design/バッチ詳細設計書.md |

本機能自身は AGENTS.md・CLAUDE.md の前半索引とテンプレート複製だけを担い、`RULES-INDEX` マーカー範囲の生成は build-derived-rules.sh に委ねます。

### 2.2 参照テーブル一覧

| テーブル | 作成 | 参照 | 更新 | 削除 | 参照先 |
|---|---|---|---|---|---|
| 該当なし | — | — | — | — | 本機能はデータベーステーブルを持ちません |

### 2.3 範囲外

規約本文の新規作成・既存規約の修正・個々の規約の意図や適用条件・承認件数などの規約索引本体は本機能の範囲外であり、build-derived-rules.sh が担います。

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | README・依存定義・ビルド設定・CI・実行スクリプト・主要ディレクトリを読み、根拠パス付きで前半索引の各項目を確定する | 未確認事項が推測で埋まっていなければ Phase 2 へ |
| 2 | 進行担当 | 本機能（Phase 2） | rules_root が指定されていれば実在と parent.yml の配置を確認し、RULES-INDEX マーカーを含むテンプレートをそのまま複製する | 個々の規約参照を書き込んでいなければ Phase 3 へ |
| 3 | 進行担当 | 本機能（Phase 3） | テンプレートへ事実を展開し、5つの検査を実行する | 全検査が成功すれば生成完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| rules_root未指定 | 対象リポジトリの規約定義の配置が未確認 | rules_root を設定せず、規約索引は不明事項として残す | .claude/skills/generating-agent-config-index-from-repo/SKILL.md 入力契約 |
| 検査不合格 | Phase 3 の5検査のいずれかが失敗する | 生成を確定せず、根拠不足として返す | .claude/skills/generating-agent-config-index-from-repo/SKILL.md Phase 3 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 呼び出し先 | build-derived-rules（バッチ設計単位。機能単位の登録なし） | RULES-INDEX マーカーを含むテンプレート | docs/design/batches/batch-rules/detail-design/バッチ詳細設計書.md |

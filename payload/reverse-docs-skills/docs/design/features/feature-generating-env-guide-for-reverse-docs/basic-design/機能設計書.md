# 環境構築の手順書を作る 機能設計書

**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: §1 機能概要、§2 機能の範囲、§3 業務フロー、§4 業務ルール、§5 データ、§6 構成要素間の状態受け渡し。§7 呼び出し仕様、§8 エラーと業務メッセージ、§9 非機能、§10 共通仕様への準拠、§11 関連資料
- 現行実装: 該当なし
- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-env-guide-for-reverse-docs |
| 機能ID | feat-generating-env-guide-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | アーキテクチャ調査書とローカル環境の調査結果をもとに、環境構築手順.htmlを機械的に作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-env-guide-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

アーキテクチャ調査書§3ビルドと起動の記載値を主データ源とする。任意でenv-config.json（surveying-local-environmentの出力）を突き合わせて環境構築手順.htmlを書き出します。起動手順の良否・簡潔さは判定せず、記載値をそのまま前提ツール・実行手順・割当の3表へ整理します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | アーキテクチャ調査書が確定済みの状態で、環境構築手順.htmlを作る | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | 調査書の実在を確認し、env-config.jsonの有無を確定する | 実在すればPhase 2へ、不在なら停止する |
| 2 | 進行担当 | 本機能（Phase 2） | prerequisites[]/environment[]/steps[]/allocations[]を確定し検証候補を保存する | Phase 3 へ |
| 3 | 進行担当 | validate-page-data.sh | 検証済みpage-dataを再生成用の正規配置へ保存する | 全項目PASSでPhase 4へ |
| 4 | 進行担当 | build-detail-page.sh／build-portal.sh | 環境構築手順.htmlを生成し、portal_output_dir指定時はポータルを再生成する | 完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 調査書不在 | アーキテクチャ調査書が実在しない | status=STOPPEDで停止する | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md 完了条件 |
| env-config.json不在 | env_config_pathが指定されないか実在しない | 無視して調査書§3だけで手順表・割当表を組み立てる | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md 設計原則 |
| allocations推測禁止 | 環境変数定義ファイルに割当を示す記載が無い | allocations[]を空配列のまま進める | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md 重要な注意事項 |
| 整合検証不合格 | validate-page-data.shがFAILを返す | 修正して再実行。同一FAILが2回連続再発でallocations抽出へ差し戻し | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md ループ設計 |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 前提 | surveying-architecture-for-reverse-docs（本リポジトリの18本には含まれない） | アーキテクチャ調査書§3 | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md いつ使わないか |
| 任意の前提 | surveying-local-environment（本リポジトリの18本には含まれない） | env-config.json | .claude/skills/generating-env-guide-for-reverse-docs/SKILL.md 使用タイミング |

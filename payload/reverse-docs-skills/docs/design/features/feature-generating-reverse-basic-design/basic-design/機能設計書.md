本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。本書が正を持つのは、構成要素をまたいで初めて意味を持つ事項だけです。

コードから確定できない事項は推測で埋めない。本書の空欄のままとする。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-reverse-basic-design |
| 機能ID | feat-generating-reverse-basic-design |
| 大分類 | 生成 |
| 業務対象 | 確定済みfacts（facts.yml）とプロジェクト共通文書だけを情報源に、業務語彙のみで書かれた画面基本設計書を著述します。 |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェスト（docs/manifests/feature-manifest.json）の sourceFile と .claude/skills/generating-reverse-basic-design/SKILL.md の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

確定済みfacts（facts.yml）とプロジェクト共通文書だけを情報源に、業務語彙のみで書かれた画面基本設計書を著述します。原本コードのReadは全面禁止です。詳細設計書の抽象化・要約ではなく独立した成果物です。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 本機能を起動し、画面基本設計書.md を得る | .claude/skills/generating-reverse-basic-design/SKILL.md |

## §2 機能の範囲

**この節の位置づけ: 仕様**

### 2.1 構成要素一覧

| 構成要素キー | 種別 | 識別子 | 個別設計書 |
|---|---|---|---|
| scaffold-screen等 | バッチ（生成エンジンスクリプト） | generation-engine/scripts/ | docs/design/batches/batch-root/detail-design/バッチ詳細設計書.md |

本機能自体は .claude/skills/generating-reverse-basic-design/SKILL.md に定義されている。この Phase/Step 手順として実行される Claude Code スキルです。cloc・find・git 等の対象プロジェクトが持つ汎用コマンド、および上表の生成エンジンスクリプトを呼び出す。起動引数は次のとおりです。facts_ref（封印済みfacts.yml）・common_docs_root。

### 2.3 範囲外

同じfactsを情報源とする執筆専任スキル facts.ymlの封印元詳細は §11 関連資料を参照する。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-reverse-common-docs |
| 機能ID | feat-generating-reverse-common-docs |
| 大分類 | 生成 |
| 業務対象 | アーキテクチャ調査書を前提に、対象リポジトリのコードから層化サンプリングで共通設計書・メッセージ定義書等のプロジェクト共通6文書のv0を書き起こします。 |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェスト（docs/manifests/feature-manifest.json）の sourceFile と .claude/skills/generating-reverse-common-docs/SKILL.md の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

アーキテクチャ調査書を前提に、対象リポジトリのコードから層化サンプリングで共通設計書・メッセージ定義書等のプロジェクト共通6文書のv0を書き起こします。対象リポジトリへは読み取り専用で動作します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 本機能を起動し、共通設計書.md・メッセージ定義書.md・DESIGN.md・基盤設計.md・UI共通設計.md・データ設計.md・サンプル記録.md を得る | .claude/skills/generating-reverse-common-docs/SKILL.md |

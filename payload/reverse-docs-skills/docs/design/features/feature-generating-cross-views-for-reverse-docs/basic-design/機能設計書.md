## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-cross-views-for-reverse-docs |
| 機能ID | feat-generating-cross-views-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 画面・接続窓口・データの一覧をもとに、権限や関係を示す対応表4ページとエージェント設定のページを合わせて5ページ作ること |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェストの sourceFile と `.claude/skills/generating-cross-views-for-reverse-docs/SKILL.md` の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

既に確立済みの種別別一覧（画面一覧・API一覧・テーブル一覧・機能一覧）のmanifestを突き合わせ、権限・CRUD・画面-API-テーブルの連鎖関係を導出します。ソースコードを新規に読み解いて画面・API・テーブルを検出する一覧生成の役割は持たず、既存manifestの再構成と`.claude/`配下（AI設定資産のみ）の走査に限定します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 種別別一覧が確定済みの状態で、権限画面マトリクス・権限機能マトリクス・CRUD図・画面-API-テーブル対応表・AI設定資産の5ページを作る | .claude/skills/generating-cross-views-for-reverse-docs/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | 本機能（Phase 1） | 画面一覧raw・raw由来ext・API一覧.htmlの実在を確認し、テーブル一覧・機能一覧の実在有無を確定する | 必須ファイルが実在すればPhase 2へ、不在なら停止する |
| 2 | 進行担当 | extract-api-metadata.sh／build-matrix-data.sh | 拡張マニフェストを抽出し、permission-matrix.json・crud-matrix.json・traceability.jsonを導出する | Phase 3 へ |
| 3 | 進行担当 | extract-ai-assets.sh | .claude/配下を走査してai-assets-data.jsonを生成する | Phase 4 へ |
| 4 | 進行担当 | build-matrix-pages.sh／build-permission-function-data.sh／build-portal.sh | 4データをテンプレートへ埋め込んで固定パスへHTMLを出力し、portal_output_dir指定時はポータルを再生成する | 完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 画面一覧・API一覧不在 | raw画面定義・raw由来ext・API一覧.htmlのいずれかが不在 | status=STOPPEDでハード停止し、先行実行を案内する | .claude/skills/generating-cross-views-for-reverse-docs/SKILL.md Phase 1 |
| テーブル一覧・機能一覧不在 | 任意データ源であるテーブル一覧・機能一覧が不在 | 不在のまま続行する（build-matrix-data.shがfail-safeで対応） | .claude/skills/generating-cross-views-for-reverse-docs/SKILL.md Phase 1 |
| データ形状不揃い | permission-functionのデータ形状が揃わない | 未生成のままskipped_pagesへ理由を記録する | .claude/skills/generating-cross-views-for-reverse-docs/SKILL.md 完了条件 |

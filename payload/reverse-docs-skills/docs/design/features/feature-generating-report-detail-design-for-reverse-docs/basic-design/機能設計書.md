本書は集約設計書です。構成要素の個別仕様は各構成要素の設計書を正とし、本書は値を再掲せずパスで参照します。本書が正を持つのは、構成要素をまたいで初めて意味を持つ事項だけです。

## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | generating-report-detail-design-for-reverse-docs |
| 機能ID | feat-generating-report-detail-design-for-reverse-docs |
| 大分類 | 生成 |
| 業務対象 | 帳票一覧の拡張マニフェストとsourceFileが指す原本コードから、帳票1本ごとの詳細設計書（項目編集・改ページ・集計・明細の繰り返し）を書き起こします。 |
| 確からしさ | high |
| 判定根拠 | 機能一覧マニフェスト（docs/manifests/feature-manifest.json）の sourceFile と .claude/skills/generating-report-detail-design-for-reverse-docs/SKILL.md の記述が一致する |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

帳票一覧の拡張マニフェストとsourceFileが指す原本コードから、帳票1本ごとの詳細設計書（項目編集・改ページ・集計・明細の繰り返し）を書き起こします。基本設計スキルが担う業務的な意味は対象外です。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 本機能を起動し、帳票詳細設計書.md を得る | .claude/skills/generating-report-detail-design-for-reverse-docs/SKILL.md |

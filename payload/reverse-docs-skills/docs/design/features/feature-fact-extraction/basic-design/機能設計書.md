## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | fact-extraction |
| 機能ID | feat-fact-extraction |
| 大分類 | リバース |
| 業務対象 | 対象ユニットの原本コードが持つ振る舞いの事実を、行番号根拠付きで宣言的契約（facts.yml）として取り出し、独立再計数・封印（確定）・再現性検証まで一貫して行うこと |
| 確からしさ | high |
| 判定根拠 | extracting-unit-facts-from-code のSKILL.mdが、原本コードから宣言的契約を抽出し独立再計数・確定・再現性検証を通して品質を保証する調査系の手順として一貫して記述されている |
| 境界の決定元 | build-target（Claude Code スキルのディレクトリ単位） |

### 1.2 業務上の位置づけ

主体: このツール自身（AIエージェントによるリバース設計フローの進行担当）です。

入力→出力: 既存コード（対象ユニットの原本ファイル） → 確定した事実の記録（facts.yml・facts.lock・recount-report.txt）です。

本機能は target-survey が確定したアーキテクチャ調査書を前提とします。対象ユニット（画面またはPythonコードユニット）ごとの原本コードから、後続の詳細設計執筆が原本を読まずに済む品質のfactsを確定します。抽出（Phase 2）と検証（Phase 3の独立再計数）の担当を分離します。確定（Phase 4のseal-facts。本機能内では「封印」の手順として扱い、別スキルには分離しません）と再現性検証（Phase 5）まで完走させます。これにより、執筆工程の入力品質を機械的に保証します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AIエージェント） | 画面ユニットまたはPythonコードユニットからfacts.ymlを抽出し、確定・再現性検証まで完走させる | `.claude/skills/extracting-unit-facts-from-code/SKILL.md` |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | extracting-unit-facts-from-code（Phase 1） | target_repo_path・verification_dir・survey_doc_pathの実在、target_file_paths全件の実在、profileの妥当性を確認する | 確認済みならPhase 2へ |
| 2 | 進行担当 | extracting-unit-facts-from-code（Phase 2） | profile=screenなら12分類、profile=pythonなら6分類のfacts.ymlをfile:line根拠付きで抽出する | Phase 3へ |
| 3 | 進行担当 | recount-facts.sh（本機能専用スクリプト） | facts.ymlのprofileを読み、原本から独立に再計数して記載件数と突合する | exit 0ならPhase 4、exit 1ならPhase 2へ差し戻し（上限3回） |
| 4 | 進行担当 | seal-facts.sh（封印・確定処理） | facts.lockを生成し（seal）、直後に整合性を確認する（verify） | verifyがexit 0ならPhase 5へ |
| 5 | 進行担当 | extracting-unit-facts-from-code（Phase 5） | 同じargsで独立した2回目の抽出を行い、normalize後のfacts.ymlをdiffで比較する | diffが空ならPhase 6へ、差分があれば診断分類する |
| 6 | 進行担当 | extracting-unit-facts-from-code（Phase 6） | 返却ブロック（status・artifacts・facts_ref・pending_measurements）を出力する | status確定で完了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 再計数不合格 | recount-facts.shがexit 1 | Phase 2へ差し戻し。上限3回、同一NG理由が2回連続で再発したら発散として即中断 | extracting-unit-facts-from-code SKILL.md ループ設計 |
| 版不一致 | facts.lockのNORMALIZE_VERSIONが現行と異なる | 改ざんではなく規則変更としてexit 3で報告し、再確定を促す | extracting-unit-facts-from-code SKILL.md 予想を裏切る挙動 |
| diff差分の診断 | Phase 5のdiffに差分がある | 順序差異／キー命名揺れ／共通文書由来の解釈分岐のいずれかへ分類し、分類できなければstatus=中断 | extracting-unit-facts-from-code SKILL.md Phase 5 |
| 非対応プロファイル | profileがscreen/python以外 | Phase 2以降を実行せずPhase 1でstatus=中断 | extracting-unit-facts-from-code SKILL.md 予想を裏切る挙動 |

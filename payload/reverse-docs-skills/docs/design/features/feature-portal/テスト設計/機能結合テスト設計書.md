## 本書が検証するもの

結合は2段に分けて定義します。1つの設計単位の中で構成要素が結合した状態を内部結合、複数の設計単位をまたぐ連携を外部結合と呼びます。単位ごとの文書は内部結合までを担い、プロジェクト全体の文書が外部結合を担います。

| 段 | 検証する状態 | 対応する設計書 | 文書 |
|---|---|---|---|
| 単体 | 1つの関数・メソッドの入出力 | 機能設計書 | 機能単体テスト設計書 |
| 内部結合 | 1つの機能の中で関数・メソッドが結合した状態（外部の振る舞い） | 機能設計書 | 機能結合テスト設計書（本書） |
| 外部結合 | 複数の画面・機能・APIをまたぐ連携 | 複数の設計書 | docs/test-cases/結合テスト仕様書.md |

| 対象 | 確認する内容 | 根拠となる機能設計書の章 |

## §1 テスト観点

**この節の位置づけ: 仕様**

§1は正常・異常・境界を含む全観点の一覧です。
§5と§6は、§1のうち異常と境界の観点を列ごとに詳しく述べる部分集合です。
§5と§6では新しい観点キーを作らず、§1と同じ観点キーを使います。
実行する全ケースは§2だけに記載し、§1の全観点へ1件以上のケースを対応させます。
実行するテストの件数は§2のデータ行数だけで数えます。

観点は機能設計書の業務フロー・業務ルール・エラーと業務メッセージの各章から起こす。

| キー | 観点 | 由来する機能設計書の章 |
|---|---|---|
| 暫定一覧-完成一覧突き合わせ | Phase 2 Step 2-7 の暫定一覧と Phase 7 Step 7-1 の完成一覧が、承認した対象範囲に基づいて種別ごとの差を報告する | 機能設計書 §3.1・§4.2 |
| 既存資産衝突-中断 | build-portal.sh 実行前に `index.html` が実在し `pt-nav-data` マーカーを含まない場合に中断し、別の出力先を確認する | 機能設計書 §3.2・§4.1 |
| 基盤ページ生成-ポータル反映 | 各基盤ページ生成スキルの検証済み page-data から HTML が生成され、`portal_output_dir` 指定時だけポータルへ反映される | 機能設計書 §3.1・§6.2 |
| 出力配置誤り-機能全体停止 | build-portal.sh の出力配置解決失敗が機能全体を異常終了させ、後続の基盤ページ確定へ進まない | 機能設計書 §3.2・§8.1 |
| 整合検証FAIL-差し戻し | 各スキルの整合検証が FAIL した場合に、page-data 組み立てへ差し戻され上限回数で打ち切られる | 機能設計書 §3.2 |

## §3 入力条件

**この節の位置づけ: 仕様**

| ケースのキー | 入力の項目 | 値 |
|---|---|---|
| 暫定一覧から完成一覧までの差なし | Step 2-7 承認時の presentKinds/excludedKinds | Step 7-1 完了時と同一の種別集合 |
| 暫定一覧から完成一覧までの差あり | Step 2-7 承認後の対象範囲変更 | 承認時から1種別を除外した状態でPhase 3以降を進める |
| 既存index.html衝突検知 | `<output_dir>/project-portal/index.html` | `pt-nav-data` マーカーを含まない対象アプリの既存ファイル |

| 整合検証3回失敗での差し戻し | validate-page-data.sh の判定結果 | 3回連続で同一検査項目がFAILする page-data.json |

## §4 期待結果

**この節の位置づけ: 仕様**

| ケースのキー | 期待する結果 | 確認の方法 |
|---|---|---|
| 暫定一覧から完成一覧までの差なし | 「差なし」と1行報告される | Step 7-1 の完了報告本文を確認する |
| 暫定一覧から完成一覧までの差あり | 種別ごとの差（承認時の件数・完成時の件数）が表で示される | Step 7-1 の完了報告本文の表を確認する |
| 既存index.html衝突検知 | build-portal.sh が実行されず、別の出力先の確認が求められる | orchestrating-ai-development-setup の中断報告を確認する |
| 自身が生成したindex.html再生成 | build-portal.sh が実行され index.html が更新される | 生成後の index.html の更新時刻とpt-nav-dataの内容を確認する |
| 技術スタック生成からポータル反映まで | 技術スタック.html が生成され、ポータルのカードへ反映される | 技術スタック.html の実在と、ポータルの技術スタックカードのリンク先を確認する |
| portal_output_dir未指定時の非反映 | 環境構築手順.html は生成されるがbuild-portal.shは実行されない | 完了報告の `portal_rebuilt` が `false` であることを確認する |
| 出力配置誤りによる全体停止 | `check_docs_root_misconfiguration` がERRORを出し、Phase 4 Step 4-4が完了しない | build-portal.sh の終了コードと標準エラー出力を確認する |
| 整合検証3回失敗での差し戻し | page-data組み立て（Phase 2）へ差し戻される | 各スキルの返却ブロックのhintを確認する |

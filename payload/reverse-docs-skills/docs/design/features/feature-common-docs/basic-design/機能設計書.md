## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | common-docs |
| 機能ID | feat-common-docs |
| 大分類 | 生成 |
| 業務対象 | 確定した事実の記録をもとに、プロジェクト共通6文書と要件定義5文書を作成します。 |
| 確からしさ | high |
| 判定根拠 | 構成要素スキル2件（generating-reverse-common-docs・generating-requirement-definitions-for-reverse-docs）のSKILL.mdが、いずれも `docs/design/common/`（commonRoot）配下へ成果物を出力する点で一致する |
| 境界の決定元 | build-target（4カテゴリ・17機能モデルにおける「リバースカテゴリ」の集約単位。2つのClaude Codeスキルのディレクトリを1機能へ統合） |

### 1.2 業務上の位置づけ

主体: このツール自身（リバース設計フローの生成担当AIエージェント）です。入力→出力は「確定した事実の記録 → プロジェクト共通6文書・要件定義5文書」です。本機能は2種類の文書を単一の機能として集約します。1つは、対象リポジトリのコードから層化サンプリングで書き起こすプロジェクト共通6文書です。内訳は、共通設計書・メッセージ定義書・DESIGN・基盤設計・UI共通設計・データ設計の6文書と、非永続のサンプル記録を合わせた7ファイルです。もう1つは、一覧マニフェストおよび個別基本設計書から確かめられる事実だけで組み立てる要件定義5文書です。内訳は、機能要件一覧・帳票要件・バッチ要件・外部連携要件・ビジネス概要です。両構成要素とも対象リポジトリへの書き込みは行わず、出力先（`docs/design/common/`配下）だけへ成果物を生成します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの生成担当（AI エージェント） | 本機能を起動し、共通設計書.md・メッセージ定義書.md・DESIGN.md・基盤設計.md・UI共通設計.md・データ設計.md・サンプル記録.md、および機能要件一覧.md・帳票要件.md・バッチ要件.md・外部連携要件.md・ビジネス概要.md を得る | `.claude/skills/generating-reverse-common-docs/SKILL.md`、`.claude/skills/generating-requirement-definitions-for-reverse-docs/SKILL.md` |

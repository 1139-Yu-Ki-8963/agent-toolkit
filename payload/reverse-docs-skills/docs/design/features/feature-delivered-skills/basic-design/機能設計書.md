## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | delivered-skills |
| 機能ID | feat-delivered-skills |
| 大分類 | セットアップ |
| 業務対象 | 対象リポジトリへ、開発フロー運転を中心とする配布スキル一式・規約レビュアー定義・生成器一式を、カタログを唯一の情報源として配置すること |
| 確からしさ | high |
| 判定根拠 | scaffold-rule-definitions.sh 冒頭コメントの「--with-skills:」節と delivery-payload/references/delivered-skill-catalog.json の内容が一致する |
| 境界の決定元 | build-target（generation-engine/scripts/rules/scaffold-rule-definitions.sh の --with-skills 経路単位） |

### 1.2 業務上の位置づけ

主体はこのツール自身（対象リポジトリへ設置する側）です。入力から出力への向きは、対象リポジトリからAIが読む定義・AIツール設定・ポータルの器へと進み、本機能はそのうちAIツール設定（対象リポジトリで動く配布スキル・レビュアー定義・生成器一式）を担います。配る対象はカタログの宣言のみを唯一の情報源とし、対象名をスクリプトへ直接書きません。各スキルを定義から派生への2段構成で配ります。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 対象リポジトリへ配布スキル一式・レビュアー定義・生成器一式を配置する（--with-skills 指定時） | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | scaffold-rule-definitions（--with-skills 指定） | delivered-skill-catalog.json の宣言を読み、配る対象（スキル名・ファイル一覧）を確定する | 対象が確定すれば1段目の複製へ |
| 2 | 進行担当 | scaffold-rule-definitions | 1段目（定義）: delivery-payload/templates/delivered-skills/配下の各ファイルを対象リポジトリのカタログ定義ルート配下へ複製する（既存なら上書きしない） | 複製完了後、2段目の派生複製へ |
| 3 | 進行担当 | scaffold-rule-definitions | 2段目（派生）: 1段目で置いた定義ファイルを対象リポジトリのカタログ派生ルート配下へ複製する（既存でも常に上書きする）。Markdownは生成物notice commentを前付け直後に入れる | 複製完了後、レビュアー定義と生成器一式の配布へ |
| 4 | 進行担当 | scaffold-rule-definitions | delivery-payload/templates/delivered-agents/rule-reviewer.md を対象リポジトリの.claude/agents/rule-reviewer.mdへ同じ生成物notice comment規約で複製する（1段のみ） | 複製完了後、生成器一式の配布へ |
| 5 | 進行担当 | scaffold-rule-definitions | 生成器一式（generation-engine/scripts・delivery-payload/templates・delivery-payload/references）を対象リポジトリのreverse-docs-engine/配下へ配る | 全配置完了で正常終了 |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| with-skills未指定 | --with-skills が指定されていない | 配布スキル・レビュアー定義・生成器一式は配布されない | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |
| 1段目の既存ファイル | 定義ルート配下に既に同名ファイルが存在する | 上書きしない | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |
| 2段目の既存ファイル | 派生ルート配下に既に同名ファイルが存在する | 常に上書きする | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |
| 拡張子がmd以外 | 配布対象ファイルの拡張子がMarkdown以外 | 生成物notice commentを入れずそのまま複製する | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 後段との関係 | standards-scaffolding（規約の配布と派生生成） | 実装フローのゲートが必須とする2ファイル（flow-values.yml・rule.md）を同時に配る | generation-engine/scripts/rules/scaffold-rule-definitions.sh 冒頭コメント |

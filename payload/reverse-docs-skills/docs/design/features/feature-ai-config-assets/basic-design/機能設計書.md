## §1 機能概要

**この節の位置づけ: 仕様**

### 1.1 基本情報

| 項目 | 値 |
|---|---|
| 機能キー | ai-config-assets |
| 機能ID | feat-ai-config-assets |
| 大分類 | セットアップ |
| 業務対象 | 対象リポジトリを調べ、AGENTS.md・CLAUDE.mdの前半索引と、AI設定資産ページ（rules/skills/subagents/hooksの一覧）の元データを実在証拠だけから作ること |
| 確からしさ | high |
| 判定根拠 | .claude/skills/generating-agent-config-index-from-repo/SKILL.md と generation-engine/scripts/extract/extract-ai-assets.sh の冒頭記述が一致する |
| 境界の決定元 | build-target（スキルディレクトリ単位・抽出スクリプト単位） |

### 1.2 業務上の位置づけ

主体はこのツール自身（対象リポジトリへ設置する側）です。入力から出力への向きは、対象リポジトリからAIが読む定義・AIツール設定・ポータルの器へと進みます。本機能はそのうちAIが読む定義（AGENTS.md・CLAUDE.mdの前半索引）とポータルの器（AI設定資産ページの元データ）を担います。AIの振る舞い・承認・委任・停止条件などの規約はコードから発明せず、対象リポジトリに明示された規約定義がある場合だけ参照として記載します。

### 1.3 利用者と権限

| 利用者区分 | この機能でできること | 参照先 |
|---|---|---|
| リバース設計フローの進行担当（AI エージェント） | 対象リポジトリを分析し、AGENTS.md・CLAUDE.mdの前半索引を新規生成または差分更新し、AI設定資産ページの元データを抽出する | .claude/skills/generating-agent-config-index-from-repo/SKILL.md |

## §3 業務フロー

**この節の位置づけ: 仕様**

### 3.1 正常系フロー

| 順 | 実行主体 | 構成要素 | 処理 | 次の分岐条件 |
|---|---|---|---|---|
| 1 | 進行担当 | generating-agent-config-index-from-repo（Phase 1） | README・依存定義・ビルド設定・CI・実行スクリプト・主要ディレクトリを読み、根拠パス付きで前半索引の各項目を確定する | 未確認事項が推測で埋まっていなければPhase 2へ |
| 2 | 進行担当 | generating-agent-config-index-from-repo（Phase 2） | 規約ルートが指定されていれば実在を確認し、規約索引マーカーを含むテンプレートをそのまま複製する | 個々の規約参照を書き込んでいなければ Phase 3 へ |
| 3 | 進行担当 | generating-agent-config-index-from-repo（Phase 3） | テンプレートへ事実を展開し、検査を実行する | 全検査が成功すれば生成完了 |
| 4 | 進行担当 | extract-ai-assets | 対象リポジトリの.claude/rules・.claude/skills・サブエージェント・hooksを走査し、4セクション構成のJSONを出力する | 検出根拠が弱い値は出力しない（欠落を優先） |

### 3.2 分岐と例外フロー

| キー | 分岐条件 | 到達先 | 参照先 |
|---|---|---|---|
| 規約ルート未指定 | 対象リポジトリの規約定義の配置が未確認 | 規約ルートを設定せず、規約索引は不明事項として残す | .claude/skills/generating-agent-config-index-from-repo/SKILL.md 入力契約 |
| 検査不合格 | Phase 3 の検査のいずれかが失敗する | 生成を確定せず、根拠不足として返す | .claude/skills/generating-agent-config-index-from-repo/SKILL.md Phase 3 |
| 検出根拠が弱い | 抽出対象の値の検出根拠が弱い | その値を出力しない（欠落扱い） | generation-engine/scripts/extract/extract-ai-assets.sh 冒頭コメント |

### 3.3 前後の機能との関係

| 関係 | 相手の機能キー | 受け渡す情報 | 参照先 |
|---|---|---|---|
| 呼び出し先 | standards-scaffolding（規約の配布と派生生成） | RULES-INDEXマーカーを含むテンプレート | .claude/skills/generating-agent-config-index-from-repo/SKILL.md 作成区分 |

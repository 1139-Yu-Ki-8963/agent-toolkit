## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/portal-catalog.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. categories[] を順に走査し、各カテゴリの blueprints[] を取り出す。
4. 各 blueprint の discovery.glob で対象プロジェクトの出力先を走査し、生成物の有無を判定する。
5. 判定結果に基づいてポータルトップのカードを表示または disabledWhenEmpty として無効化する。

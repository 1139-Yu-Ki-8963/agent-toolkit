## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/rule-banned-terms.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. terms[] を順に走査し、scope に一致する呼び出し元（規約定義／スキル定義）を対象に語の出現を検査する。
4. 禁止語が出現した箇所が exemptions[] に登録された parent／key と一致する場合は除外する。
5. 除外されない出現があれば不合格として報告する。

## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/reference-json-integrity.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. checks[] を順に走査し、各検査の source.file／source.query と target.file／target.query を取り出す。
4. 参照元・参照先それぞれのファイルから query（jqクエリ）でキー集合を取り出す。
5. relation（equal等）に従って2つのキー集合を突き合わせ、不一致を不合格として報告する。

## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/配布文書の言葉.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. glossaryDocument が指す文書から glossaryHeading の節を探し、terms[] の各語の説明を確認する。
4. referringDocuments[] が指す各文書を走査し、terms[] の語が初出する箇所より前に用語集への言及があるかを確認する。
5. 節の不在、説明の不在、または言及より前の語の使用を検出した場合は不合格として報告する。

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/rule-taxonomy.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. parents[] を順に走査し、各親の children[] から規約1件ごとの分類情報を取り出す。
4. children[].toolDefined が true の規約については checker の実在を確認する。
5. 対象プロジェクトの実装状況が未解析または対象なしの場合、projectRulePlaceholders の定型文を規約本文へ差し込む。

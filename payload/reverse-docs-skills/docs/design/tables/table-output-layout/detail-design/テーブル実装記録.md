## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/output-layout.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. 必要な項目（layout.<key>, kindDirNames.<kind>, unitPhaseDirNames.<phase> 等）を取り出す。
4. 対象プロジェクト側の上書き定義（存在する場合）とキー単位で合成する。
5. 取り出した値を用いて、呼び出し元固有の配置または検証処理を行う。

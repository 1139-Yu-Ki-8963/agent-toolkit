## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

読み込み元スクリプトは次の手順でこの定義を扱います。

1. delivery-payload/references/instruction-writing-terms.json をファイルとして読み込む。
2. JSON として解析する。解析に失敗した場合は処理を中断しエラーを通知する。
3. transliterations[] の各要素から term と replacement を取り出す。
4. 指示書の地の文に term が出現するかを走査し、出現した場合は不合格として報告する。
5. quotedTemplateHeadings[] を取り出し、配布物テンプレートの章名を引用する記述を除外条件として使う。

## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

```
assertSafeWritePath を実行する

　　書き込み先の場所を階層ごとに分ける

　　各階層について、次を繰り返す

　　　　もし 現在の階層が実在しないならば

　　　　　　繰り返しを打ち切る

　　　　もし 現在の階層が近道でないならば

　　　　　　次の階層へ進む

　　　　isOsStandardLink を呼び、近道の指す先が標準かどうかを調べる

　　　　もし 標準でないならば

　　　　　　想定外の近道であるという例外を送出する

処理を終える
```

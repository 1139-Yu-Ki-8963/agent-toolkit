## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

```
build_manifest_for_kind(設計文書のルート, 出力先, 種別)
  もし 宣言（走査基点・代替値の定義）が種別に対して欠けているならば

    エラーを報告して終わる

  種別の走査基点の下から対象文書を集める
  対象文書が0件ならば

    件数0件の一覧の元データを書き出して終わる

  対象文書ごとに繰り返す

    frontmatterから項目を取り出す
    導けない項目は宣言済みの代替値で埋める
    もし 識別子（キー・出典）が代替値で埋まったならば

      種別を「未確認」で固定する

    組み立てた1件を蓄積する

  蓄積した全件から一覧の元データを組み立てて書き出す
  組み立てた元データを検証する
  もし 検証が不合格ならば

    当該種別をエラーとして扱い、他の種別の処理は続ける

extract_transition(画面一覧の元データ, 画面基本設計書のルート, 出力先)
  もし 画面一覧の元データが不在または不正ならば

    エラーを報告して終わる

  画面一覧の元データから節の一覧を組み立てる
  画面基本設計書ごとに繰り返す

    業務文脈の表からデータ行を取り出す
    データ行が0件ならば 次の画面基本設計書へ進む
    データ行ごとに繰り返す

      遷移元・遷移先を画面一覧の中から解決する
      解決できたならば 矢印として蓄積する
      解決できないならば 未解決の一覧へ理由付きで記録する

  蓄積した節と矢印から元データを組み立てて書き出す
```

## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

```
detect_screens(原本コードのルート, 出力先)
  原本コードをたどって画面らしきファイルを探す
  もし 画面が1件も見つからなければ

    空の検出結果を書き出して終わる

  見つかった画面ごとに繰り返す

    画面の識別子・経路・種別を組み立てる

  組み立てた全件から検出結果を書き出す

build_unit_list(一覧の元データ, 出力先, 種別)
  もし 種別が画面または機能ならば

    対応する専用の組み立て処理へ委譲する

  でなければ

    validate_manifest(一覧の元データ, 種別) を呼ぶ
    もし 検証が不合格ならば

      エラーを報告して終わる

    自前の汎用テンプレートで一覧を組み立てて書き出す

rebuild_screen_derived_pages(画面一覧の元データ, 出力先)
  一時的な作業場所を用意する
  作業場所の中で派生成果物一式を順番に作り直す
  もし いずれかの段が失敗したならば

    退避しておいた元の内容で復元して終わる

  作業場所の内容を出力先へ確定させる
```

## §1 疑似コード

**この節の位置づけ: 現行実装。本節は現在の実装の作りをそのまま記録した節です。作り直す前に、この節に書いた作りをどう扱うかを決める必要がある**

```
apply_guide_style(実書き込みするか)
  統一済みの定義を読み込む
  対象説明書ごとに繰り返す

    もし 既に統一済みならば 次の説明書へ進む
    もし 実書き込みするならば

      一時ファイルへ書き換え結果を組み立てる
      一時ファイルで元ファイルを置き換える

    でなければ

      未統一として件数へ数える

check_guide_script_paths()
  対象説明書ごとに繰り返す

    本文から参照先パスの候補を取り出す
    候補ごとに繰り返す

      もし パスが実在しないならば 不在の一覧へ追加する

  不在の一覧を報告する
```

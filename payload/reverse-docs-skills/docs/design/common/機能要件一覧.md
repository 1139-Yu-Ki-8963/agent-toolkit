**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: §1 本書の位置づけ、§2 機能一覧（観測事実）、§3 関連資料

- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

## §1 本書の位置づけ

**この節の位置づけ: 仕様**

本書はシステムが備える機能の一覧と、各機能が満たすべき要件を記します。機能の存在・構成・分類は機能一覧マニフェストから観測できます。一方、各機能が業務上なぜ必要か、誰のための要件かは原本から導けないため、§2（観測事実）には観測できた事実だけを書き、原本から導けない事項は要確認事項一覧に明記します。

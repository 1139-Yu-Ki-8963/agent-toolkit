# 共通設計書（リバース版）

**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: 該当なし
- 現行実装: 該当なし
- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

本書は、複数の画面から共通して観測される実装済み挙動（画面状態・操作規則・レイアウト原則）を記録する文書です。対象リポジトリは画面（UIコンポーネント）を1件も持たず、画面が対象外である判定の記録は `docs/scope-and-progress/excluded-kinds.json` を正とします。本書は同記録への参照だけを持ち、実測値・出典を書き直しません。

## 対象外の根拠

画面が対象外である根拠（実測値・出典）は `docs/scope-and-progress/excluded-kinds.json` を正とし、本書へは書き直しません。

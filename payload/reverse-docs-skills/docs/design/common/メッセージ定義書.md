# 共通メッセージ定義書（リバース版）

本書は、対象リポジトリの検査スクリプト群が繰り返し出力する共通の判定ラベル文言の記録です。対象リポジトリは画面（UIコンポーネント）を持たないため、複数画面から抽出したUI文言ではなく、複数の検査スクリプト・複数の規約フックが共通して出力する実装済みの判定ラベルを対象とします。あるべき文言を新たに設計するのではなく、既存コードに実際に存在する文言のみを扱います。

## 本書に書かないもの

書かない内容は次の3点です。文言の出力実装・分岐ロジックは実装コードを正の置き場とします。個々の検査スクリプト固有の1回きりの出力文言は、当該スクリプトのヘッダコメントを正の置き場とします。共通のデザイントークン（色・フォント等）は本フォルダの DESIGN.md を正の置き場とします。

## キーと文言の記録方針

キーは内容要約キーで付けます（連番識別子は使いません）。実装コードから取り出した実際の文言をそのまま転記し、言い回しの改善提案はここに書きません。複数の検査スクリプトで共通して使われる判定ラベルのみを本書に収録し、個別スクリプト限定の出力文言は当該スクリプトのヘッダコメントに置きます。

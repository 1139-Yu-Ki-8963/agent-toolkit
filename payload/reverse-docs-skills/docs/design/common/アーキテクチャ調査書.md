## §7 判定不能と実在しない項目の理由

**この節の位置づけ: 仕様**

| キー | 内容 | 理由 |
|---|---|---|
| 画面-実在なし | §6画面種別が実在しない | 対象リポジトリはスキル定義リポジトリであり、業務アプリケーションのUIコンポーネントを持たない。同名パターンの一致は `generation-engine/samples`・`generation-engine/samples-no-screen`・`generation-engine/samples-api-only`・`delivery-payload/references/gold-standard` に置かれた、生成エンジン自身を検証するための疑似入力（フィクスチャ）に限られる |
| API-実在なし | §6API種別が実在しない | 対象リポジトリはHTTPサーバーを持たず、SDL/IDLソースも見つからない |
| 帳票-実在なし | §6帳票種別が実在しない | 対象リポジトリは帳票を出力する機能を持たない |
| 外部連携-実在なし | §6外部連携種別が実在しない | 対象リポジトリは外部サービスへのクライアント呼び出しを持たない。検出パターンに一致する文字列は、他リポジトリの外部連携を検出するための検出スクリプト（`generation-engine/scripts/extract/` 等）自身が持つ例示・自己テスト用フィクスチャに限られる |
| 環境変数定義-実在なし | §3環境変数定義の所在が実在しない | `.env` 等の集中管理ファイルを持たず、個別スクリプトが都度環境変数を参照する構成のため |
| ビルド起動コマンド-実在なし | §3起動コマンドが実在しない | 常駐アプリケーションサーバーを持たず、スキル単位の都度起動構成のため |

# データ設計書（リバース版）

**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: §1 データモデル概要（実測）、§2 APIスキーマ（実測）、§5 キャッシュ戦略（実測）、§6 状態遷移表（実測）
- 現行実装: §3 状態管理方針（実測）、§4 データフロー（実測）
- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

本書は、アーキテクチャ調査書および層化サンプルから取り出した、データ関連の実装方針を横断的に整理した記録です。あるべきデータ設計を新たに構想するのではなく、既存コードに実際に存在する方針のみを扱います。個別のテーブル定義書は本書ではプロジェクト横断の方針のみを扱います。対象コードの位置は記録しません。

## 本書に書かないもの

個別テーブルのカラム定義は各テーブル定義書を正の置き場とします。画面固有のデータ取得ロジックや UI 表示上の状態は、対象リポジトリが画面を持たないため該当がありません。

## §6 状態遷移表（実測）

**この節の位置づけ: 仕様**

docs/tasks配下の指示書は、対応の記録として次の状態を持ちます。

| エンティティ | 状態 | 遷移前 | 契機 | 遷移後 |
|---|---|---|---|---|
| 指示書の判定 | 未着手 | （初期状態） | 指示書の新規作成 | 未着手 |
| 指示書の判定 | 対応中 | 未着手 | 担当者が作業に着手 | 対応中 |
| 指示書の判定 | 完了 | 対応中 | 判定手段が満たすことを確かめる | 完了 |
| 指示書の判定 | 未確認 | 対応中 | 判定手段の実行が時間の上限を超える | 未確認 |
| 指示書の判定 | 対象外 | 対応中 | 実測の結果、判定が成立しないと分かる | 対象外 |

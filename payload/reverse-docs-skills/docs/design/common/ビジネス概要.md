## §1 本書の位置づけ

**この節の位置づけ: 仕様**

本書は事業の概要と、システムが事業の中で担う役割を記します。事業の目的・対象顧客・システムの位置づけは実装コードから導けません。本書が観測から埋められるのは、システムの規模（機能・テーブル・バッチ等の件数）にとどまります。

確定できなかった事項は次の3点です。事業概要（対象リポジトリが解決する業務課題・利用者への価値）は原本から確定できません。システム役割（対象リポジトリが担う業務上の役割）は原本から確定できません。対象利用者（想定する利用者像）は原本から確定できません。いずれも§3の要確認事項一覧へ回します。

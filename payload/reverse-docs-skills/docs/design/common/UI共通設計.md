# UI共通設計書（リバース版）

**この文書の位置づけ**（別の言語で作り直す場合は、まず「仕様」から読む）

- 仕様: 該当なし
- 現行実装: 該当なし
- 仕様／現行実装（詳細は各節の太字1行を見る）: 該当なし

本書は、複数の画面から共通して観測されるUIの設計方針（デザインシステム・共通コンポーネント・レイアウト方針等）を上位から俯瞰する文書です。対象リポジトリは画面（UIコンポーネント）を1件も持たないため、本書は対象外とします。画面が対象外である判定の記録は `docs/scope-and-progress/excluded-kinds.json` を正とし、本書は同記録への参照だけを持ちます。

なお、対象リポジトリが生成するポータルHTML群の共通デザイントークンは、業務アプリケーションの画面ではなく生成物であり、本書の対象とはしません。同トークンの記録は本フォルダの `DESIGN.md` を参照してください。

## 対象外の根拠

画面が対象外である根拠（実測値・出典）は `docs/scope-and-progress/excluded-kinds.json` を正とし、本書へは書き直しません。

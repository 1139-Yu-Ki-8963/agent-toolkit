対象は `docs/tasks/自己設計書整備の指示書.md` 4.5節の手順で洗い出した第1優先（素直でない実装を持つ）1本。群全体の役割・呼び出し関係・共通する背景は `基本設計書.md` を参照する。`rule.md` に既にある「このスクリプトが存在する理由」のADRとは重複させず、個別の実装判断だけを書く。

各節の「実装判断」は指示書4.2節の4点（1: なぜ素直な形を採らなかったか、2: 実測値、3: 環境依存かどうか、4: 過去に消えて再発した経緯）に沿って記載する。

## build-rule-proposal.sh

### 実装契約

- 引数: `<入力JSON> <出力HTML> [--generated-at <iso8601>]`、または `--self-test`
- 環境変数: なし
- 出力: `<出力HTML>`（規約提案HTML1枚。外部依存無しの単一ファイル）
- 終了コード: `jq`/入力/テンプレート不在・不正JSON・静的検査不合格のいずれかで `exit 1`（`build_rule_proposal()` の `return 1` を経由）。正常終了は `exit 0`
- 副作用: 出力先ディレクトリを `mkdir -p` する。一時ファイルは作らない（`printf '%s\n' "$out" > "$output"` で直接書く）

### 実装判断

1. **なぜ素直な形を採らなかったか**: 3点ある。
   (a) `VERIFY_SCRIPT`（該当箇所）が `$HOME/agent-home/skills/reviewing-explanatory-html/scripts/verify-html-static.mjs` という、このリポジトリの外（実行マシン固有の設定資産置き場）を指す。素直な形（静的検査スクリプトをこのリポジトリへ同梱する）を避けている。HTML静的検査（禁止色・box-shadow・未解決 `{{` 等）は、このリポジトリの他のHTML生成スクリプト（`detail-pages/build-detail-page.sh` 等）が検査対象にする観点と重複するため、同梱して二重保守するより既存の検査器（`reviewing-explanatory-html` skill）を再利用する設計とした。
   (b) `run_static_verify()`（該当箇所）は、`VERIFY_SCRIPT` が存在しない、または `node` コマンドが見つからない場合、素直な形（fail-closed。生成そのものを失敗させる）を避け、警告のみでスキップして `return 0` する（fail-open）。`VERIFY_SCRIPT` は(a)のとおりこのリポジトリの外を指すため、agent-homeを持たない実行環境（他マシン・CI・納品先での再生成等）では常に不在になる。この検査はこのリポジトリの開発時の追加チェックであり、本体の生成契約（決定的なHTML生成）に必須の依存ではないため、不在を理由に生成そのものを止めない。判定の根拠行はスクリプト本体の該当箇所（`[ ! -f "$VERIFY_SCRIPT" ]` と `! command -v node` の各分岐、いずれも `return 0`）。
   (c) HTML属性 `data-paths`/`data-sources`（該当箇所）だけ、他の属性と異なり区切り文字を `"`（ダブルクォート）ではなく `\x27`（printfの16進エスケープでシングルクォートを表す）にしている。値は `jq -c` で組み立てたJSON配列文字列であり、要素ごとに `"` を大量に含む。`html_escape()` で `"` は `&quot;` へ変換済みのためダブルクォート区切りでも壊れないが、出力後の生HTMLを人が読む・grepする際に `"` だらけの属性値を判別しやすくする目的で、この2属性だけシングルクォート区切りにしている。
2. **実測値**: 実測値なし。
3. **環境に依存するかどうか**: (a)(b) は依存する。実行マシンに `agent-home` が存在するかどうかに依存し、存在しない環境では静的検査が常にスキップされる。**手元の開発環境（agent-homeあり）で検査が実行され不合格を検出できることを理由に、この依存を「常に検査を強制する」方向（fail-closed）へ書き換えるな。他の環境で生成そのものが失敗するようになる。** (c) は環境に依存しない（読みやすさのための表記選択であり、実行結果には影響しない）。
4. **過去に消えて再発した経緯**: 記録なし。今回の作業時点で(a)(b)(c)いずれも理由コメントが無いことを発見し、本作業で追記した。

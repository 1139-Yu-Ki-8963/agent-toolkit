# 繰り返す作業の手順書の決まり

## 概要

定期的に繰り返す定型作業を、いつ・誰が・何をもって終わりとするかを決める取り決め。

定型作業は手順が同じであるため、実行するたびに判断をやり直す必要がない。判断をやり直すと、実行のたびに結果が変わる。手順・実行の間隔・完了の判定を先に書き、実行者が変わっても同じ結果になる状態を保つ。

## 規則

| 規則 | 内容 | 検査 |
|---|---|---|
| 手順を文書に固定する | 定型作業の手順を文書へ書き、記憶と口伝に頼らない | 静的解析: リポジトリ内に定型作業の手順書が実在するかを走査する |
| 実行の間隔と起点を書く | 何を起点に、どの間隔で実行するかを手順書へ明記する | 静的解析: 手順書に実行の間隔または起点を示す記述があるかを走査する ／ レビュー: 記述された間隔・起点が実行者によらず一意に定まる内容かどうかを人が判断する |
| 失敗したときの扱いを書く | 途中で失敗した場合に、やり直すのか途中から再開するのかを手順書へ書く | 静的解析: 手順書に失敗時の扱いを述べた見出しまたは記述があるかを走査する ／ レビュー: 記述が「やり直す」か「再開する」かを曖昧さなく定めているかを人が判断する |

## 違反時の手順

手順書が見当たらないと知らされた場合、定型作業の手順を書いた文書をリポジトリへ置く。実行の間隔または起点が見当たらないと知らされた場合は、何を起点にどの間隔で実行するかを手順書へ書き足す。失敗したときの扱いが見当たらないと知らされた場合は、途中で失敗したときにやり直すのか途中から再開するのかを手順書へ書き足す。

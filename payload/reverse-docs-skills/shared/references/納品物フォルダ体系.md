# 納品物フォルダ体系

本ファイルはリバース設計の納品物（成果物一式）の目録の正本である。各成果物を生成するスキルとの対応と実装状況をここで管理する。

画像からの文字起こし。リバース対象ユニットの成果物置き場（`<output_dir>` 配下）の全体構成と、各ファイルを生成するスキルの対応を示す。

実装状況の凡例: 【済】= 現行スキルが生成する成果物。【段階計画 Cycle 1〜3】= テーブル・バッチ・帳票・外部連携の詳細設計書群（未実装。API詳細設計書は実装済みのため本群から外れた）。【段階計画 Cycle 4】= 上位抽象化スキルが担う基本設計・要件定義文書群（未実装）。

用語のリバース解析候補は納品物ではない。`generating-glossary-for-reverse-docs` は呼び出し元が明示した対象repo外の絶対パスへproposal YAMLとdiagnosticsだけを生成し、この体系へ直接書き込まない。

## ポータルカテゴリ対応表

`shared/references/portal-catalog.json`のカテゴリキーと、この目録に記載する成果物・生成スキルの対応を管理する。同一カテゴリに複数の成果物を記載できる。

| カテゴリキー | カテゴリ名 | 成果物 | 生成スキル |
|---|---|---|---|
| `project` | 基盤情報 | `技術スタック.html` | `generating-tech-stack-for-reverse-docs` |
| `standards` | 規約 | `規約/コーディング規約.html` | `generating-reverse-common-docs` |
| `design` | 設計書 | `プロジェクト共通/共通設計書.html` | `generating-reverse-common-docs` |
| `list` | 一覧・設計図 | `一覧/画面一覧/画面一覧.html` | `generating-screen-list-for-reverse-docs` |
| `cross` | マトリクス・対応表 | `マトリクス・対応表/権限画面マトリクス/権限画面マトリクス.html` | `generating-cross-views-for-reverse-docs` |
| `cross` | マトリクス・対応表 | `マトリクス・対応表/権限機能マトリクス/権限機能マトリクス.html` | `generating-cross-views-for-reverse-docs` |
| `cross` | マトリクス・対応表 | `マトリクス・対応表/CRUD図/CRUD図.html` | `generating-cross-views-for-reverse-docs` |
| `cross` | マトリクス・対応表 | `マトリクス・対応表/追跡可能性/追跡可能性.html` | `generating-cross-views-for-reverse-docs` |
| `ai` | AI設定資産 | `AI設定資産/AI設定資産.html` | `generating-agent-config-index-from-repo` |
| `design-tools` | デザイン | `デザインシステム.html` | `generating-design-system-for-reverse-docs` |

## 検証記録（verification/）

検証記録は納品物ではないため `docs/` の外に配置する。`docs/` と同階層の `verification/` フォルダに格納する。

```
verification/
└── screen-<画面ID>/
    ├── facts/
    │   └── <run_id>/
    │       ├── facts.yml
    │       ├── facts.lock
    │       └── recount-report.txt
    ├── 単体-<対象ファイルbasename>/
    │   └── <timestamp>/
    │       └── (単体検証記録)
    └── <timestamp>/
        ├── 修正指示書.md
        ├── 最終報告.md
        └── (テストログ・差分レポート等)
```

docs 内に検証記録は一切存在しない。facts・単体検証記録・修正指示書・最終報告・テストログはすべて verification/ 配下に配置する。

## 出典

`納品物フォルダ体系.md`（提供されたスクリーンショット2枚）の文字起こし。文字起こしのみを目的とし、実際のディレクトリ・ファイルの生成は行っていない。実装状況（【済】/【段階計画 Cycle N】）は文字起こし後にリポジトリの現行スキル構成と突合して追記したもの。

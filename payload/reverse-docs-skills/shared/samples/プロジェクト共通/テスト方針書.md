# テスト方針書

## テスト種別と判別基準

| 種別 | ファイルパターン | フレームワーク |
|---|---|---|
| 単体テスト | *.test.ts(x) / *.spec.ts(x) | jest / vitest |
| 結合テスト | tests/integration/ 配下 | jest / vitest + msw |
| E2Eテスト | *.e2e.ts / cypress/ / playwright/ | Cypress / Playwright |

## カバレッジ基準

- 単体テスト: 主要ビジネスロジックを網羅
- E2Eテスト: 主要ユーザーフローを網羅

# 命名規約

## データベース

- テーブル名は複数形スネークケース（`user_accounts`）
- カラム名はスネークケース（`created_at`）
- 外部キーは `参照先テーブル単数形_id`（`user_id`）
- インデックス名は `idx_テーブル名_カラム名`

## API エンドポイント

- リソース名は複数形（`/api/v1/users`）
- アクションは HTTP メソッドで表現（GET/POST/PUT/DELETE）
- クエリパラメータはキャメルケース（`?pageSize=20`）

## フロントエンド

- コンポーネント名はパスカルケース（`UserProfileCard`）
- イベントハンドラは `handle` + イベント名（`handleSubmit`）
- CSS クラスはBEM記法（`block__element--modifier`）
- 状態管理のキーはドット区切り（`user.profile.name`）

## AI設定資産への変換

| 規約キー | 対象パス | 強制区分 | 規約要点 | 違反時手順 |
|---|---|---|---|---|
| `naming-files` | `**/*` | `advisory` | component、hook、utility、test、styleのfile名を実測patternに合わせる | 対象fileと参照を実測patternへrenameする |
| `naming-symbols` | `**/*` | `advisory` | 変数、関数、定数、Props型、event handlerを実測patternに合わせる | symbolと全参照を実測patternへrenameしてtestする |
| `naming-css-classes` | `**/*` | `advisory` | CSS class名を実測patternに合わせる | class定義と参照を同時に直し、表示を再確認する |

# AIエージェント行動規約

## 概要

この規約は、AIエージェントへ作業を委任する際の役割分担と実行方式を定める。対象は、方針を決める工程と決めた内容を反映する工程の分離である。サンプルアプリの開発で観測した委任の失敗パターンをもとに定めた。

## 規則

| 規則 | 内容 | 根拠 |
|---|---|---|
| 判断と反映の分離 | 修正方針の決定は上位のエージェントが行い、確定した内容の反映だけを下位のエージェントへ委任する | 方針決定と反映を同一の担当者に任せると、途中で方針がぶれても気づきにくい |
| バックグラウンド起動の徹底 | サブエージェントは必ずバックグラウンドで起動し、フォアグラウンド起動を禁止する | フォアグラウンド起動は呼び出し元を応答不能にし、並行作業を妨げる |
| 結果検証の義務化 | サブエージェントの報告は、数値の裏取りと推測部分の分離を行ってから利用者へ伝える | 未検証の報告をそのまま伝えると、誤った情報が意思決定に混入する |

## 違反時の手順

1. 委任判定フローに立ち返り、作業の種類に対応する担当へ委任し直す
2. 判断と反映が同一の担当に混在している箇所を洗い出し、担当を分離する
3. 検証されていない報告が見つかった場合は、報告者に根拠の提示を求める
4. advisory のため実行は止まらないが、繰り返し発生する場合は規約自体の見直しを検討する

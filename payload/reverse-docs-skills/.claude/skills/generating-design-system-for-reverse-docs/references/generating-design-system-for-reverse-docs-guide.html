デザインシステム生成スキル
generating-design-system-for-reverse-docs

共通 DESIGN.md に書かれた CSS トークンをそのまま転記し、デザインシステム.html を生成する基盤ページ生成スキルの確定仕様。

対応 OSWindows WSL2 環境
検証状況共有エンジン（validate-page-data.sh・build-detail-page.sh）は他の詳細ページ生成スキルで動作確認済み。CSS トークン抽出（extract-design-tokens-from-designmd.sh）の単独実機検証は未実施。スキル専用のテストスクリプトは持たない
依存共有スクリプト shared/scripts/extract/extract-design-tokens-from-designmd.sh・shared/scripts/detail-pages/validate-page-data.sh・shared/scripts/detail-pages/build-detail-page.sh ／ 任意 shared/scripts/build-portal.sh

§1概要

画面の見た目を支える色・余白・文字サイズといった値は、共通 DESIGN.md に文章として書かれている。本スキルはその記述から CSS トークンを取り出し、一覧として読めるデザインシステム.html を作成する。

やることは転記だけである。値が適切か、命名が揃っているか、使われていないトークンがあるかといった判定は一切行わない。DESIGN.md に書かれていない値を推測して補うこともしない。

本スキルがやること
共通 DESIGN.md からの CSS トークン抽出・デザインシステム.html の生成
本スキルがやらないこと
トークンの値・命名の良否判定・未使用トークンの指摘（いずれも人間の判断） ／ 共通 DESIGN.md 自体の作成（generating-reverse-common-docs の担当）

起動引数

引数内容
output_dir共通 DESIGN.md の所在であり、デザインシステム.html の書き出し先でもあるディレクトリ
portal_output_dir任意。渡された場合のみポータルへ反映する

output_dir に共通 DESIGN.md が存在しない場合、本スキルは生成せず SKIP を返す。

§2出力

対象リポジトリ 1 つにつき、次の 1 点が生まれる。

デザインシステム.html
共通 DESIGN.md から取り出した CSS トークンの一覧。トークン名と値を、DESIGN.md に書かれたままの形で持つ。output_dir の直下に置かれる

§3用語

CSS トークン
色・余白・文字サイズ・角丸といった見た目の値に名前を付けたもの。CSS カスタムプロパティとして書かれることが多い
転記
原本に書かれた値をそのまま写すこと。単位の変換・値の丸め・命名の統一を行わない

§4動作フロー（Phase 1〜4）

Phase内容
Phase 1 原本の確認output_dir に共通 DESIGN.md が存在するかを確認する。無ければ生成せず SKIP を返す
Phase 2 抽出extract-design-tokens-from-designmd.sh が CSS トークンを取り出し、ページデータの JSON を組み立てる
Phase 3 整合検証（機械実行）validate-page-data.sh を実行する。全項目 PASS が次へ進む条件。FAIL は 3 回まで修正を試み、超過したら Phase 2 へ差し戻す
Phase 4 生成build-detail-page.sh がデザインシステム.html を出力する。portal_output_dir が渡されていれば build-portal.sh でポータルへ反映する

§5守り（禁止事項と機械検証）

禁止事項

  • 抽出結果の JSON や生成後の HTML を手作業で編集しない。直すのは抽出スクリプトの側
  • 共通 DESIGN.md に書かれていない値を推測で補完しない
  • トークンの値・命名に対する評価を成果物に書き込まない

機械検証

Phase 3 の validate-page-data.sh が全項目 PASS しない限り HTML は生成されない。3 回の修正で PASS しない場合は Phase 2 へ差し戻し、原因が抽出側にあることを明示して止まる。

デザインシステム生成

概要

共通DESIGN.mdの記載をデザインシステムHTMLへ転記する。

出力

デザインシステム.html。

入力

output_dir/プロジェクト共通/DESIGN.md。

抽出

colors、typography、spacing、rounded、components。

制約

トークンの良否や意図を評価しない。

フォールバック

frontmatter未検出時はCSS変数を機械的に参照する。

検証

生成ページの整合を確認する。

予想を裏切る挙動

DESIGN.mdにないトークンは追加しない。

参照

SKILL.md。

完了

生成物と検証結果を返す。

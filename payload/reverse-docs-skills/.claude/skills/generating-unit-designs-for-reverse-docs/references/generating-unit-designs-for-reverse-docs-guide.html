ユニット設計リバース

出力

facts
<verification_dir>/<kind>-<id>/facts/unit-facts.json。
設計書
検証済みfactsだけから生成する非画面ユニット設計書。

入力

api / table / batch / report / externalの対象コードとunit ID。

停止

根拠がなければstatus=STOPPED、source_paths=[]、structure=[]とし、uncertaintiesへ根拠不足の種別と理由を記録する。設計書は生成しない。

検証

各構造行の値、原文抜粋、1始まり行番号、原本SHA-256を照合する。test・fixture・自己テストは根拠として拒否する。

差し戻し

facts抽出へ戻す。

報告

unit kindと未確定事項。

注意

架空値を禁止。

挙動

意図は空欄ではなく未確定。

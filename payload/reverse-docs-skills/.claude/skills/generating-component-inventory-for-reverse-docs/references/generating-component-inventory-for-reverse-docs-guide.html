コンポーネント棚卸し生成スキル
generating-component-inventory-for-reverse-docs

対象リポジトリの UI 部品ファイルを走査し、ディレクトリ由来の分類だけを付けた コンポーネント棚卸し.html を生成する基盤ページ生成スキルの確定仕様。

対応 OSWindows WSL2 環境
検証状況共有エンジン（validate-page-data.sh・build-detail-page.sh）は他の詳細ページ生成スキルで動作確認済み。コンポーネント抽出（extract-component-inventory.sh）の単独実機検証は未実施。スキル専用のテストスクリプトは持たない
依存共有スクリプト shared/scripts/extract/extract-component-inventory.sh・shared/scripts/detail-pages/validate-page-data.sh・shared/scripts/detail-pages/build-detail-page.sh ／ 任意 shared/scripts/build-portal.sh
関連資料SKILL.md, references/test-cases.md

§1概要

リバース設計で UI の実装状況を把握するには、どの部品がどこに定義され、どれだけの数があるかを最初に確定させる必要がある。本スキルは対象リポジトリの .tsx・.jsx・.vue を走査し、ファイル単位で UI 部品を洗い出してコンポーネント棚卸し.html を作成する。

分類はディレクトリのパスから機械的に導く。責務が適切か、再利用できているか、重複していないかといった評価は一切行わない。良し悪しの判断は人間の担当であり、本スキルは事実の棚卸しに徹する。

本スキルがやること
UI 部品ファイルの走査・ディレクトリ由来の分類付け・コンポーネント棚卸し.html の生成
本スキルがやらないこと
コンポーネント設計の良否判定・重複の指摘・統合の提案（いずれも人間の判断） ／ アイコン参照の抽出（generating-icon-catalog-for-reverse-docs の担当）

起動引数

引数内容
target_repo_path走査対象のリポジトリルート。ここから下の .tsx・.jsx・.vue を探す
output_dirコンポーネント棚卸し.html の書き出し先ディレクトリ
portal_output_dir任意。渡された場合のみポータルへ反映する

対象リポジトリに .tsx・.jsx・.vue が 1 件も無い場合、本スキルは生成せず SKIP を返す。

§2出力

対象リポジトリ 1 つにつき、次の 1 点が生まれる。

コンポーネント棚卸し.html
検出した UI 部品の一覧。部品名・定義ファイルのパス・ディレクトリ由来の分類・総件数を持つ。output_dir の直下に置かれる

§3用語

コンポーネント
.tsx・.jsx・.vue のファイル単位で検出した UI 部品。1 ファイルを 1 件として数える
ディレクトリ由来の分類
定義ファイルが置かれたディレクトリ名をそのまま分類名に使う方式。ディレクトリ名の意図を推測して読み替えることはしない

§4動作フロー（Phase 1〜4）

Phase内容
Phase 1 走査対象の確認target_repo_path 配下に対象拡張子のファイルが存在するかを確認する。0 件なら生成せず SKIP を返す
Phase 2 抽出extract-component-inventory.sh が UI 部品を抽出し、ページデータの JSON を組み立てる
Phase 3 整合検証（機械実行）validate-page-data.sh --target-repo を実行する。全項目 PASS が次へ進む条件。FAIL は 3 回まで修正を試み、超過したら Phase 2 へ差し戻す
Phase 4 生成build-detail-page.sh がコンポーネント棚卸し.html を出力する。portal_output_dir が渡されていれば build-portal.sh でポータルへ反映する

§5守り（禁止事項と機械検証）

禁止事項

  • 抽出結果の JSON や生成後の HTML を手作業で編集しない。直すのは抽出スクリプトの側
  • 実コードに存在しない部品を補完しない
  • 責務・再利用性・重複の評価を成果物に書き込まない

機械検証

Phase 3 の validate-page-data.sh が全項目 PASS しない限り HTML は生成されない。3 回の修正で PASS しない場合は Phase 2 へ差し戻し、原因が抽出側にあることを明示して止まる。

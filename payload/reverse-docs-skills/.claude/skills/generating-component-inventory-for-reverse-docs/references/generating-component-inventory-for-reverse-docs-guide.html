コンポーネント棚卸し

概要

.tsx/.jsx/.vueの実在ファイルから棚卸しを生成する。

出力

コンポーネント棚卸し.html。

入力

target_repo_path、output_dir。

抽出

export名、props有無、ディレクトリ分類、被参照件数。

分類

components/pages/layouts等のディレクトリから機械的に導出する。

制約

責務や意味の推定をしない。

検証

決定的な整合検証を行う。

予想を裏切る挙動

自動分類はtaxonomy inferenceではない。

SKILL.md。

完了

生成物と検証結果を返す。

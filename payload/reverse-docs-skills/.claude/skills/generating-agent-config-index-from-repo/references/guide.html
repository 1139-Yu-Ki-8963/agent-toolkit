§1概要

AGENTS.md と CLAUDE.md は、AI エージェントが対象リポジトリで作業するときに最初に読む案内である。本スキルは対象リポジトリを分析し、そこで実際に確認できた事実だけを使って両ファイルの前半索引を生成する。

規約の本文をコードから発明することはしない。書けるのは、リポジトリの構成と、既に存在する規約ファイルへの参照パスだけである。AGENTS.md の後半（規約一覧）は RULES-INDEX のマーカーだけを置き、中身は複製しない。

本スキルがやること
リポジトリ構成の分析・前半索引の生成・既存規約への参照パスの確定
本スキルがやらないこと
規約本文の新規作成・既存規約の編集（いずれも人間の判断） ／ CLAUDE.md への規約一覧の記載

起動引数

引数 内容
target_repo_path 分析対象のリポジトリルート
template_root 雛形の所在ディレクトリ
output_dir AGENTS.md・CLAUDE.md の書き出し先ディレクトリ
rules_root 任意。既存規約の所在を明示する場合に渡す
mode 任意。生成の動作を切り替える場合に渡す

根拠が確認できない項目は、推測で埋めずに「根拠不足」として返す。

§2出力

対象リポジトリ 1 つにつき、次の 3 点が生まれる。

AGENTS.md
前半のリポジトリ索引と、対象リポジトリで確認できた規約の正確な参照パス。後半は RULES-INDEX のマーカーのみを置く
CLAUDE.md
前半のリポジトリ索引。規約本文・規約一覧は含めない
検証報告
根拠パス・規約参照の実在・両ファイルの重複状態を確認した結果

§3用語

根拠不足
分析で確認できなかった項目に与える扱い。推測で埋めない

§4動作フロー（Phase 1〜3）

Phase 内容
Phase 1 分析 target_repo_path を走査し、リポジトリ構成と既存規約の所在を確認する
Phase 2 規約参照の確定 確認できた規約ファイルの参照パスを確定する。実在しないパスは索引に載せない
Phase 3 生成と検証 雛形から AGENTS.md と CLAUDE.md を生成し、5 項目（前半項目の一致・RULES-INDEX マーカーの単一存在・CLAUDE.md への規約本文の非混入・プレースホルダーの残留なし・出力先の逸脱なし）を確認する

§5守り（禁止事項と機械検証）

禁止事項

  • 規約の本文をコードから発明しない
  • 実在しない参照パスを索引に載せない
  • CLAUDE.md に規約本文・規約一覧を書かない
  • 雛形のプレースホルダーを未解決のまま残さない

機械検証

Phase 3 の 5 項目の確認を通らない限り生成物を完成として扱わない。確認できない項目があれば「根拠不足」として返し、推測で埋めることはしない。

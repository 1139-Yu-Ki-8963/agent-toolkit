AGENTS/CLAUDE索引生成

対象リポジトリの実在情報から、AI設定ファイルの前半索引を生成するスキル。

概要

コードから確定できる索引と、明示された規約参照を分離する。

出力

AGENTS.md
前半のリポジトリ索引と、対象リポジトリで確認できた規約の正確な参照パス。
CLAUDE.md
前半のリポジトリ索引。規約本文・規約一覧は含めない。
検証報告
根拠パス、規約参照の実在、両ファイルの重複状態を確認した結果。

入力

target_repo_path、template_root、output_dir、任意の rules_root。

工程

  1. リポジトリの事実を収集する。
  2. 規約正本の実在パスを確認する。
  3. テンプレートへ展開し検証する。

作成区分

両ファイルの前半は共通索引。後半の規約読み込みはAGENTS.mdだけに置く。

禁止事項

規約、業務目的、AIの行動規範、未確認コマンド、架空のサンプル値を推測で作らない。

返却

status、artifacts、evidence_root、hintを返す。

予想を裏切る挙動

CLAUDE.mdは規約読み込みの代替ではない。

検証

参照パスの実在と、CLAUDE.mdへの規約重複なしを確認する。

参照

shared/templates/ai-assets/ と shared/references/納品物フォルダ体系.md。

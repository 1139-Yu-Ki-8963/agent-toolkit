# AGENTS/CLAUDE索引生成スキル

対象リポジトリを分析し、既存の事実から `AGENTS.md` と `CLAUDE.md` の前半索引を生成する。AIの振る舞い・承認・委任・停止条件などの規約はコードから発明しない。対象リポジトリに明示された規約正本がある場合だけ、`AGENTS.md` の後半へ正確なパスを参照として記載する。

## 使用タイミング

- リバース対象リポジトリへAI設定資産の索引を初回生成するとき
- リポジトリ構成や規約正本の配置が変わり、索引を再生成するとき

## 入力契約

| 引数 | 必須 | 内容 |
|---|---|---|
| `target_repo_path` | 必須 | 分析対象リポジトリの絶対パス |
| `template_root` | 必須 | `AGENTS.md` と `CLAUDE.md` のテンプレートを含むルート |
| `output_dir` | 必須 | 生成先ディレクトリ |
| `rules_root` | 任意 | 対象リポジトリで明示的に確定した規約ルート。未確認なら設定しない |
| `mode` | 任意 | `new` または既存索引の差分更新。既定は `new` |

## 作成区分

- **前半（両ファイル共通）**: リポジトリ名、目的、技術スタック、実行コマンド、ディレクトリ構造、リバース対象、成果物の正本・派生物、調査入口、検証出力先を、コード・設定・既存文書から根拠付きで記入する。
- **後半（AGENTS.mdのみ）**: 対象リポジトリで実在と適用範囲が確認できた規約ファイルを、正確な相対パスで参照する。規約本文や未確認のカテゴリは記載しない。
- **後半（CLAUDE.md）**: 規約本文・規約一覧・AIの行動規範を生成しない。前半の索引と、必要な入口情報だけを保持する。

## Phase 1: 事実を収集する

1. `README`、package/依存定義、ビルド・テスト設定、CI、実行スクリプト、主要ディレクトリを読む。
2. 実行コマンドは記載元と実行検証結果があるものだけ採録する。未実行のコマンドを成功例として書かない。
3. リバース対象は実在する種別・入口・出力ルートから確定する。業務目的・将来計画・非機能要求は索引へ推測記入しない。
4. 正本と派生物は、生成元・manifest・既存文書に明示された関係だけを記録する。

完了条件: 前半索引の各項目に根拠パスがあり、未確認事項が推測で埋まっていない。

## Phase 2: 規約参照を確定する

1. `rules_root` が指定された場合、その配下の実在ファイルを列挙する。
2. `rule.md` 等のパスは、対象リポジトリからの相対パスとして存在確認する。
3. `AGENTS.md` には「どのフォルダの、どの意図の規約か」と正確なパスを記載する。
4. 根拠がない規約カテゴリ、AIの振る舞い、承認・委任・停止条件を生成せず、不明事項として残す。

完了条件: AGENTS.mdの規約参照が実在パスだけで構成され、CLAUDE.mdに規約一覧が複製されていない。

## Phase 3: 生成と検証

テンプレートへ事実を展開し、次を検査する。

- 両ファイルの前半項目が同じ事実・同じパスを参照している
- AGENTS.mdの規約参照先がすべて実在する
- CLAUDE.mdに規約本文・未確認の規約パス・AI行動規範がない
- プレースホルダーが、対象リポジトリで確認できない値の代用として残っていない
- 出力先がテンプレートルートや対象リポジトリの無関係な場所へ逸脱していない

検証が失敗したら生成を確定せず、根拠不足として返す。

完了条件: 両ファイルと検証報告が `output_dir` に存在し、全検査が成功する。

## 返却形式

```text
status: 生成完了 | 根拠不足 | 検証失敗
artifacts: [AGENTS.md, CLAUDE.md, 検証報告]
evidence_root: <根拠の起点>
hint: <未確定事項または次工程>
```

## 重要な注意事項

- 規約本文をAGENTS.mdまたはCLAUDE.mdへコピーしない。
- `docs/rules/` のような推測の固定パスを書かない。対象リポジトリで確定した実在パスだけを使う。
- サンプル値、架空のコマンド、架空のスキル名、架空の規約カテゴリを作らない。
- 入力リポジトリへ変更を加えず、指定された出力先だけへ生成する。

## 予想を裏切る挙動

`CLAUDE.md` は規約読み込みの代替ではない。規約参照が必要な場合も、後半の読み込みは `AGENTS.md` だけに残す。

## 完了報告

`managing-agent-configs/references/skills/completion-report-format.md` の作業報告型に従う。固有の検証行として、前半共通項目の一致、AGENTS規約パス実在、CLAUDE規約重複なしを報告する。

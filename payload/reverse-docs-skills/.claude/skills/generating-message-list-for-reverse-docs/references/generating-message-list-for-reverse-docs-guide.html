メッセージ一覧生成スキル
generating-message-list-for-reverse-docs

メッセージ定義書.md をマニフェストへ変換し、整合検証を通過したデータだけから メッセージ一覧.html を生成する派生一覧スキルの確定仕様。

対応 OSWindows WSL2 環境
検証状況一覧生成エンジン（build-unit-list.sh）は画面一覧生成で実プロジェクト動作確認済み。メッセージ定義書のマニフェスト変換と専用検証（convert-message-doc-to-manifest.sh・validate-message-manifest.sh）の単独実機検証は未実施。スキル専用のテストスクリプトは持たない
依存共有スクリプト shared/scripts/convert-message-doc-to-manifest.sh・shared/scripts/validate-message-manifest.sh・shared/scripts/unit-list/build-unit-list.sh ／ 任意 shared/scripts/build-portal.sh

§1概要

メッセージ定義書.md は文書として書かれているため、そのままでは横断的に数えたり絞り込んだりできない。本スキルは定義書をマニフェストの JSON へ変換し、一覧として引けるメッセージ一覧.html を作成する。

本スキルは派生一覧である。元になるメッセージ定義書は先行工程が採録したものを読むだけで、定義書の中身を書き足したり言い換えたりすることはしない。

本スキルがやること
メッセージ定義書.md のマニフェスト変換・整合検証・メッセージ一覧.html の生成
本スキルがやらないこと
メッセージ定義書そのものの採録（generating-reverse-common-docs の担当） ／ メッセージ文言の良否判定

起動引数

引数内容
output_dirメッセージ定義書.md の所在であり、メッセージ一覧.html の書き出し先でもあるディレクトリ
portal_output_dir任意。渡された場合のみポータルへ反映する

output_dir にメッセージ定義書.md が存在しない場合、本スキルは生成せず SKIP を返す。

§2出力

対象リポジトリ 1 つにつき、次の 1 点が生まれる。

メッセージ一覧.html
メッセージ定義書に書かれた個々のメッセージを、横断で数えたり絞り込んだりできる形にまとめた一覧。定義書の記述をそのまま写した項目を持ち、文言の言い換えや補完は行わない。output_dir 配下の 一覧/メッセージ一覧/ に置かれる

§3用語

マニフェスト
一覧生成エンジンが読む JSON。定義書の記述を機械が扱える形へ写したもの
派生一覧
コードを直接走査せず、先行工程が作った文書を元に組み立てる一覧

§4動作フロー（Phase 1〜4）

Phase内容
Phase 1 原本の確認output_dir にメッセージ定義書.md が存在するかを確認する。無ければ生成せず SKIP を返す
Phase 2 マニフェスト変換（機械実行）convert-message-doc-to-manifest.sh が定義書をマニフェストの JSON へ変換する
Phase 3 整合検証（機械実行）validate-message-manifest.sh を実行する。全項目 PASS が次へ進む条件。FAIL は 3 回まで修正を試み、超過したら Phase 2 へ差し戻す
Phase 4 生成build-unit-list.sh がメッセージ一覧.html を出力する。portal_output_dir が渡されていれば build-portal.sh でポータルへ反映する

§5守り（禁止事項と機械検証）

禁止事項

  • マニフェストや生成後の HTML を手作業で編集しない。直すのは変換スクリプトの側
  • メッセージ定義書に書かれていない項目を補完しない
  • メッセージ文言の適否に関する評価を成果物に書き込まない

機械検証

Phase 3 の validate-message-manifest.sh が全項目 PASS しない限り HTML は生成されない。3 回の修正で PASS しない場合は Phase 2 へ差し戻し、原因が変換側にあることを明示して止まる。

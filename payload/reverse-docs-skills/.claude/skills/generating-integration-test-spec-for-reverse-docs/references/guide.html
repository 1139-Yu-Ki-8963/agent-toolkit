結合テスト仕様書の生成
generating-integration-test-spec-for-reverse-docs

複数の設計単位をまたぐ試験を、プロジェクト全体で1冊の仕様書へまとめる。

スキル情報
対応 OS Windows WSL2 環境
検証状況 生成、必須項目の検査、ポータル反映の手順を定義済み
依存 許可ツール: Read、Bash、Edit、Grep、Glob。SKILL.md本文で参照する実行用スクリプト: generation-engine/scripts/generate-integration-test-spec.sh、generation-engine/scripts/build-portal.sh
関連資料 SKILL.md、delivery-payload/references/output-layout.json
目次
  1. 概要
  2. 出力
  3. 動作フロー
  4. 検証

§1概要

画面、機能、API、テーブル、バッチ、帳票、外部連携のうち、2つ以上の設計単位をまたぐ連携だけを対象とする。

§2出力

複数の設計単位をまたぐ試験について、次の成果物と状態が生まれる。

結合テスト仕様書
操作手順、期待結果、障害時の回復方法を連携単位で確認できる文書。
ポータルから参照できる状態
生成した仕様書が納品物の入口から辿れる状態。

§3動作フロー

Phase 1 対象確定
  → Phase 2 仕様書生成・設計書の事実を記入
  → Phase 3 必須項目を検証・ポータル反映

§4検証

対象範囲に2つ以上の設計単位があり、操作手順、期待結果、障害時の回復方法が記入されていることを確認する。

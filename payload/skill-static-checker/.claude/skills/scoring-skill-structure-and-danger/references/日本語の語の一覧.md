# 日本語の語の一覧

このリファレンスは、SkillEvaluator が英語の見出しと語で調べる項目を、日本語のスキルで調べるときの見出しと語を持つ。`scripts/check-structure.mjs` は、この一覧と同じ値を持つ。値を変えるときは、このリファレンスとスクリプトを同じ変更で直す。

## 章の見出しの語

step 3-3 と 3-5 で使う。

| SkillEvaluator の見出し | 日本語のスキルの見出しか行 |
|---|---|
| `## Purpose` | 「目的:」の行 |
| `## Prerequisites` | 「## 前提ツール」 |
| `## Instructions`、`## Usage` | 「## phase <番号> <名前>」 |
| `## Available Scripts` | 「## 使用するスクリプト」 |
| `## Limitations` | 「## できないこと」 |
| `## Examples` | 「## 使い方の例」 |

`## Troubleshooting` に当たる章は求めない。雛形は、Troubleshooting に当たるものを、手順の中止の段落と、全スキル共通の決まりの「中止の決まり」の章としている。

## description の語

step 3-3 で使う。

| 語の種類 | 語 | 調べ方 |
|---|---|---|
| 使う場面の語 | 発動する場面は | description が持つ |
| 使わない場面の語 | 発動しない場面は | description が 100 字を超え、中身の広い語を持つときに、持つ |
| 中身の広い語 | データ、ファイル、管理する、処理する | 使わない場面の語と合わせて調べる。雛形の「対象を添えたときだけ使える語」の「もの」は、日本語の文で広く使うので、この検査では見ない |

## エラーの扱いの語

step 3-3 で使う。`SKILL.md` は、次の語のどれかを持つ。

中止、失敗、エラー

## 使わない語

step 3-3 で使う。

| 語 | 調べる範囲 | SkillEvaluator の当たる語 |
|---|---|---|
| あなた、私、私たち | description | i can、you should、your など |
| いろいろ、様々 | description | something、various など |
| 活用、促進、シナジー、パラダイム | `SKILL.md` の全文 | utilize、facilitate、leverage、paradigm、synergy |

## リファレンスで使わないファイル名

step 3-3 で使う。`references/` の `.md` のファイル名(拡張子を除く)は、次の名前と、数字だけの名前を使わない。

資料、メモ、その他、一時

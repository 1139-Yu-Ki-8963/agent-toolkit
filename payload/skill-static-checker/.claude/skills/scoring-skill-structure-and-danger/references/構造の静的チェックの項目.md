# 構造の静的チェックの項目

このリファレンスは、構造の静的チェックの項目ごとに、調べること、重さ、分野、減点、SkillEvaluator の当たるものを持つ。重さと減点の値は、SkillEvaluator(`src/skillevaluator/`)の値を写したものである。SkillEvaluator が減点の値を持たない項目は、元の重さごとの既定の値(HIGH は 15、MEDIUM は 10、LOW は 5)とする。重さの段階と点数の出し方は、リファレンス `references/点数の付け方.md` にある。

## フロントマターの項目

step 3-2 で、`scripts/check-schema.mjs` が調べる。分野は、すべて「正しさ」とする。

| 項目 | 調べること | 重さ(元の重さ) | 減点 | SkillEvaluator の当たるもの |
|---|---|---|---|---|
| フロントマターの有無 | `SKILL.md` が、1 行目の `---` から始まり、`---` の行で閉じるフロントマターを持つ | 重大(HIGH) | 15 | `validators/schema.py` の frontmatter_format |
| name と description の有無 | フロントマターが、空でない name と description を持つ | 重大(HIGH) | 15 | `models/skill.py` の必須の項目 |
| name の形 | name が、英小文字で始まり、英小文字と数字と、間に 1 つずつ置いたハイフンだけでできた 64 字以内の名前である | 重大(HIGH) | 15 | `validators/quality_score.py` の Invalid name format(15 点) |
| name の予約語 | name を `-` で区切った語が、anthropic と claude を持たない | 重大(HIGH) | 15 | `config/quality-default.yaml` の reserved_name(15 点) |
| name とフォルダの名前 | name が、スキルのフォルダの名前と同じである | 重大(HIGH) | 15 | `validators/schema.py` の name_consistency |
| description の字数 | description が 1,024 字以内である | 重大(HIGH) | 15 | `models/skill.py` の DESCRIPTION_MAX_LENGTH |
| XML のタグ | フロントマターのどの値も、XML のタグを持たない | 重大(HIGH) | 15 | `validators/quality_score.py` の XML tags(15 点) |
| 同じキー | フロントマターが、同じキーを 2 回持たない | 重大(HIGH) | 15 | `validators/schema.py` の duplicate_key |
| キーの型 | キーが、数、真偽、空の値として読まれない文字列である | 重大(HIGH) | 15 | `validators/schema.py` の yaml_syntax |
| BOM | `SKILL.md` が、UTF-8 の BOM で始まらない | 注意(MEDIUM) | 10 | `validators/schema.py` の manifest_bom |
| タブの字下げ | フロントマターの行が、タブで字下げされていない | 重大(HIGH) | 15 | `validators/schema.py` の yaml_syntax |
| alwaysApply と globs | フロントマターが、キー alwaysApply と globs を持たない | 重大(HIGH) | 15 | `models/skill.py` の FORBIDDEN_SKILL_FIELDS |
| metadata.version の形 | metadata.version があるときは、点で区切った 3 つの整数(1.2.3 の形)である | 重大(HIGH) | 15 | `models/skill.py` の SEMVER_RE |

## 本文とフォルダの項目

step 3-3 で、`scripts/check-structure.mjs` が調べる。日本語の語は、リファレンス `references/日本語の語の一覧.md` の値である。

| 項目 | 調べること | 重さ(元の重さ) | 分野 | 減点 | SkillEvaluator の当たるもの |
|---|---|---|---|---|---|
| 「目的:」の行 | 本文が「目的:」の行を持つ | 注意(LOW) | 見つけやすさ | 5 | `## Purpose`(5 点) |
| description の発動する場面 | description が「発動する場面は」を持つ | 注意(LOW) | 見つけやすさ | 10 | description の use、when(10 点) |
| description の一人称と二人称 | description が「あなた」「私」「私たち」を持たない | 注意(MEDIUM) | 見つけやすさ | 15 | first/second person(15 点) |
| description の曖昧な語 | description が「いろいろ」「様々」を持たない | 注意(MEDIUM) | 見つけやすさ | 15 | vague words(15 点) |
| description の広い語 | description が 100 字を超え、「データ」「ファイル」「管理する」「処理する」のどれかを持つときは、「発動しない場面は」を持つ | 注意(LOW) | 見つけやすさ | 5 | negative triggers(5 点) |
| 「## 前提ツール」の章 | 本文が「## 前提ツール」の章を持つ | 注意(LOW) | 信頼性 | 5 | `## Prerequisites`(5 点) |
| 「## phase」の章 | 本文が「## phase <番号> <名前>」の章を持つ | 注意(MEDIUM) | 正しさ | 10 | `## Instructions`(schema の MEDIUM) |
| 「## 使用するスクリプト」の章 | 本文が「## 使用するスクリプト」の章を持つ | 注意(MEDIUM) | 正しさ | 10 | `## Available Scripts`(10 点) |
| 使用するスクリプトの表 | `scripts/` があるときは、「## 使用するスクリプト」の章が、見出しの行と区切りの行と 1 行以上の行の表を持つ | 注意(MEDIUM) | 正しさ | 10 | No documented scripts in table format(10 点) |
| scripts の中身 | `scripts/` があるときは、その直下にファイルが 1 つ以上ある | 注意(MEDIUM) | 正しさ | 10 | scripts/ exists but contains no files(10 点) |
| 「## できないこと」の章 | 本文が「## できないこと」の章を持つ | 注意(LOW) | 信頼性 | 5 | `## Limitations`(5 点) |
| 「## 使い方の例」の章 | 本文が「## 使い方の例」の章を持つ | 注意(LOW) | 正しさ | 5 | No examples provided(5 点) |
| エラーの扱いの語 | `SKILL.md` が「中止」「失敗」「エラー」のどれかを持つ | 注意(LOW) | 信頼性 | 10 | error handling の mentioned(10 点) |
| 使わない語 | `SKILL.md` が「活用」「促進」「シナジー」「パラダイム」を持たない | 注意(LOW) | 効率 | 5 | complex/corporate language(5 点) |
| 行の繰り返し | `SKILL.md` の空でない行のうち、違う行が 7 割以上ある | 注意(LOW) | 効率 | 10 | High line repetition(10 点) |
| references の中の文書でないもの | `references/` が、`.md` の文書だけを持つ | 注意(LOW) | 効率 | 5 | Non-doc file in references/(5 点) |
| リファレンスのファイル名 | リファレンスのファイル名が、使わない名前と数字だけの名前でない | 注意(LOW) | 効率 | 5 | Non-descriptive filename(5 点) |
| リファレンスの参照の深さ | リファレンスが、ほかの `.md` への相対リンクを持たない(`../SKILL.md` を除く) | 注意(MEDIUM) | 効率 | 10 | Deeply nested references(10 点) |
| SKILL.md が指さないリファレンス | `references/` の下のすべてのファイルのパスを、`SKILL.md` が持つ | 注意(MEDIUM) | 効率 | 10 | 規約 skill-writing-rule の「リファレンス」規則 2。減点は Deeply nested references と同じ |
| README.md へのリンク | `SKILL.md` が、README.md への相対リンクを持たない | 注意(MEDIUM) | 正しさ | 5 | SKILL.md references README.md(5 点) |
| 相対リンクの先 | `SKILL.md` とリファレンスの相対リンクの先が、すべてあり、スキルのフォルダの中にある | 重大(HIGH) | 正しさ | 15 | `validators/hygiene.py` の Dead link |
| パスの区切り | `SKILL.md` とリファレンスのパスが、区切りに「\」を使わない | 注意(MEDIUM) | 正しさ | 10 | Windows-style paths(10 点) |
| スクリプトのシェバンと実行権限 | `scripts/` と `scripts/tests/` のファイルが、1 行目の `#!` と実行権限を持つ | 注意(MEDIUM) | 正しさ | 10 | 規約 skill-writing-rule の「スキルのフォルダが持つもの」規則 1 |
| スクリプトの説明書とテスト | `scripts/` の直下のスクリプトごとに、名前を含む `scripts/tests/` のファイルと、名前を含むリファレンスの見出しがある | 注意(MEDIUM) | 信頼性 | 10 | 規約 skill-writing-rule の「スクリプト」規則 1 |
| 部品の版の固定 | 「## 前提ツール」の表の、区分「スキルごとのツール」の行の版が、1.2.3 の形の 1 つの版である | 注意(MEDIUM) | 信頼性 | 10 | `validators/hygiene.py` の Unpinned |
| スキルのフォルダが持つもの | スキルのフォルダの、`.` で始まらないものが、`SKILL.md`、`references/`、`scripts/` だけで、`scripts/` の下のフォルダが `tests/` だけである | 注意(LOW) | 正しさ | 5 | `validators/schema.py` の unexpected_file |

1 つの項目に当たる箇所が 2 つ以上あるときは、項目ごとに 1 件の指摘にまとめ、当たる箇所を指摘の中身に並べる。

## 道具ごとの読み込みの項目

step 3-4 で、`scripts/check-harness.mjs` が調べる。この項目は助言で、点数と合否に入れない。

| 項目 | 調べること | 重さ(元の重さ) | 分野 | 減点 | SkillEvaluator の当たるもの |
|---|---|---|---|---|---|
| 同じ名前のスキル | 調べるスキルと同じフォルダと、ホームのフォルダの下の 10 の置き場に、同じ name のスキルがない | 参考(INFO) | なし | 0 | `harness/overlay.py` の duplicate_name と user copy、`harness/profiles/claude-code.yaml` の CC-PRECEDENCE と CC-USER-COPY |

10 の置き場は、ホームのフォルダの下の `.agents/skills`、`.claude/skills`、`.codex/skills`、`.github/skills`、`.opencode/skills`、`.opencode/skill`、`.hermes/skills`、`.copilot/skills`、`.openclaw/skills`、`.config/opencode/skills` である。

## 日本語の章の中身を見る基準

step 3-5 で、実行者が AI による推論で見る。見るのは、`SKILL.md` にある「目的:」の行と、次の表の章だけとする。章がないときは、step 3-3 の項目が指摘するので、この基準では見ない。

| 項目 | 中身があるとする条件 | 重さ | 分野 | 減点 |
|---|---|---|---|---|
| 「目的:」の行の中身 | 「目的:」の後ろに、何のために何をするかを言う 1 文以上がある | 注意 | 見つけやすさ | 5 |
| 「## 前提ツール」の章の中身 | 章が、表か「なし」の 1 行を持つ | 注意 | 信頼性 | 5 |
| 「## 使用するスクリプト」の章の中身 | 章が、表か「なし」の 1 行を持つ | 注意 | 正しさ | 10 |
| 「## できないこと」の章の中身 | 章が、「- 扱わない依頼:」と「- 扱えない入力:」の 2 行を持ち、2 行とも、一覧か「なし」を値に持つ | 注意 | 信頼性 | 5 |
| 「## 使い方の例」の章の中身 | 章が、依頼の文の例を 1 つ以上と、最終出力の表の、ユーザーへの完了の報告を除く行ごとの例を持つ | 注意 | 正しさ | 5 |

条件に合わない例は、見出しだけで次の章が始まる章、山かっこの欄や「TODO」「未定」「あとで書く」だけを持つ章、ほかのスキルの文を写したままで、このスキルの名前や入力と食い違う章である。
指摘の元の重さは、「LOW」とする。ただし、「## 使用するスクリプト」の章の中身は「MEDIUM」とする。

## 参考の数の値

step 3-3 で、`scripts/check-structure.mjs` が数える。数の上限は規約に入れないので、指摘にせず、報告に参考として載せる。上限は、SkillEvaluator の既定の値である。

| 数の値 | 数え方 | 参考の上限 | SkillEvaluator の当たるもの |
|---|---|---|---|
| SKILL.md の行数 | 改行で区切った行の数 | 500 行 | `constants.py` の QUALITY_MAX_BODY_LINES |
| SKILL.md の推定トークン | 字数を 4 で割った数 | 5,000 | `config/quality-default.yaml` の token_budget |
| SKILL.md の大きさ | UTF-8 のバイトの数 | 32,768 バイト | `validators/schema.py` の manifest_size |
| SKILL.md の最も長い行の字数 | 1 行の字数の最大 | 2,000 字 | 道具ごとの読み込みの上限 |
| description の字数 | description の字数 | 200 字 | `config/quality-default.yaml` の description_too_long |
| name の字数 | name の字数 | 5 字以上 | `validators/quality_score.py` の Skill name very short |

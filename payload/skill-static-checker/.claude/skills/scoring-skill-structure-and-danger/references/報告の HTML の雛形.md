# 報告の HTML の雛形

このリファレンスは、step 5-2 で `scripts/render-html.mjs` が書く報告の HTML の名前と、並びと、デザインの決まりを持つ。

## 報告の HTML の形

- ファイルの名前: `<出力先のフォルダ>/<調べたスキルの名前>-構造と危険の静的チェック-<年月日時分>.html`。年月日時分は、`202611191230` のような 12 桁とする。名前は、step 5-1 で `scripts/score.mjs` が決めて点数の JSON に書き、`scripts/render-html.mjs` はその名前で書く。同じ名前のファイルがあるときは、`scripts/render-html.mjs` は書かずに終了コード 2 で終わる。
- 1 つのファイルだけで開ける。外部のファイル(スタイルシート、スクリプト、画像、フォント)を読み込まない。
- 文書の言語は日本語(`lang="ja"`)とし、明るい表示と暗い表示の両方の色を持つ。
- 指摘の中身は、山かっこと引用符を文字に置き換えてから書く。

並びは、次の順とする。

| 順 | 部分 | 中身 |
|---|---|---|
| 1 | 題名 | `<調べたスキルの名前> の構造と危険の静的チェック`、その下に薄い字で、調べたスキルのフォルダ、報告の出力先のフォルダ、作った日時 |
| 2 | 結果の札 | 1 枚目は、構造の点数を大きな字で出し、下の行に構造の合否と合格ラインと危険の合否を出す。2 枚目からは、検査ごとに、日本語の検査の名前と指摘の数を大きな字で出し、下の行に重さごとの件数を出す。同じ名前のスキル、見えない文字、部品の脆弱性の検査は、参考の件数も出す |
| 3 | 構造の点数の出し方 | 分野ごとの重み、減点の合計、分野の点数、重みをかけた点と、構造の点数 |
| 4 | 最初に直す指摘 | 重さ「重大」の指摘の表 |
| 5 | 指摘の一覧 | すべての指摘の表(重さ、検査、項目、ファイル、行、中身、直し方、区分、減点と分野)。危険、構造、助言の順、同じ区分では重大、注意、参考の順 |
| 6 | 参考の数の値 | 項目、値、参考の上限、上限を超えたか |
| 7 | 検査ごとの状態 | 検査、状態(済み、対象なし、調べられなかった)、指摘の数、補足(調べた部品か見分けたライセンス) |

列「検査」の値は、次の表の日本語の検査の名前とする。対応は、`scripts/score.mjs` が持ち、点数の JSON に書く。

| 指摘の JSON の検査の名前 | 日本語の検査の名前 |
|---|---|
| check-schema | フロントマターの形 |
| check-structure | 本文とフォルダの形 |
| check-harness | 同じ名前のスキル |
| ai-structure | 日本語の章の中身(AI の推論) |
| check-secrets | 秘密の値と個人の情報 |
| check-unicode | 見えない文字 |
| check-code-risk | 危ないコードとコマンド |
| check-license | ライセンス |
| check-dependencies | 部品の脆弱性 |
| ai-danger | AI を乗っ取る書き方(AI の推論) |

## デザインの決まり

- 色、文字、並びは、`scripts/render-html.mjs` の `<style>` の 1 つの定義だけで決める。色は、緑を合格、赤を重さ「重大」と不合格、黄を注意を要するもの(重さ「注意」、参考の上限を超えた値、合否の「調べきれなかった」)、青を重さ「参考」に使う。
- 題名の下に、薄い字で、調べたスキルのフォルダと作った日時を置く。ほかの入力のパスは、その間に置く。
- 結果の札は、1 枚目を合否か点数の札とし、大きな字で合否か点数を出す。2 枚目からは、検査ごとの指摘の数を大きな字で出し、札の下の行に重さごとの件数を「重大 n 件、注意 n 件」の形で出す(重さ「参考」を持つ検査は「、参考 n 件」を足す)。
- 「最初に直す指摘(重さ「重大」)」の節は、重大の指摘がないとき、「重さ「重大」の指摘は、ありません。」と書く。
- 「指摘の一覧」の表は、列「重さ」「検査」「項目」「ファイル」「行」「中身」「直し方」から始め、検査に固有の列をその後ろに置く。列「検査」の値は、日本語の検査の名前とする。行がない指摘の列「行」は「なし」とする。
- 「検査ごとの状態」の表は、列「検査」「状態」「指摘の数」「補足」とする。検査に固有の数(候補の数、調べた部品)は、列「補足」に書く。

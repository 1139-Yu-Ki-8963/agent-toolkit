# 報告の HTML の雛形

このリファレンスは、step 5-2 で `scripts/render-html.mjs` が書く報告の HTML の名前と、並びを持つ。報告の HTML は、SkillEvaluator の `reporting/html.py` の形をまねる。

## 報告の HTML の形

- ファイルの名前: `<出力先のフォルダ>/<調べたスキルの名前>-構造と危険の静的チェック-<年月日時分>.html`。年月日時分は、`202611191230` のような 12 桁とする。同じ名前のファイルがあるときは、スクリプトは書かずに終了コード 2 で終わる。
- 1 つのファイルだけで開ける。外部のファイル(スタイルシート、スクリプト、画像、フォント)を読み込まない。
- 文書の言語は日本語(`lang="ja"`)とし、明るい表示と暗い表示の両方の色を持つ。
- 指摘の中身は、山かっこと引用符を文字に置き換えてから書く。

並びは、次の順とする。

| 順 | 部分 | 中身 |
|---|---|---|
| 1 | 題名 | `<調べたスキルの名前> の構造と危険の静的チェック`、調べたスキルのフォルダ、作った日時 |
| 2 | 結果の札 | 構造の点数と合否と合格ライン、危険の合否と重さごとの数、構造の指摘の数、道具ごとの読み込みの助言の数 |
| 3 | 構造の点数の出し方 | 分野ごとの重み、減点の合計、分野の点数、重みをかけた点と、構造の点数 |
| 4 | 最初に直す指摘 | 重さ「重大」の指摘の表 |
| 5 | 指摘の一覧 | すべての指摘の表(重さ、区分、検査、項目、ファイル、行、中身、直し方、減点と分野)。危険、構造、助言の順、同じ区分では重大、注意、参考の順 |
| 6 | 参考の数の値 | 項目、値、参考の上限、上限を超えたか |
| 7 | 検査ごとの状態 | 検査、状態(済み、対象なし、調べられなかった)、指摘の数、調べた部品か見分けたライセンス |

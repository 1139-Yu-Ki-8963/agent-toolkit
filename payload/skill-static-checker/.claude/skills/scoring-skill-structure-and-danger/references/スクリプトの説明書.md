# スクリプトの説明書

このリファレンスは、`scripts/` のスクリプト 1 本ごとに、何をするか、呼び方、終了コード、テストと、空行とコメント行を除く 1 行ごとの処理と理由を持つ。スクリプトは、空行とコメント行を持たないので、表の「行」は、ファイルの行の番号と同じである。

10 本のスクリプトは、次の決まりを同じく持つ。

- 外部の npm のパッケージを使わず、node の標準の部品だけを使う。
- 終了コードは、指摘がなければ 0、指摘があれば 1、引数かファイルが誤っていれば 2 とする。
- 終わりは `process.exitCode` で決め、`process.exit` を呼ばない。標準出力がパイプのときに、書き終わる前の JSON が切れないようにするためである。

## check-schema.mjs の説明書

このスクリプトは、調べるスキルの `SKILL.md` のフロントマターの形を調べ、構造の指摘を JSON で出す。
呼び方は `node scripts/check-schema.mjs <調べるスキルのフォルダ> [--out <指摘の JSON のパス>]` で、`--out` がなければ、JSON を標準出力に出す。
終了コードは、指摘がなければ 0、指摘があれば 1、引数が誤っているか、フォルダに `SKILL.md` がないか、JSON を書けなければ 2 とする。
テストは `node scripts/tests/test-check-schema.mjs` で、引数なしで実行する。

このスクリプトは、指摘の JSON のフォルダの `.json` のファイルをすべて読み、構造の点数と危険の合否を出して、点数の JSON を出す。
呼び方は `node scripts/score.mjs <指摘の JSON のフォルダ> [--out <点数の JSON のパス>]` で、`--out` がなければ、JSON を標準出力に出す。
終了コードは、指摘がなければ 0、指摘があれば 1、引数が誤っているか、フォルダがないか、指摘の JSON が 1 つもないか、読めない JSON か形の違う JSON があるか、点数の JSON を書けなければ 2 とする。

# スクリプトの説明書

このリファレンスは、`scripts/` のスクリプト 1 本ごとに、何をするか、呼び方、終了コード、テストと、空行とコメント行を除く 1 行ごとの処理と理由を持つ。スクリプトは、空行とコメント行を持たないので、表の「行」は、ファイルの行の番号と同じである。

14 本のスクリプトは、次の決まりを同じく持つ。

- 外部の npm のパッケージを使わず、node の標準の部品だけを使う。
- 終了コードは、指摘がなければ 0、指摘があれば 1、引数かファイルが誤っていれば 2 とする。
- 終わりは `process.exitCode` で決め、`process.exit` を呼ばない。標準出力がパイプのときに、書き終わる前の JSON が切れないようにするためである。

## make-temp-dir.mjs の説明書

このスクリプトは、OS の一時フォルダの下に、名前が `scoring-skill-structure-and-danger-` で始まる一時フォルダを作り、引数の名前の下のフォルダも作って、一時フォルダの絶対パスを、区切りを `/` にして標準出力に 1 行出す。
呼び方は `node scripts/make-temp-dir.mjs [<作る下のフォルダの名前>...]` とする。
終了コードは、作れたら 0、下のフォルダの名前がパスを持つか、フォルダを作れなければ 2 とする。
テストは `node scripts/tests/test-make-temp-dir.mjs` で、引数なしで実行する。

| 行 | 処理 | 理由 |

| 2 | 一時でない名前のフォルダを作る関数と、フォルダを作る関数を読み込む | 一時フォルダと、その下のフォルダを作るため |
| 3 | パスをつなぐ関数、最後の名前を取る関数、パスの区切りを読み込む | パスを作り、区切りを `/` にするため |

# スキルの構造と危険の静的チェック

## 全体像

- 目的: スキルのフォルダを動かさずに調べ、構造の点数と危険の合否を出して、配る前と使う前に直すところを一目で分かるようにする。
- 全体の決まり: スキルは、調べるスキルのフォルダのファイルを読むだけにし、書き換えない。

## できないこと

- 扱わない依頼: 調べるスキルを動かして確かめる依頼、同じ指示を繰り返す節や役目が重なるスキルを探す依頼、雛形や規約との照合の依頼、見つけた指摘を直す依頼
- 扱えない入力: SKILL.md を持たない調べるスキルのフォルダ、書けない報告の出力先のフォルダ、同じ分に同じスキルの報告の HTML を書いた報告の出力先のフォルダ

## 使い方の例

依頼の文の例:

```text
skills/fixing-skill を、構造と危険の静的チェックにかけて。報告は sample-reports に書いて。
```

報告の HTML の例:

```text
sample-reports/fixing-skill-構造と危険の静的チェック-202611201330.html
(構造の点数 97.0 点と合格、危険の合格、分野ごとの減点、指摘の一覧、参考の数の値、検査ごとの状態を持つ 1 ファイルの HTML)
```

構造の点数と危険の合否の例:

```text
構造の点数と危険の合否
- 構造の点数: 97.0 点(合格ライン 70 点、合格)
- 危険の合否: 合格(重大 0 件、注意 0 件、参考 0 件)
- 構造の指摘: 重大 0 件、注意 2 件
- 道具ごとの読み込みの助言: 0 件
- 調べられなかった検査: なし
- 報告の HTML: sample-reports/fixing-skill-構造と危険の静的チェック-202611201330.html
```

## phase 1 全スキル共通の決まりの読み込みと前提ツールの準備

- phase の入力: なし
- phase の出力: なし
- 合格の条件:
  - 全スキル共通の決まりが、文脈に読み込まれている。
  - 中止で終わるときは、中止の表示の step の番号が、1-1、1-2、1-4、1-5 のどれかである。
  - 前提ツールの表のすべての行の「ツールの有無を確かめるコマンド」の終了コードが、0 である。

### step 1-1 全スキル共通の決まりを読む

#### 手順

`references/全スキル共通の決まり.md` を、ファイルを読むツールで全文読む。

読めないときは、中止し、次の文面を表示する。

**step 1-1 で中止しました**
- 理由: <SKILL.md があるフォルダ>/references/全スキル共通の決まり.md を読めない。
- ユーザーが次にすること: スキルのフォルダにこのファイルがあるかを確かめ、なければ、スキルを入れ直してから、もう一度実行する。
- 中止までの成果物: なし

#### ── step 1-1 の情報 ──

- 種別: 固定の手順
- 入力: なし
- 出力: なし

### step 1-2 前提ツールがあるかを探す

#### 手順

「前提ツール」の章の表の 1 行ごとに、コマンドを実行するツールで「ツールの有無を確かめるコマンド」を実行し、表のすべての行を実行したら、次の段落へ進む。
表の行は、常に 1 行以上ある。

終了コードが 0 でないツールの名前と区分を、「不足しているツールの一覧」に入れたら終わる。

#### ── step 1-2 の情報 ──

- 種別: 固定の手順
- 入力: なし
- 出力: 不足しているツールの一覧を step 1-3 から 1-5 へ渡す

### step 1-3 不足している前提ツールがあるかを見る [分岐]

#### 手順

「不足しているツールの一覧」が 0 件かを見る。

0 件なら、step 2-1 へ進む。

1 件以上なら、step 1-4 へ進む。

#### ── step 1-3 の情報 ──

- 種別: 固定の手順
- 入力: 不足しているツールの一覧を step 1-2 から受け取る
- 出力: なし

### step 1-4 不足している前提ツールをインストールするかをユーザーに聞く [ユーザー確認]

#### ユーザーに見せる文面

ユーザー確認。

質問の文:

```text
<不足しているツールの名前の一覧> がありません。インストールしますか。
```

| 表示する名前 | 選ぶと何が起こるか | 行き先 |
|---|---|---|
| インストールする(推奨) | 不足しているツールをインストールして、次の step へ進む。 | step 1-5 |
| やめる | 今の環境のまま、スキルを中止する。 | 中止 |

推奨する理由: 3-1 から 3-4、3-7、4-1 から 4-5、4-8、5-1、5-2、5-4、6-1 の実行に、このツールが要るため。

#### 手順

「ユーザーに見せる文面」の質問を、選択肢を提示するツールで提示し、回答を待つ。

選択肢にない回答のときは、同じ質問をもう一度表示する。

「インストールする」なら、step 1-5 へ進む。

# スキルの重複の検査

## 全体像

- 目的: スキルのフォルダの中で同じ指示を繰り返す節と、役目が重なるほかのスキルを見つけ、配る前と使う前に、まとめるところを一目で分かるようにする。節どうしの近さは、本文を外部へ送らずに、手元で測る。
- 全体の決まり: スキルは、調べるスキルのフォルダと、比べるスキルの置き場のファイルを読むだけにし、書き換えない。

## できないこと

- 扱わない依頼: 構造と危険の静的チェックの依頼、調べるスキルを動かして確かめる依頼、雛形や規約との照合の依頼、見つけた重複を直す依頼、言葉を言い換えて同じ指示を書いた節を探す依頼(文字の近さでは見つからない)、`scripts/` のスクリプトと `references/` の下のフォルダの重複を探す依頼、`references/全スキル共通の決まり.md` の文を写した節を探す依頼、置き場の中のすべてのスキルの組を比べる依頼、保存した目録や SKILL.md の全文でスキルどうしを比べる依頼
- 扱えない入力: SKILL.md を持たない調べるスキルのフォルダ、ないフォルダを指す比べるスキルの置き場、書けない報告の出力先のフォルダ、同じ分に同じスキルの報告の HTML を書いた報告の出力先のフォルダ

## 使い方の例

依頼の文の例:

```text
skills/fixing-skill を、重複の検査にかけて。報告は sample-reports に書いて。
```

報告の HTML の例:

```text
sample-reports/fixing-skill-重複の検査-202611201330.html
(重複の検査の合否、指摘の一覧、1 本の中の重複の候補と判定、スキルどうしの重なりの候補と判定、検査ごとの状態を持つ 1 ファイルの HTML)
```

重複の検査の合否の例:

```text
重複の検査の合否
- 合否: 合格(重大 0 件、注意 1 件)
- 1 本の中の重複: 候補 2 件、指摘 0 件、済み
- スキルどうしの重なり: 比べたスキル 13 本、指摘 1 件、済み
- 判定がない候補: なし
- 報告の HTML: sample-reports/fixing-skill-重複の検査-202611201330.html
```

## phase 2 入力の確定

- phase の入力: 調べるスキルのフォルダ、報告の出力先のフォルダ、比べるスキルの置き場
- phase の出力: 確定した依頼
- 合格の条件:

# スクリプトの説明書

このリファレンスは、`scripts/` のスクリプト 1 本ごとに、何をするか、呼び方、終了コード、テストと、空行とコメント行を除く 1 行ごとの処理と理由を持つ。スクリプトは、空行とコメント行を持たないので、表の「行」は、ファイルの行の番号と同じである。

9 本のスクリプトは、次の決まりを同じく持つ。

- 外部の npm のパッケージを使わず、node の標準の部品だけを使う。ネットワークにつながらない。
- 終了コードは、正常に終われば 0、引数かファイルが誤っていれば 2 とする。merge-judgments.mjs は合否が合格でなければ、save-judgment.mjs は形と違う返り値があれば、check-outputs.mjs はないパスがあれば、1 とする。
- 終わりは `process.exitCode` で決め、成功の経路で `process.exit` を呼ばない。標準出力がパイプのときに、書き終わる前の JSON が切れないようにするためである。

## make-temp-dir.mjs の説明書

このスクリプトは、OS の一時フォルダの下に、名前が `checking-skill-duplication-` で始まる一時フォルダを作り、その絶対パスを `/` 区切りで標準出力に 1 行出す。
呼び方は `node scripts/make-temp-dir.mjs [<作る下のフォルダの名前>...]` で、下のフォルダの名前を渡すと、一時フォルダの下にそのフォルダも作る。
終了コードは、作れたら 0、下のフォルダの名前がパスを持つか、フォルダを作れなければ 2 とする。
テストは `node scripts/tests/test-make-temp-dir.mjs` で、引数なしで実行する。

|---|---|---|

| 2 | 一時フォルダを作る関数と、フォルダを作る関数を読み込む | 一時フォルダと下のフォルダを作るため |
| 3 | パスをつなぐ関数、最後の名前を取る関数、OS のパスの区切りを読み込む | 下のフォルダの名前を確かめ、出すパスの区切りを `/` にするため |
| 4 | OS の一時フォルダを求める関数を読み込む | 3 つの OS で、一時フォルダの置き場を同じ書き方で求めるため |
| 5 | 引数と、一時フォルダの名前の頭 `checking-skill-duplication-` を決める | remove-temp-dir.mjs が消してよいフォルダを、名前で見分けられるようにするため |

終了コードは、正常に終われば 0、引数が誤っているか、フォルダに `SKILL.md` がないか、ファイルを読めないか、JSON を書けなければ 2 とする。

## save-judgment.mjs の説明書

このスクリプトは、一時フォルダの judge-1.txt と judge-2.txt(判定者の返り値の文)から、`json` のコードブロックを取り出して形を確かめ、judge-1.json と judge-2.json に書く。形と違う返り値は、理由だけを持つ判定の JSON(`{"error": "<理由>"}`)に書く。
呼び方は `node scripts/save-judgment.mjs <一時フォルダのパス>` で、判定の JSON ごとに「judge-<番号>.json: 形のとおり」か「judge-<番号>.json: 形と違う(<理由>)」の 1 行を標準出力に出す。
終了コードは、2 つとも形のとおりなら 0、形と違う返り値があれば 1、引数が誤っているか、返り値の文のファイルを読めないか、判定の JSON を書けなければ 2 とする。

| 3 | パスをつなぐ関数を読み込む | 一時フォルダの中のファイルのパスを求めるため |
| 4 | 引数から一時フォルダのパスを取り出す | 読むファイルと書くファイルの置き場を決めるため |

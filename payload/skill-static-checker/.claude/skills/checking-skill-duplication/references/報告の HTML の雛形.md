# 報告の HTML の雛形

このリファレンスは、step 5-2 で `scripts/render-html.mjs` が書く報告の HTML の名前と、並びを持つ。

## 報告の HTML の形

- ファイルの名前: `<出力先のフォルダ>/<調べたスキルのフォルダの名前>-重複の検査-<年月日時分>.html`。年月日時分は、`202611191230` のような 12 桁とする。名前は、step 5-1 で `scripts/merge-judgments.mjs` が決めて結果の JSON に書き、`scripts/render-html.mjs` はその名前で書く。同じ名前のファイルがあるときは、`scripts/render-html.mjs` は書かずに終了コード 2 で終わる。
- 1 つのファイルだけで開ける。外部のファイル(スタイルシート、スクリプト、画像、フォント)を読み込まない。
- 文書の言語は日本語(`lang="ja"`)とし、明るい表示と暗い表示の両方の色を持つ。
- 指摘の中身と判定の理由は、山かっこと引用符を文字に置き換えてから書く。

並びは、次の順とする。

| 順 | 部分 | 中身 |
|---|---|---|
| 1 | 題名 | `<調べたスキルのフォルダの名前> の重複の検査`、調べたスキルのフォルダ、比べたスキルの置き場、作った日時 |
| 2 | 結果の札 | 合否と重さごとの数、検査ごとの指摘の数と重さごとの数 |
| 3 | 合否の決め方 | 判定者 2 人の判定から重さと合否を決める決まり |
| 4 | 最初に直す指摘 | 重さ「重大」の指摘の表 |
| 5 | 指摘の一覧 | すべての指摘の表(重さ、検査、項目、ファイル、行、中身、直し方、相手、文字の近さ、判定の理由)。重大、注意の順 |
| 6 | 1 本の中の重複の候補と判定 | 候補、文字の近さ、節 1、節 2、判定者 2 人の判定、判定の理由 |
| 7 | スキルどうしの重なりの候補と判定 | スキル、文字の近さ、判定者 2 人の判定、判定の理由 |
| 8 | 検査ごとの状態 | 検査、状態(済み、対象なし、調べきれなかった)、指摘の数、補足(候補の数、上限を超えて判定しなかった候補の数、読めないスキル)と、判定がない候補と、形と違う判定 |

## デザインの決まり

- 色、文字、並びは、`scripts/render-html.mjs` の `<style>` の 1 つの定義だけで決める。色は、緑を合格、赤を重さ「重大」と不合格、黄を注意を要するもの(重さ「注意」、参考の上限を超えた値、合否の「調べきれなかった」)、青を重さ「参考」に使う。
- 題名の下に、薄い字で、調べたスキルのフォルダと作った日時を置く。ほかの入力のパスは、その間に置く。
- 結果の札は、1 枚目を合否か点数の札とし、大きな字で合否か点数を出す。2 枚目からは、検査ごとの指摘の数を大きな字で出し、札の下の行に重さごとの件数を「重大 n 件、注意 n 件」の形で出す(重さ「参考」を持つ検査は「、参考 n 件」を足す)。
- 「最初に直す指摘(重さ「重大」)」の節は、重大の指摘がないとき、「重さ「重大」の指摘は、ありません。」と書く。
- 「指摘の一覧」の表は、列「重さ」「検査」「項目」「ファイル」「行」「中身」「直し方」から始め、検査に固有の列をその後ろに置く。列「検査」の値は、日本語の検査の名前とする。行がない指摘の列「行」は「なし」とする。
- 「検査ごとの状態」の表は、列「検査」「状態」「指摘の数」「補足」とする。検査に固有の数(候補の数、調べた部品)は、列「補足」に書く。

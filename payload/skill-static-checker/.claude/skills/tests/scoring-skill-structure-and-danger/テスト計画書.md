## 使わなかった技法と理由

| 技法 | 使ったか | 理由 |
|---|---|---|
| 同値分割 | 使った | IN-1(シンボリックリンクのフォルダ)、IN-3(読めない SKILL.md)、OUT-2(構造の合格と不合格、危険の合格と不合格)、SC-1 から SC-10 に当てた |
| 境界値分析 | 使った | PV-5(0 件と 1 件)、PV-6(0 件)、OUT-2 の構造の点数の合格ライン 70 点(64.0 点の例)に当てた |
| デシジョンテーブル | 使った | IN-1 と IN-2 の、ある、なしの組み合わせに当てた。両方あり(TC-15)、IN-1 なし(TC-24)、IN-2 なし(TC-25)。両方なしは、step 2-2 が 1 回の質問にまとめて聞く同じ段落を通るので、片方ずつの 2 件で段落を確かめる |
| ペアワイズ | 使わない | 開始時の入力のうち、ある、なしを変えられる項目が IN-1 と IN-2 の 2 つだけで、デシジョンテーブルで組み合わせを見る |
| 状態遷移 | 使わない | スキルが、やり直しの step を持たない |
| ユースケース | 使わない | スキルが、要件定義書を持たない(設計書から作った) |
| 命令網羅 | 使った | phase 3 から 5 の手順の段落(P3-1 から P3-3、P4-1、P4-2、P5-1 から P5-3)と、照合のスクリプト(SC-11 から SC-14)に当てた |
| 分岐網羅 | 使った | BR-1-3-1 に当てた。BR-1-3-2 と CH-1-4-1 から CH-1-4-3 は、実行環境で作れない |
| 条件網羅 | 使わない | スキルの分岐の step(step 1-3)の条件が、「0 件か」の 1 つだけである |
| 経路網羅 | 使った | 開始から最終出力までの経路(TC-15)と、中止までの経路(AB-1-1、AB-3-2、AB-5-2)に当てた |

## 合否と中断の基準

- 全体の合否の基準: スクリプトで確かめるテストケース(TC-1 から TC-14)の全件が終了コード 0 で合格し、そのあとに流すスキルを流して確かめるテストケース(TC-15 から TC-34)の全件が、期待する結果と一致したときに、全体を合格とする。
- 中断する step の番号: スクリプトで確かめるテストケースが 1 件でも不合格なら、スキルを流して確かめるテストケースを流さずに中断する。スキルを流すシナリオで、期待しない step(期待する結果にない step の番号)で中止の表示が出たら、そのシナリオを中断し、残りのシナリオを流す。
- 再開の基準: 不合格の原因を直したあとに、中断したテストケースから流し直す。
- 最初に流すケース: TC-15(依頼の文から最終出力まで通る正常のテストケース)。
- 回帰の選び方: 直したスクリプトの、スクリプトで確かめるテストケースと、TC-11 から TC-14 と、直した step を含む phase の番号を phase の列に持つテストケースと、TC-15 を流す。

## フォルダとファイルの役割

**README.md**
- 置くもの: この案件フォルダのフォルダとファイルの役割
- 作るときと直すとき: コンサルタントは、案件を始めるときに雛形から複製し、フォルダやファイルの役割を変えたときに直します。

**CLAUDE.md**
- 置くもの: この案件で AI に守らせる決まり
- 作るときと直すとき: 案件を始めるときに雛形から複製します。決まりを変えたときに直します。

**.claude/**
- 置くもの: 案件フォルダへの置き方の規約(`rules/case-folder-placement/case-folder-placement-rule.md`)と、ポータルの運用の規約(`rules/portal-operation/portal-operation-rule.md`)と、要るときに足す Claude Code の設定、規約、スキル
- 作るときと直すとき: 案件を始めるときに雛形から複製します。設定や規約を足すときに、中にファイルを置きます。

**portal/**
- 置くもの: この案件の業務管理ポータル。`index.html` は 1 つのページで、課題管理、全体マップ、計画・タスク、受領資料一覧、登場人物、アクセス・環境準備、会議メモ・議事録、決定事項ログの画面を切り替えて見られます。
- 作るときと直すとき: 案件を始めるときに雛形から複製します。

**portal/index.html**
- 置くもの: ポータルの画面
- 作るときと直すとき: 案件を始めるときに雛形から複製します。案件の中では、複製したときの中身を保ちます。

**portal/data.js**
- 置くもの: ポータルの画面に出す、この案件のデータ
- 作るときと直すとき: コンサルタントは、案件を始めるときに雛形から複製し、`<案件名>` と `<期間と定例の曜日>` を、この案件の値に書き換えます。その後は、AI が、`.claude/rules/portal-operation/portal-operation-rule.md` に従って直します。

**参照資料/**
- 置くもの: 先方から受け取った原本のうち、会議の文書(議事録、メモ、書き起こし、録音)を除くすべて
- 作るときと直すとき: 案件を始めるときに雛形から複製します。原本は受け取るたびに置き、置いた後は中身を変えません。

**依頼内容/**
- 置くもの: 依頼ごとのフォルダだけ
- 作るときと直すとき: 案件を始めるときに雛形から複製します。

**依頼名/**
- 置くもの: 先方からの 1 件の依頼に関わるもの。コンサルタントは、ここに `依頼.md` と、1 つの課題に決まらないものを置く `作業/`、`成果物/`、`納品/` と、課題ごとのフォルダを置きます。
- 作るときと直すとき: コンサルタントは、先方から依頼を受けたときに、雛形の `依頼名/` を複製し、フォルダの名前を依頼の名前に変えます。

**依頼.md**
- 置くもの: 先方の言葉のままの依頼
- 作るときと直すとき: コンサルタントは、依頼のフォルダと一緒に作ります。

**課題名/**
- 置くもの: 依頼の中の 1 つの課題に関わるもの。コンサルタントは、ここに `課題.md`、`作業/`、`成果物/`、`納品/` を置きます。
- 作るときと直すとき: コンサルタントは、依頼を課題に分けたときに、雛形の `課題名/` を複製し、フォルダの名前を課題の名前に変えます。

**課題.md**
- 置くもの: 課題の説明と、この課題で使う関連資料の名前
- 作るときと直すとき: コンサルタントは、課題のフォルダと一緒に作り、関連資料が増えたときと、課題の説明が変わったときに直します。

**作業/**
- 置くもの: 先方へ出す前の、作業の途中のもの。`案件管理/案件全体/`、依頼のフォルダ、課題のフォルダの 3 か所にあり、それぞれ、2 つ以上の依頼にまたがるか依頼が決まる前の作業、その依頼の作業、その課題の作業の、途中のものを置きます。
- 作るときと直すとき: それぞれのフォルダと一緒に作ります。作業の間は、いつでも置き、いつでも直します。

**成果物/**
- 置くもの: 先方へ出すために作った、最新の確定版。`作業/` と同じ 3 か所にあります。
- 作るときと直すとき: それぞれのフォルダと一緒に作ります。確定した版ができたときに置き、直したら上書きします。

**成果物/提示済み/YYYYMMDD/**
- 置くもの: 意見をもらうために先方へ見せた版の写し。`作業/` と同じ 3 か所にあります。
- 作るときと直すとき: 先方へ見せた日に、`YYYYMMDD` をその日の日付にしたフォルダを作り、写しを置きます。置いた後は中身を変えません。

**納品/YYYYMMDD_名前/**
- 置くもの: 先方へ正式に渡したものの写し。`作業/` と同じ 3 か所にあります。
- 作るときと直すとき: 先方へ渡した日に、`YYYYMMDD` をその日の日付に、`名前` を納品物の名前にしたフォルダを作り、写しを置きます。置いた後は中身を変えません。

**案件管理/**
- 置くもの: すべての会議の文書と、2 つ以上の依頼にまたがるものと、依頼が決まる前に作るものと、社内の書類。コンサルタントは、中を次の 3 つのフォルダに分けます。
- 作るときと直すとき: 案件を始めるときに雛形から複製します。

**案件管理/議事録/**
- 置くもの: 依頼の前の相談とヒアリング、依頼の後の定例、先方の担当者との個別の打ち合わせ、経営層との会議の、すべての会議の文書(議事録、メモ、書き起こし、録音)。AI かコンサルタントが書く議事録は `YYYYMMDD_会議名.md`、先方から受け取った会議の文書は `YYYYMMDD_会議名_<文書の種類>.<元の拡張子>` の名前にします。
- 作るときと直すとき: 案件を始めるときに雛形から複製します。会議のたびに、`YYYYMMDD` を会議を開いた日にした名前で置きます。課題に関わる会議の文書は、その課題の `課題.md` の「関連資料」に書きます。

**案件管理/案件全体/**
- 置くもの: 2 つ以上の依頼にまたがるものと、依頼が決まる前に作るもの(課題受付簿、業務棚卸し表、案件全体の完了報告など)。中は、課題のフォルダと同じく、`作業/`、`成果物/`、`納品/` に分けます。
- 作るときと直すとき: 案件を始めるときに雛形から複製します。

**案件管理/社内向け/**
- 置くもの: 先方に見せない社内の書類(見積、請求、提案書の下書き)
- 作るときと直すとき: 案件を始めるときに雛形から複製します。書類ができるたびに置きます。

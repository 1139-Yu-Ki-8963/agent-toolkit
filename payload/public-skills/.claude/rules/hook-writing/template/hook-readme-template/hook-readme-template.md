# hook の README の雛形

## 使う場面

スクリプトの README を書くとき。

## 省ける部分

雛形の本文のうち、隅付き括弧【】の 1 行は、その次の見出しの章を書く条件を示す。README は、その章を、隅付き括弧の中の条件のときだけ持つ。

## 雛形の本文

```markdown
# <スクリプトの名前>

## 登録

| 項目 | 値 |
|---|---|
| 発火点 | <発火点の鍵> |
| matcher | <`matcher` の値。持たない発火点では「なし」> |
| command | <`command` の値> |
| timeout | <秒> |

## 検査

| 検査の名前 | 確かめること | 対象のファイルの条件 | 根拠の規約と規則の観点 | 呼ぶもの | 返す kind | テスト |
|---|---|---|---|---|---|---|
| <検査の名前> | <1 文> | <拡張子、フォルダ。すべてなら「すべて」> | <規約 <ファイル名> の規則「<観点>」か、規約 <ファイル名> のすべての規則。なければ「なし」> | <外部のコマンドのパスか、点検の依頼の文のファイル名か、`require` で読み込む部品のパス。なければ「なし」> | <`violation` か `prompt`> | <「<検査の名前>: 結果を返す」と「<検査の名前>: 結果を返さない」の 2 つ> |

## 入力

| 標準入力の鍵 | 使い方 |
|---|---|
| <鍵> | <何に使うか> |

## 出力

| スクリプトが終える場合 | 終了コード | 出力先 | 出力の形 |
|---|---|---|---|
| <場合を 1 行ずつ> | <終了コード> | <出力先> | <出力の形> |

## 確かめ方

<確かめる人が、`node --test hooks/<スクリプトの名前>/<スクリプトの名前>.test.js` を実行し、すべてのテストが合格することを言う 1 文>

【点検の依頼の文のファイルがあるときだけ】
## 点検の依頼の文

| ファイル | そのファイルを渡す検査 |
|---|---|
| <点検の依頼の文のファイル名> | <検査の名前> |
```

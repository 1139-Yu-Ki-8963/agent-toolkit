# 検証の指示文

## サブエージェントへの指示

```text
あなたは、これから渡すスキルを初めて読む検証者です。ファイルは読むだけにして、判定してください。

1. 次の検証対象のファイルを、ファイルを読むツールで 1 つずつ全文読んでください。
   <対象のファイルのパスの一覧(1 行に 1 つ)>
2. 読んだあと、規約(「目次」と「守ること」の章)、雛形「スキルの雛形(phase と step)」(「省ける部分」「決まった値の一覧」「この雛形で作るスキルが守ること」「書き方の決まり」「全スキル共通の決まり」「雛形の本文」の章)、完成例の 3 つの中身が、あなたの文脈に自動で読み込まれているかを、文脈の中だけで見てください。1 つでもなければ、判定を止めて「規約なし」だけを返してください。
3. 読めないファイルがあれば、判定を止めて「読めないファイル: <読めなかったファイルのパス(1 件以上、読点で区切る)>」だけを返してください。
4. 照合は 2 つで、この順に行ってください。判定の基準は、文脈にある規約、雛形、完成例の文だけです。この指示文は、何をどの順に見るかだけを決めます。

   照合 1: 雛形の照合(機械的)。雛形の「雛形の本文」の章を上から順にたどり、雛形にある行が対象の SKILL.md に同じ順で現れるかを突き合わせてください。
   - 雛形の山かっこ `<〜>` は任意の文字列として扱い、それ以外の文字列(見出し、表の列の名前の行、固定の step の見出しと手順の文、固定の行)は一字一句の一致で判定してください。
   - 雛形の「省ける部分」の表にある「【〜だけ】」の部分は、その条件に当たらないスキルでは省かれているのが正しく、当たるスキルでは入っているのが正しいです。「【〜だけ】」の行そのものは、SKILL.md から除かれているのが正しいです。
   - `references/全スキル共通の決まり.md` は、雛形の「全スキル共通の決まり」の章と一字一句一致するかを突き合わせてください。
   - 雛形の「決まった値の一覧」の章の表の値に対象が合うかと、雛形の規則「上限に収まること」の上限に対象が収まるかを数えてください。数え方は雛形の規則「数の数え方」のとおりです。
   - 違反は、雛形の章の名前、雛形の該当行の文、対象の箇所(ファイル:行)、何が違うか、を記録してください。

   照合 2: 規約の照合。規約の「守ること」の規則と、雛形の「この雛形で作るスキルが守ること」の章の規則を、この順に、節の順に 1 規則ずつ次を行ってください。雛形の規則の違反は、規則の列に「雛形の規則「<観点>」」と書いてください。規則の見出しは「規則 <番号>: <観点>」で、参照は観点で行います。
   - 規則の節の直前にある「〜のとき」を読み、対象にその場面があるかを見る。なければ「該当なし」として次の規則へ進む。
   - 「判定の仕方」を読む。
   - 規則の文が指す対象の箇所(description、どの表、どの種類の step、手順の文)を特定する。
   - 「機械的」なら、数える、有無を見る、表と表を突き合わせる、で合否を出す。
   - 「AI の推論」なら、規則の文の観点で判定し、完成例の同種の箇所を目盛りにする。完成例がしている書き方は合格とする。完成例の同種の箇所が持っている要素を対象が持っていなければ違反にする。完成例に同種の箇所がない規則は、規則の文だけで判定する。
   - 規則の文が他の規則を「規則「<観点>」」の形で参照しているときは、その観点が参照先の規則の見出しと一致するかも見て、一致しなければ規約の側の違反として記録する。
   - 照合 1 で既に記録した違反と同じ箇所を指す機械的な規則は、照合 1 の雛形の該当行だけを書く。
   - 違反は、規則の観点、ファイル:行、違反の内容(規則のどの文に反するか)、直し方の案、を記録してください。
5. 下の「サブエージェントが返す書式」のとおりに返してください。返すのは、その書式の文だけにしてください。
```

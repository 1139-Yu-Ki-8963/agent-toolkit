# 実行結果の取り方と判定の仕方

step 3-7 が実行の記録から実行結果を取る取り方と、step 3-8 がテストケースごとに「合格」「不合格」「判定できない」を決める判定の仕方。どちらも、「ケースの中身」の「期待結果の種類ごとの判定」の表の、そのケースの期待結果の種類と同じ行の「比べる記録」「判定の仕方」を使う。

## 1. 実行結果の取り方(step 3-7)

「比べる記録」の値ごとに、次の表のとおりに、いまの実行の単位の実行の記録から実行結果を取る。複数行の内容は、1 行ずつ「」で囲んで並べる。

| 比べる記録 | 実行結果の取り方 |
|---|---|
| 行動の記録 | 実行の記録の「行動の記録」の表の step の列を、上から読点でつなぐ。同じ番号が続くときは 1 つにする |
| 止めた step と理由 | 実行の記録の「止めた step と理由」の下の文をそのまま写す |
| 表示の記録 | 実行の記録の「表示の記録」の番号つきの行をすべて写す |
| 最後の表示 | 実行の記録の「最後の表示」の下の文をすべて写す |
| 書いたファイルのパス | 実行の記録の「書いたファイルのパス」の各パスのうち、そのシナリオの一時フォルダのパスで始まるものは、その部分を除いた相対パスにする。それ以外のパスはそのまま並べる |
| 見本のファイルのハッシュ | 「見本の控えの一覧」のそのシナリオの 1 件ごとに、コマンドを実行するツールで `shasum <一時フォルダのパス>/<シナリオの番号>/<見本のファイルの相対パス>` を実行し、得たハッシュが控えのハッシュと同じかどうか(一致 / 不一致)を相対パスごとに並べる。控えが「なし」なら「なし」 |
| 書いたファイルの中身(「書いたファイルの中身」で始まる値) | そのケースの機能と同じ名前を持つ、「ケースの中身」の最終出力の表の行を取る。出力の種類が「ファイル」なら、実行の記録の「書いたファイルのパス」のうち、その行の見分け方のパス(山かっこの部分を任意の文字列とする)に合う 1 つを、ファイルを読むツールで全文読み、中身を実行結果にする。出力の種類が「チャットへの表示」なら、実行の記録の「表示の記録」のうち、その行の名前の見出しを持つ記録を実行結果にする。合うパスか記録がないときは「なし」 |

## 2. 期待する結果の山かっこの置き換え(step 3-8)

比べる前に、そのケースの期待する結果の山かっこのうち、中の語がいまのシナリオの「依頼で渡した出力先」の「<項目の名前> = <相対パス>」の項目の名前と同じものを、その相対パスに置き換える。相対パスが `<一時フォルダ>/` で始まるときは、その部分を除く。「依頼で渡した出力先」が「なし」なら、置き換えない。置き換えた後の期待する結果を、テスト結果の文書の「期待する結果」の値にする。

## 3. 判定の仕方(step 3-8)

いまの実行の単位のケースの 1 件ごとに、次の順に判定を決める。

1. 判定できない。実行の記録の「止めた step と理由」の理由が、実行者の指示文の決まりの語(「一時フォルダの外」「インストール」「ネットワーク」「サブエージェントの起動」「回答がない」)のどれかを含み、かつ、実行結果が「なし」であるか、止めた step の番号が期待する結果に現れる step の番号のどれかより前なら、「判定できない」にし、理由に止めた step と理由を写す。対象のスキルの手順の「中止する。」の段落で止まったときは、次へ進む。
2. 回で決まる判定。観点が「再現性」か「冪等性」のケースは、いまの実行の単位の回が 1 なら判定せず、ケースの結果に入れない。回が 2 なら、次の 4 の項に従う。
3. 通常の判定。「判定の仕方」の列の文のとおりに、実行結果を置き換えた後の期待する結果と比べる。満たさない点が 1 つでもあれば「不合格」にし、理由に満たさなかった点を書く。満たさない点がなければ「合格」にする。期待結果の種類が「最終出力の中身」のケースは、期待する結果の「(機械的)」の項目だけを比べ、「(AI の推論)」の項目は step 4-2 の判定者に委ねる。
4. 2 回目だけの判定。観点が「再現性」のケースは、「ケースの結果の一覧」にある同じシナリオの 1 回目の実行の記録と、いまの実行の記録の、「行動の記録」の step の列(同じ番号が続くときは 1 つ)と「最後の表示」を比べる。step の列が一致し、最後の表示の山かっこに入る値(パス、step の番号、選択肢の名前、件数)が一致すれば「合格」、どちらかが違えば「不合格」にし、理由に違った点を書く。観点が「冪等性」のケースは、3 の項のとおりに 2 回目の実行結果を比べ、さらに「見本のファイルのハッシュ」の取り方で取った値がすべて一致するときだけ「合格」にする。
5. 期待との差。期待結果の種類が「表示の記録」「最後の表示」のケースと、4 の項の再現性のケースで、山かっこに入る値以外の語句の差は、判定にかかわらず「期待との差」に、期待する結果の語句と実行結果の語句の組で書く。差がなければ「なし」にする。ほかのケースの「期待との差」は「なし」にする。

ケースの結果の 1 件は、実行の単位(シナリオの番号、シナリオの名前、回)、ケースごとの判定の一覧(ID、確かめること、観点、期待結果の種類、判定、置き換えた後の期待する結果、実行結果、期待との差、理由。合格なら理由は「なし」)、実行の記録の全文の 3 つを持つ。

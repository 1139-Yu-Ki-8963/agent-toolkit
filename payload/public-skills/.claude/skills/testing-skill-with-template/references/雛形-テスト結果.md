# 雛形: テスト結果の文書

テスト結果の文書の形と、山かっこの値をどこから取るかの表。ケースは、確かめることと ID で書き、実行の単位(シナリオの番号と回)ごとの塊に置く。

## 形

```markdown
# テスト結果: <対象のスキルの名前>

- テストシナリオの文書: <テストシナリオの文書のパス>
- テストケースの文書: <テストケースの文書のパス>
- 実行日時: <実行日時>
- 受け入れ: <可 / 不可>

## 集計

| 判定 | 件数 |
|---|---|
| 合格 | <合格の数> |
| 不合格 | <不合格の数> |
| 判定できない | <判定できないの数> |

- 一時フォルダの外への書き込み: <一時フォルダの外への書き込みの件数> 件
- 期待との差(要件は満たす): <期待との差の件数> 件
- 実行者が補った点: <補った点の件数> 件

## 不合格と判定できないケース

### <シナリオの名前>(シナリオ <シナリオの番号>、<回> 回目)

**<確かめること>(<ID>)**
- 観点: <観点>
- 判定: <不合格 / 判定できない>
- 期待する結果: <期待する結果>
- 実行結果: <実行結果>
- 理由: <理由>

## 合格したケース

### <シナリオの名前>(シナリオ <シナリオの番号>、<回> 回目)

**<確かめること>(<ID>)**
- 観点: <観点>
- 期待との差: <期待との差>

## 実行者の記録

### <シナリオの名前>(シナリオ <シナリオの番号>、<回> 回目)

- 止めた step と理由: <止めた step と理由>
- 分からなかった点: <分からなかった点>
- 補った点: <補った点>
- 返り値の全文: 記録/<シナリオの番号>-<回>.md
- 書いたファイル: 成果物/<シナリオの番号>/
```

## 値の取り方

| 値 | 取る場所 |
|---|---|
| 対象のスキルの名前 | 「シナリオの中身」の対象のスキルの名前 |
| テストシナリオの文書のパス | 「聞き取り後の依頼」のテストシナリオの文書のパス |
| テストケースの文書のパス | 「シナリオの中身」のテストケースの文書のパス |
| 実行日時 | 「実行日時」 |
| 受け入れ | 不合格の数が 0 かつ判定できないの数が 0 なら「可」、それ以外は「不可」 |
| 合格の数、不合格の数、判定できないの数 | 「確定したケースの結果の一覧」のケースを ID ごとにまとめ、ID ごとに 1 件として数える。同じ ID のどれかの回が「不合格」なら不合格、それ以外でどれかの回が「判定できない」なら判定できない、すべての回が「合格」なら合格に数える |
| 一時フォルダの外への書き込みの件数 | 「確定したケースの結果の一覧」の各実行の単位の実行の記録の「書いたファイルのパス」のうち、「一時フォルダのパス」で始まらないパスの数(実行の単位をまたいで同じパスは 1 と数える) |
| 期待との差の件数 | 「確定したケースの結果の一覧」のケースのうち、「期待との差」が「なし」でない件の数 |
| 補った点の件数 | 各実行の単位の実行の記録の「補った点」の行の数の合計(「なし」は 0) |
| 不合格と判定できないケースの節 | 「確定したケースの結果の一覧」の実行の単位ごとに、判定が「不合格」か「判定できない」のケースを持つ単位だけ、「### <シナリオの名前>(シナリオ <番号>、<回> 回目)」の見出しと、そのケースごとの塊を、文書に現れる順に置く。塊の 7 つの値は、そのケースの確かめること、ID、観点、判定、置き換えた後の期待する結果、実行結果、理由から写す。該当するケースが 0 件なら、節の見出しの下に「なし」の 1 行だけを置く |
| 合格したケースの節 | 同じ形で、判定が「合格」のケースだけを置く。塊の値は、確かめること、ID、観点、期待との差から写す。該当するケースが 0 件なら、節の見出しの下に「なし」の 1 行だけを置く |
| 実行者の記録の節 | 「確定したケースの結果の一覧」の実行の単位ごとに 1 つ。見出しの値は実行の単位から、止めた step と理由、分からなかった点、補った点は、その単位の実行の記録の同じ見出しの下の文から写す(複数のときは 1 件ずつ「」で囲んで並べる)。返り値の全文と書いたファイルは、シナリオの番号と回を入れた相対パス |
| 複数の値の書き方 | 1 つの行に入れる値が複数行のときは、1 行ずつ「」で囲んで並べる |

# 全スキル共通の決まり

このファイルは、このスキルのどの step でも使う決まりを持つ。実行者は、step 1-1 でこのファイルを全文読む。

## 1. ツールの呼び方

| 呼び方 | ないときの動作 |
|---|---|
| ファイルを読むツール | 中止する |
| ファイルを書くツール | 中止する |
| ファイルを名前で探すツール | コマンドを実行するツールで代わりに探す |
| ファイルの中身を検索するツール | コマンドを実行するツールで代わりに探す |
| コマンドを実行するツール | 中止する |
| 選択肢を提示するツール | チャットに番号付きの選択肢を出し、回答を待つ |
| サブエージェントを起動するツール | 委任の step の「委任できる条件」が「そのスキルを初めて読む実行者に検証させるとき」か「前の step までに作った成果物を、それを作った文脈と別の文脈で判定させるとき」なら、中止する。それ以外は、自分で順に行う |

## 2. チャットへの表示の書式

実行者は、作業の開始をユーザーに伝える宣言、中止の表示、ユーザーへの完了の報告の 3 つを、次の形の Markdown のまま出す。1 行目は、太字の見出し、2 行目以降は、「- <名前>: <値>」の箇条書きとする。実行者は、見出しの行を、山かっこを値で埋めたうえで、空白を含めて一字一句そのまま写す。

実行者は、作業の開始をユーザーに伝える宣言を、SKILL.md の手順に「宣言を出したら終わる」と書かれた step の最後に 1 回出す。
実行者は、入力の行を、開始時の入力の項目ごとに 1 行ずつ出し、成果物の行を、最終出力の表の、ユーザーへの完了の報告を除く行ごとに 1 行ずつ出す。

**次の内容で始めます**
- 目的: <SKILL.md の目的の 1 文目>
- <入力の項目>: <値>
- 成果物: <最終出力の名前>(<パス。チャットへの表示なら、「チャットに表示」>)

実行者は、中止の表示を、手順の「中止する。」の段落で出す。
実行者は、中止の表示の値を、その段落の「理由」「ユーザーが次にすること」「中止までの成果物」の行から取る。
実行者は、中止の表示の「理由」を、手順の「理由:」の行の文を、山かっこを値で埋めて一字一句そのまま写したものとする。
実行者は、中止の表示の「中止までの成果物」に、その段落の行が指す最終出力のうち、それまでに書いたフォルダの行のパスと、その直下のファイルの行のパスの両方を書く。

**step <番号> で中止しました**
- 理由: <理由>
- ユーザーが次にすること: <ユーザーが次にすること>
- 中止までの成果物: <パスの一覧。なければ、「なし」>

実行者は、ユーザーへの完了の報告を、最終出力の確認とユーザーへの完了の報告の phase の最後の step で出す。
実行者は、2 行目以降を、最終出力の表の、出力の種類が「ファイル」と「フォルダ」の行ごとに 1 行ずつ出す。その行がなければ、実行者は、1 行目だけを出す。
実行者は、読んだ中身と書く中身が同じファイルの行の、パスの後ろに「(変更なし)」を添える。
実行者は、見出しの題名に、いま実行しているスキル自身の SKILL.md の 1 行目の「# 」の見出しの文を入れる。

**<このスキルの SKILL.md の題名> が完了しました**
- <ファイルかフォルダの最終出力の名前>: <パスの一覧>

実行者は、ユーザーに見せる文面の山かっこのうち、名前が「一覧」で終わる値を、読点で区切って書き、0 件のときは、「なし」と書く。
実行者は、一覧の全件を扱う。上限を持つ step は、その手順に、上限と、超えたときの動きを持つ。
実行者は、チャットに出すパスのうち、依頼の文に書かれたパスは依頼の文の形のまま書き、スキルが決めたパスは作業フォルダからの相対パスで書く。作業フォルダは、依頼の文で指定されたフォルダとし、指定がなければ `skills/` の親のフォルダとする。例: `skills/<スキルの名前>/SKILL.md`。

## 3. 中止の決まり

手順にないことが起きたら、実行者は、その場で中止する。
実行者は、一時フォルダの中間成果物を消してから、中止の表示を出す。
実行者は、中止の表示を出したら止まる。

リファレンスを読めないときは、実行者は、中止する。
理由: <パス> を読めない。
ユーザーが次にすること: スキルのフォルダに <パス> があるかを確かめ、なければ、スキルを入れ直してから、もう一度実行する。
中止までの成果物: それまでに書いた最終出力のフォルダとファイル。なければ、「なし」。

## 4. 最終出力の確認とユーザーへの完了の報告

実行者は、この章の手順を、最終出力の確認とユーザーへの完了の報告の phase の最初の step で使う。

最終出力にファイルかフォルダがあるとき:
フォルダの行の見分け方に直下のファイル名が書かれているときは、実行者は、そのファイルを表にあるファイルとして扱う。
実行者は、最終出力の表の、出力の種類が「ファイル」と「フォルダ」の行のすべてが次の 2 つを満たすかを、ファイルを名前で探すツールで見る。
- 「0 件でもよいか」が「いいえ」の行は、見分け方のパスに当たるものを 1 つ以上持つ。
- 「フォルダ」の行は、直下のファイルがすべて表の行に当たる。見分け方に「(既にあるファイルと並べて書く)」か「(別のスキルを動かす作業用のフォルダ)」とあるフォルダは、この確かめの対象の外とする。
満たさない行があるときは、実行者は、中止する。
理由: 最終出力が最終出力の表と合わない(<合わなかったパスか行の名前の一覧>)。
ユーザーが次にすること: 最終出力のパスとフォルダの中身を確かめてから、もう一度実行する。
中止までの成果物: <表の行に当たるファイルとフォルダのパスの一覧>

最終出力がチャットへの表示だけのとき:
実行者は、最終出力の表の、ユーザーへの完了の報告を除く各行について、その名前の見出しを持つ表示を出したかを、自分の出力を読み返して調べる。
出していない行があれば、実行者は、中止する。
理由: 最終出力の表示を出していない(<出していない行の名前の一覧>)。
ユーザーが次にすること: もう一度実行する。
中止までの成果物: なし

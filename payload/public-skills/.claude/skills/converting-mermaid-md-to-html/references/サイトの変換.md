# サイトの変換

このリファレンスは、スキル converting-mermaid-md-to-html が、不足している前提ツールを入れる方法と、出力先のフォルダに書く設定ファイル 5 本の全文を、スキルで使う順に 2 つの節で持つ。各 step は、使う節だけを全文読む。

## インストールの方法

step 1-5 で、不足している前提ツールをインストールするときに読む。

### OS の見分け方

コマンドを実行するツールで `uname -s` を実行する。出力が `Darwin` なら macOS、`Linux` なら Linux(WSL を含む)とする。

### OS ごとのインストールのコマンド

パッケージマネージャだけを使い、管理者権限(`sudo`)を使わない。

| OS | ツール | インストールのコマンド |
|---|---|---|
| macOS | hugo(extended) | `brew --version && brew install hugo` |
| macOS | git | `brew --version && brew install git` |
| Linux | hugo(extended) | `if command -v brew >/dev/null; then brew install hugo; else npm install -g hugo-extended; fi` |
| Linux | git | `command -v brew >/dev/null && brew install git` |

macOS の Homebrew の hugo は extended の版である。Homebrew がないときは、最初の `brew --version` の終了コードが 0 でなくなり、step 1-5 は中止する。

Linux の hugo は、Homebrew(Linuxbrew)があればそれを、なければ npm のパッケージ `hugo-extended` を使う。どちらも管理者権限なしで入る。npm もないときは、コマンドの終了コードが 0 でなくなり、step 1-5 は中止する。

Linux の git は、Homebrew があればそれで入れる。Homebrew がないときは、管理者権限なしで入れる手段がないため、コマンドの終了コードが 0 でなくなり、step 1-5 は中止する。

## サイトの設定一式

step 3-5 で、出力先のフォルダに 5 本の設定ファイルを書くときに読む。5 本は、設定の全文である。

### 書き方

- 下の 5 本を、見出しのパスに、コードブロックの中身のとおりに書く。パスは出力先のフォルダからの相対パス。
- `hugo.toml` の `<題名>` は、題名を TOML の二重引用符の文字列として書いたものに置き換える。`\` は `\\` に、`"` は `\"` にする。
- 「空のファイル」と書いた 2 本は、中身のない 0 バイトのファイルとして書く。
- 中身のある 3 本は、UTF-8 で、最後の行の後に改行を 1 つ付けて書く。
- 行頭の字下げは、`layouts/partials/topbar/area/start.html` の 2 行目だけがタブ 1 つで、ほかはすべて半角の空白である。

### 5 本の役割

- `hugo.toml`: Hugo と Relearn の公式の設定項目だけを持つ。`languageCode` は非推奨の警告が出るが、この形のまま書く。`mermaidZoom = true` で図の拡大と移動とリセットを有効にする。サイドバーのメニュー、検索、Home ボタン、前後のページ移動ボタン、生成器の名前を消す。
- `assets/css/theme-sekkei.css`: 色の変種。CSS 変数だけを持つ。最後の `:root` のブロックの 3 つの変数は、サイドバーの幅を 0 にする。
- `layouts/partials/menu-footer.html`: 空のファイル。「Built with Hugo」の表記を消す。
- `layouts/partials/heading.html`: 空のファイル。テーマが出す題名の見出しを消す。md の H1 と重なるため。
- `layouts/partials/topbar/area/start.html`: 上のバーの左側を、目次ボタンだけにする。

### hugo.toml

```toml
baseURL = '/'
relativeURLs = true
languageCode = 'ja'
title = "<題名>"
theme = 'hugo-theme-relearn'
disableHugoGeneratorInject = true

[params]
  mermaidZoom = true
  themeVariant = 'sekkei'
  disableGeneratorVersion = true
  disableLandingPageButton = true
  disableNextPrev = true
  sidebarmenus = []
  search.disable = true
  search.index.disable = true
  search.page.disable = true

[markup.highlight]
  noClasses = false
```

# インストールの方法

## 適用する場面

step 1-4 で、不足している前提ツールをインストールするとき。

## OS の見分け方

コマンドの実行の機能で `uname -s` を実行する。出力が `Darwin` なら macOS、`Linux` なら Linux(WSL を含む)とする。

## OS ごとのインストールのコマンド

| OS | ツール | インストールのコマンド |
|---|---|---|
| macOS | hugo(extended) | `brew --version && brew install hugo` |
| Linux | hugo(extended) | `mkdir -p ~/.local/bin && a=$(uname -m) && case "$a" in x86_64) a=amd64;; aarch64) a=arm64;; esac && curl -fsSL "https://github.com/gohugoio/hugo/releases/download/v0.167.0/hugo_extended_0.167.0_linux-$a.tar.gz" \| tar -xz -C ~/.local/bin hugo && ~/.local/bin/hugo version` |

macOS の Homebrew の hugo は extended の版である。Homebrew がないときは、最初の `brew --version` の終了コードが 0 でなくなり、step 1-4 は中止する。

Linux は、公式の配布物の extended 版(0.167.0)を `~/.local/bin` に展開する。`~/.local/bin` が `PATH` にないときは、以降の step の `hugo` は `~/.local/bin/hugo` で呼ぶ。この行は macOS 以外で実行して確かめていない。

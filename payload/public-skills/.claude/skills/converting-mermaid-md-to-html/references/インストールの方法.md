# インストールの方法

## 適用する場面

step 1-5 で、不足している前提ツールをインストールするとき。

## OS の見分け方

コマンドを実行するツールで `uname -s` を実行する。出力が `Darwin` なら macOS、`Linux` なら Linux(WSL を含む)とする。

## OS ごとのインストールのコマンド

パッケージマネージャだけを使い、管理者権限(`sudo`)を使わない。

| OS | ツール | インストールのコマンド |
|---|---|---|
| macOS | hugo(extended) | `brew --version && brew install hugo` |
| macOS | git | `brew --version && brew install git` |
| Linux | hugo(extended) | `if command -v brew >/dev/null; then brew install hugo; else npm install -g hugo-extended; fi` |
| Linux | git | `command -v brew >/dev/null && brew install git` |

macOS の Homebrew の hugo は extended の版である。Homebrew がないときは、最初の `brew --version` の終了コードが 0 でなくなり、step 1-5 は中止する。

Linux の hugo は、Homebrew(Linuxbrew)があればそれを、なければ npm のパッケージ `hugo-extended` を使う。どちらも管理者権限なしで入る。npm もないときは、コマンドの終了コードが 0 でなくなり、step 1-5 は中止する。

Linux の git は、Homebrew があればそれで入れる。Homebrew がないときは、管理者権限なしで入れる手段がないため、コマンドの終了コードが 0 でなくなり、step 1-5 は中止する。

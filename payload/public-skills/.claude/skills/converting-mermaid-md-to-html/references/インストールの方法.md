# インストールの方法

## 適用する場面

step 1-4 で、不足している前提ツールをインストールするとき。

## OS の見分け方

コマンドの実行の機能で `uname -s` を実行する。出力が `Darwin` なら macOS、`Linux` なら Linux(WSL を含む)とする。

## OS ごとのインストールのコマンド

パッケージマネージャだけを使う。生の `curl` や `wget` による取得は使わない。

| OS | ツール | インストールのコマンド |
|---|---|---|
| macOS | hugo(extended) | `brew --version && brew install hugo` |
| Linux | hugo(extended) | `if command -v brew >/dev/null; then brew install hugo; else sudo snap install hugo; fi` |

macOS の Homebrew の hugo は extended の版である。Homebrew がないときは、最初の `brew --version` の終了コードが 0 でなくなり、step 1-4 は中止する。

Linux は、Homebrew(Linuxbrew)があればそれを、なければ snap を使う。どちらの hugo も extended の版である。apt の hugo は配布元によって extended でない版があるため使わない。この行は macOS 以外で実行して確かめていない。

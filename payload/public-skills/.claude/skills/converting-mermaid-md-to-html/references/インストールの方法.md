# インストールの方法

## 適用する場面

step 1-4 で、不足している前提ツールをインストールするとき。

## OS の見分け方

コマンドの実行の機能で `uname -s` を実行する。出力が `Darwin` なら macOS とする。

## OS ごとのインストールのコマンド

| OS | ツール | インストールのコマンド |
|---|---|---|
| macOS | hugo(extended) | `brew --version && brew install hugo` |

Homebrew の hugo は extended の版である。Homebrew がないときは、最初の `brew --version` の終了コードが 0 でなくなり、step 1-4 は中止する。表にない OS では、インストールしない。

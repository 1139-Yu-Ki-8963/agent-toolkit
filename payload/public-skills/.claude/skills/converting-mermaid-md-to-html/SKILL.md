# Mermaid の図を含む md を HTML に変換する

## 全体像

- 目的: Mermaid の図を含む md ファイルを、図を拡大して読める 1 ページの HTML に変換する。
- 全体の決まり: 使うツールは 3 つで、Mermaid は md の ` ```mermaid ` のブロックを SVG の図に描画し(Relearn に同梱され、step 3-4 の取得で揃う)、Relearn(9.1.0)は Hugo のテーマとして Mermaid を呼び出して図を描き、拡大・移動・リセットを付け、目次と見た目も担い、Hugo(extended、0.167.0)は md を HTML に変換する。変換のためにスキルが行うのは、公式のコマンドの実行、設定ファイルの配置、md のそのままのコピーの 3 つだけで、このほかにツールの有無の確認、入力の確定、出力先の有無の判定、完了の照合を行う。題名はブラウザのタブと上のバーに出て、本文の大見出しは md の最初の H1 がそのまま出るので、題名を指定すると両者は違う文字列になり得る。md と生成した HTML はそのまま扱い、スキルの作業は HTML を出力先に書いた時点で終わる。開くのは `public/index.html` 1 枚で、同じ `public/` の css、js、fonts を読むので、渡すときは `public/` ごと渡す。表示の文面の山かっこのうち、名前が「一覧」で終わる値は 0 件以上で、読点で区切って書き、0 件のときは「なし」と書く。

## phase 2 入力の確定

### step 2-1 依頼を読み取る

#### 手順

依頼の文面から、md ファイルのパス、出力先のフォルダ、題名の 3 項目を読み取る。
値は原文の語句のまま写し、明示されていない項目は「不明」とする。
値の切り出し方は、次の 5 つの段落のとおりとする。

md ファイルのパスは、`/` か `~` を含み `.md` で終わる語句とする。
「md」だけや、`sample.md` のようなファイル名だけは当たらない。

出力先のフォルダは、「出力先は」の後ろにある、`/` か `~` を含む語句とする。

題名は、「題名は」か「タイトルは」の後ろから、その文の終わりまでとする。

値の終わりは、項目ごとに次のとおりとする。
2 つのパスは、空白、句点、依頼の終わりのどれかで終わる。
ただし引用符かかぎかっこで囲まれたパスは、囲みの中が値で、空白を含んでよい。
題名は、句点か依頼の終わりで終わり、空白を含んでよい。
どの項目も、末尾に続く「にして」「で」「に」「を」のような依頼の語は値に含めない。

切り出した値は、前後の空白を除く。
値の全体を囲むかぎかっこか引用符が 1 組あるときは、その 1 組だけを除く。
値の中にある引用符は、値の一部として残す。
例: 「題名は 注文 "フロー" 図」の題名は `注文 "フロー" 図`。

3 項目を受け渡し値「読み取った入力」にして終わる。

#### step 2-1 の情報

- 種別: AI による推論
- 入力: 開始時の入力の 3 項目
- 出力: 受け渡し値「読み取った入力」
- 判断の観点: 文面に明示されているかどうか
- 合格の基準: 原文にない語句を値に入れていない

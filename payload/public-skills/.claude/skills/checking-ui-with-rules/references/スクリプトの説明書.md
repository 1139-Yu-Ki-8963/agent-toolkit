# スクリプトの説明書

このファイルは、`scripts/` の下のスクリプトの説明書である。章ごとに、空行とコメント行を除く 1 行ごとに、その行の処理と理由を書く。行の番号は、スクリプトのファイルの 1 から数えた行の番号である。

## list-ui-files.js の説明書

この章は、スクリプトの説明書である。調べる範囲の画面のファイルを、拡張子と飛ばすフォルダで列挙し、`--changed` のときは `git status --porcelain` のファイルを列挙する(step 5-1)。終了コードは、0 正常、2 呼び出しの誤り。

.env で始まるファイル、鍵のファイル、認証の情報のファイルは列挙しない。
変えたファイルだけのときは、`git status --porcelain` のファイル(ステージ済みと、git が追っていない新しいファイルを含む)を出す。
入口のファイルのときは、そのファイル 1 本を出す。

## measure-screen.js の説明書

この章は、スクリプトの説明書である。Playwright で画面の URL を幅 1440、768、375 で開き、写真を撮り、はみ出し、押す場所の大きさ、色の比、フォーカスの順、コンソールのエラーを測って JSON に書く(step 6-2)。終了コードは、0 正常、2 呼び出しの誤りか、開けない URL か、ブラウザを起動できない。

スクリプトは、画面の URL を、ツールのフォルダの Playwright(Chromium のヘッドレス版)で開き、URL ごとに、開いて読み込みが終わった直後の状態だけを、幅 1440、768、375 で、スクロールした先を含むページの全体の写真に撮り、`<URL の番号>-<幅>.png` に書く。
スクリプトは、横のはみ出し、ボタンとリンクの幅と高さ、文字の色と背景の色の比(WCAG 2.2 の relative luminance の式)、Tab キーで移るフォーカスの順(100 回まで。最初の部品に戻ったら止める)、コンソールのエラーを測る。
背景が透明なときは親の要素をたどり、半透明の色、背景の画像、グラデーションの上の文字は、比が決まらない文字として出す。
開いたあとに出る部品(メニュー、ダイアログ)は測らない。

## compare-findings.js の説明書

この章は、スクリプトの説明書である。前の回の json と鍵で突き合わせて、直った、新しく出た、残っているに分け、番号を付ける(step 7-2)。終了コードは、0 正常、2 呼び出しの誤り。

スクリプトは、指摘 1 件を 1 件とし、前にあって今ない指摘を直った、前になくて今ある指摘を新しく出た、両方にある指摘を残っているとする。
スクリプトは、残っている指摘の番号を前のまま変えず、新しく出た指摘に、結果のフォルダの下のすべての回の json の番号の最も大きい数の続きの番号を付ける。
前の回と今の回の両方が 0 件なら、直った、新しく出た、残っているをすべて 0 件にする。

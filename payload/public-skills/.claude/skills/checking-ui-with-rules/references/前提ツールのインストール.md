# 前提ツールのインストール

## インストールの方法

この章は、対応表である。

### OS の見分け方

実行者は、セッションの環境の情報の Platform の値を、次の表で OS に対応させる。

| Platform の値 | OS |
|---|---|
| `darwin` | macOS |
| `linux` | Linux(WSL を含む) |
| `win32` | Windows |

### OS ごとのインストールのコマンド

次の表のコマンドは、パッケージマネージャのコマンドで、一般ユーザーの権限で実行できる。npm は、node と一緒に入るので、node の行のコマンドで入れる。スキルごとのツールの行の `<ツールのフォルダ>` は、step 1-2 で決めたツールのフォルダのパスで置き換える。`@playwright/browser-chromium` は、npm の install script `node install.js` が、Chromium のヘッドレス版を公式の配布元から取る。

| OS | ツール | インストールのコマンド | 管理者の権限 | 先に書くファイル |
|---|---|---|---|---|
| macOS | node | `brew --version && brew install node` | なし | なし |
| Linux | node | `brew --version && brew install node` | なし | なし |
| Windows | node | `winget install OpenJS.NodeJS.LTS` | なし | なし |
| macOS | npm | `brew --version && brew install node` | なし | なし |
| Linux | npm | `brew --version && brew install node` | なし | なし |
| Windows | npm | `winget install OpenJS.NodeJS.LTS` | なし | なし |
| macOS | git | `brew --version && brew install git` | なし | なし |
| Linux | git | `brew --version && brew install git` | なし | なし |
| Windows | git | `winget install Git.Git` | なし | なし |
| すべての OS | playwright | `npm install --prefix "<ツールのフォルダ>" playwright@1.65.1` | なし | なし |
| すべての OS | @playwright/browser-chromium | `npm install --prefix "<ツールのフォルダ>" @playwright/browser-chromium@1.65.1` | なし | なし |

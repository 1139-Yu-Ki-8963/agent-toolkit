# 画面のファイルの選び方

## 当てる節の選び方

この章は、判定の基準である。実行者は、step 5-2 で、画面のファイルの一覧の 1 本ごとに、次の表のとおりに、入れるかと、当てる規約の節を決める。

| 場面 | 決め方 |
|---|---|
| 調べる範囲が入口のファイルのとき | 入口のファイルから、import と部品に渡す値をたどり、つながりを確かめたファイルだけを入れる。名前が似ているだけのファイルは入れない |
| 画面の部品を書いていない .js と .ts | 外す(例: サーバーの処理、テストのファイル、型だけのファイル) |
| 自作の部品 | 描く要素で節を決める(例: `<Button>` が `<button>` を描くなら、ボタンの節) |
| 見た目のファイルと値のファイル | 色、文字、余白のように値を決める節を当てる。値のファイルは、tokens.json、theme.ts、tailwind.config.js のように、色や文字の大きさの値を決めているファイル |
| 節の「対象」に当たるか迷うとき | 当てる |

検索の文字の並びは、判定の仕方が「機械的」で確かめる場所が「コード」の規則ごとに、違反の例のコードから、空白を除いた最も短い特有の部分とする(例: `outline: none` の規則は `outline:none` と `outline: none`、`transition: all` の規則は `transition: all`)。空白のあるなしで書き方が分かれる並びは、両方の形を検索の文字の並びにする。

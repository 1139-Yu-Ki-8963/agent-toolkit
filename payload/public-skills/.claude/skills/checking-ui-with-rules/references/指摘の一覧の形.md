# 指摘の一覧の形

## 指摘の一覧.md の雛形

この章は、雛形である。実行者は、step 8-2 の最初の照合で、次の山かっこを埋めて `指摘の一覧.md` の中身を作る。パスは、結果のフォルダからの相対パスで書く。指摘は、まとめた指摘の通し番号の順(重さの重い順)に並べる。

````markdown
# 指摘の一覧

## 照合の入力

- ルール: <ルールの場所の一覧>
- 使う規約: <使う規約のパスの一覧>
- 範囲: <調べる範囲>
- 画面: <画面の URL の一覧。なければ「なし」>

## 件数のまとめ

- 直す: <件数> 件
- できれば直す: <件数> 件
- 規約 <規約のファイルの名前> <節の見出し>: <件数> 件

## 指摘

**<通し番号>. <重さ>**
- 規約と規則の観点: <規約のパス>、<規則の観点>
- 場所: `<ファイル>:<行>`(画面の指摘は、URL <URL>、幅 <幅の一覧>、写真 <写真のパスの一覧>、部品 `<セレクタ>`、推し量ったファイル `<ファイル>:<行>`(推測))
- 違反しているコードの引用: `<quote>`
- 何が合わないか: <problem>
- 直し方の案: 直す前 `<fix_before>`、直した後 `<fix_after>`、理由: <fix_reason>(decision_needed が true の指摘は「決めてもらうことの <通し番号> を見る。」)
- 確かめ方: <機械的 / AI の推論>(画面の指摘は、続けて「、写真で確かめた」か「、推測」)
- 1 人だけが指摘(single が true の指摘だけ、この行を書く)

## 合格

- <指摘のなかった画面のファイルのパス。なければ「なし」>

## 決めてもらうこと

**<通し番号>. <決めること>**
- 案 1: <fix_after の 1 つ目の案>
- 案 2: <fix_after の 2 つ目の案>
- 勧める案と理由: 案 <案の番号>。<理由>

## 画面で確かめていない規則

- <規約のパス>、<規則の観点>: <理由(画面の URL がない、開いたあとに出る部品、色の比が決まらない)>
````

指摘が 0 件のときは、章「指摘」と章「決めてもらうこと」に「なし」とだけ書き、章「合格」にすべての画面のファイルを並べる。決めてもらうことがないときと、画面で確かめていない規則がないときは、その章に「なし」とだけ書く。

## 調べ直しの結果.md の雛形

この章は、雛形である。実行者は、step 8-2 の調べ直しで、次の山かっこを埋めて `調べ直しの結果.md` の中身を作る。

````markdown
# 調べ直しの結果(<回> 回目)

## 照合の入力

- ルール: <ルールの場所の一覧>
- 使う規約: <使う規約のパスの一覧>
- 範囲: <調べる範囲>
- 画面: <画面の URL の一覧。なければ「なし」>
- 直した画面のファイル: <直した画面のファイルの一覧>
- 前の回の一覧: <前の回の一覧の json のパス>

## 件数のまとめ

- 直った: <件数> 件
- 新しく出た: <件数> 件
- 残り: <残っている件数と新しく出た件数の和> 件

## 直った

- <番号>. `<ファイル>:<行>` <規則の観点>

## 新しく出た

<指摘の一覧.md の雛形の章「指摘」の 1 件と同じ項目で、新しく出た指摘を並べる>

## 残っている

- <番号>. `<ファイル>:<行>` <規則の観点>

## 画面で確かめていない規則

- <規約のパス>、<規則の観点>: <理由>
````

直った指摘、新しく出た指摘、残っている指摘、画面で確かめていない規則がないときは、その章に「なし」とだけ書く。

## 指摘の一覧.json の形

この章は、雛形である。実行者は、step 8-1 で、次の形の配列を書く。

| ファイル | 配列の 1 件が持つ項目 |
|---|---|
| `指摘の一覧.json` | 照合者の返す項目(`rule_file`、`rule_viewpoint`、`file`、`line`、`quote`、`occurrence`、`rule_quote`、`problem`、`fix_before`、`fix_after`、`fix_reason`、`decision_needed`。画面の指摘は、さらに `url`、`width`、`selector`、`photo`、`file_guessed`)に、`number`(通し番号)、`weight`(「直す」か「できれば直す」)、`single`(1 人だけが指摘なら `true`)を足したもの |
| `調べ直し-<回>/調べ直しの結果.json` | `指摘の一覧.json` と同じ項目に、`status`(「残っている」か「新しく出た」)を足したもの |

指摘が 0 件のときは、空の配列 `[]` を書く。

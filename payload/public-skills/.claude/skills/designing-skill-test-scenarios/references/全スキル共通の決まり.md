# 全スキル共通の決まり

このスキルのどの step でも使う決まり。step 1-1 で全文読む。

## 1. ツールの呼び方

| 呼び方 | ないときの動作 |
|---|---|
| ファイルを読むツール | 中止する |
| ファイルを書くツール | 中止する |
| ファイルを名前で探すツール | コマンドを実行するツールで代わりに探す |
| ファイルの中身を検索するツール | コマンドを実行するツールで代わりに探す |
| コマンドを実行するツール | 中止する |
| 選択肢を提示するツール | チャットに番号付きの選択肢を出し、回答を待つ |
| サブエージェントを起動するツール | 検証の委任なら中止する。それ以外は自分で順に行う |

## 2. チャットへの表示の書式

3 つの表示は、コードブロックに入れず、次の形の Markdown のまま出す。1 行目は太字の見出し、2 行目以降は「- <名前>: <値>」の箇条書き。

作業の開始をユーザーに伝える宣言。入力がすべて決まった step の最後に 1 回出す。
入力の行は開始時の入力の項目ごとに、成果物の行は最終出力の表の、ユーザーへの完了の報告を除く行ごとに 1 行ずつ出す。

**次の内容で始めます**
- 作業: <SKILL.md の目的の 1 文目>
- <入力の項目>: <値>
- 成果物: <最終出力の名前>(<パス。チャットへの表示なら「チャットに表示」>)

中止の表示。手順の「中止する。」の段落で出す。
値は、その段落の「理由」「ユーザーが次にすること」「中止までの成果物」の行から取る。

**step <番号> で中止しました**
- 理由: <理由>
- ユーザーが次にすること: <ユーザーが次にすること>
- 中止までの成果物: <パスの一覧。なければ「なし」>

ユーザーへの完了の報告。最終出力の確認とユーザーへの完了の報告の最後の step で出す。
2 行目以降は、最終出力の表の、出力の種類が「ファイル」の行ごとに 1 行ずつ出す。その行がなければ 1 行目だけを出す。

**<スキルの名前> が完了しました**
- <ファイルの最終出力の名前>: <パス>

表示の文面の山かっこのうち、名前が「一覧」で終わる値は 0 件以上で、読点で区切って書き、0 件のときは「なし」と書く。
一覧の件数に上限はなく、多いときも全件を扱う。上限があるときは、その step の手順に、上限と、超えたときの動きがある。

## 3. 中止の決まり

手順にないことが起きたら、その場で中止する。
途中でだけ使うファイルを消してから、中止の表示を出す。
中止の表示を出したら止まる。

リファレンスを読めないときは、中止する。
理由: <パス> を読めない。
ユーザーが次にすること: スキルのフォルダに <パス> があるかを確かめ、なければスキルを入れ直してから、もう一度実行する。
中止までの成果物: それまでに書いた最終出力のファイル。なければ「なし」。

## 4. 最終出力の確認とユーザーへの完了の報告

最終出力の確認とユーザーへの完了の報告の phase の最初の step で使う。

最終出力にファイルがあるとき:
出力先のフォルダの下の全ファイル(隠しファイルを含む)を、最終出力の表の、出力の種類が「ファイル」の行と比べる。
表にないファイルがあるか、「0 件でもよいか」が「いいえ」の行に当たるファイルがないときは、中止する。
理由: 出力先のファイルが最終出力の表と合わない(<合わなかったパスか行の名前の一覧>)。
ユーザーが次にすること: 出力先のフォルダの中身を確かめてから、もう一度実行する。
中止までの成果物: <出力先のフォルダの全ファイル>

最終出力がチャットへの表示だけのとき:
最終出力の表の、ユーザーへの完了の報告を除く各行について、その名前の見出しを持つ表示を出したかを、自分の出力を読み返して調べる。
出していない行があれば、中止する。
理由: 最終出力の表示を出していない(<出していない行の名前の一覧>)。
ユーザーが次にすること: もう一度実行する。
中止までの成果物: なし

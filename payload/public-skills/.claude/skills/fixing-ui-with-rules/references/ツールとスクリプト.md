# ツールとスクリプト

## インストールの方法

この章は、対応表である。

### OS の見分け方

実行者は、セッションの環境の情報の Platform の値を、次の表で OS に対応させる。

| Platform の値 | OS |
|---|---|
| `darwin` | macOS |
| `linux` | Linux |
| `win32` | Windows |

### OS ごとのインストールのコマンド

次の表のコマンドは、パッケージマネージャのコマンドで、一般ユーザーの権限で実行できる。

| OS | ツール | インストールのコマンド | 管理者の権限 | 先に書くファイル |
|---|---|---|---|---|
| macOS | node | `brew --version && brew install node` | なし | なし |
| Linux | node | `brew --version && brew install node` | なし | なし |
| Windows | node | `winget install OpenJS.NodeJS.LTS` | なし | なし |
| macOS | npm | `brew --version && brew install node` | なし | なし |
| Linux | npm | `brew --version && brew install node` | なし | なし |
| Windows | npm | `winget install OpenJS.NodeJS.LTS` | なし | なし |

npm は、node と一緒に入る。

## select-findings.js の説明書

このスクリプトは、返事の文から、直す番号、選んだ案の番号、直さない番号と理由を取り出し、直す対象の json から番号の指摘を抜き出して、重さの重い順に並べる。
呼び方は `node scripts/select-findings.js <直す対象の json のパス> <返事の文>` で、結果を `{"fix":[...],"skip":[{"number":n,"reason":"..."}],"plans":{"n":k}}` の 1 行の JSON で標準出力に出す。
fix は、重さが「直す」の番号を先に、「できれば直す」の番号をあとにし、同じ重さの中を番号の小さい順に並べた、直す番号の配列とする。
skip は、直さない番号と、返事の括弧の中の理由の組の配列とし、理由がないときは、reason を空の文字列にする。
plans は、直す番号と、選んだ案の番号の組とする。
返事は、「全部直して」、「1、3 を直して。9 は案 2」、「4 は直さない(理由)」の形と、その組み合わせを読む。全角の数字と括弧と読点「,」は、半角と同じに読む。
終了コードは、正常なら 0、一覧にない番号か読み取れない返事なら 1、引数か json が誤っていれば 2 とする。
終了コード 1 のときは、標準出力に「一覧にない番号: <番号を読点で区切った並び>」の行か、「読み取れない返事: <読み取れなかった文>」の行を出す。
テストは `node scripts/tests/select-findings.test.js` で、引数なしで実行する。

| 行 | 処理 | 理由 |
|---|---|---|
| 1 | `node` で実行することを示す | 規約の規則「実行系は node」に合わせるため |
| 2 | ファイルを読む関数を読み込む | 直す対象の json を読むため |
| 3 | 引数が 2 つでなければ、使い方を標準エラーに出して終了コード 2 で終わる | 呼び出しの誤りを、返事の誤りの 1 と分けて返すため |
| 4 | 引数から、直す対象の json のパスと返事の文を取り出す | 読むファイルと読む返事を決めるため |
| 5 | 指摘の配列を入れる変数を用意する | 読んだ配列を次の行で入れるため |
| 6 | json を読んで配列にし、読めなければ標準エラーに出して終了コード 2 で終わる | 読めない json を、返事の誤りの 1 と分けて返すため |
| 7 | 配列でないか、整数の number を持たない要素があれば、標準エラーに出して終了コード 2 で終わる | 番号で指摘を引けない json を、呼び出しの誤りとして返すため |
| 8 | 番号から指摘を引く表を作る | 番号が一覧にあるかと、重さと案の数を引くため |
| 9 | 文から番号を取り出す関数を定める。「1〜3」の形は、1 から 3 の番号に広げる | 番号の並びと範囲の両方を読むため |
| 10 | 直す番号、直さない番号と理由、選んだ案、読み取れない文の入れ物を用意する | 文ごとに読んだ結果を集めるため |
| 11 | 「全部」の印を用意する | 「全部直して」を読んだかを覚えるため |
| 12 | 返事を全角から半角に揃え、括弧の中を切らずに、「。」と改行で文に分け、1 文ずつ繰り返す | 理由の括弧の中の「。」で文を切らないため |
| 13 | 文から「<番号> は案 <番号>」を取り出して、選んだ案と直す番号に入れ、文から消す | 案を選んだ指摘を直す番号に入れ、残りの文を次の行で読むため |
| 14 | 文から「直さない」の前の部分と、後ろの括弧の中の理由を取り出す | 直さない番号と理由を分けて読むため |
| 15 | 「直さない」の前の部分か文が「全部」「すべて」「全て」を持ち、文が「直」を持てば、「全部」の印を立てる | 「全部直して」を、直さない番号と同じ文に書いた返事も読むため |
| 16 | 「直さない」があれば、その前の部分の最後の「直」より前の番号を直す番号に、後ろの番号を直さない番号と理由に入れる | 「1 を直して、4 は直さない」の 1 を直さない番号に入れないため |
| 17 | 「直さない」がなく、文が「直」を持つか番号と区切りだけなら、文の番号を直す番号に入れる | 「1、3 を直して」と「1、3」を読むため |
| 18 | どの形にも当たらず数字を持つ文を、読み取れない文に入れる | 読めなかった番号を黙って捨てないため |
| 19 | 文ごとの繰り返しを閉じる | 繰り返しの範囲を示すため |
| 20 | 直す番号も直さない番号も「全部」の印も読み取れない文もなければ、返事の全文を読み取れない文に入れる | 番号のない返事を、0 件の正常と分けて返すため |
| 21 | 「全部」の印があれば、配列のすべての番号を直す番号に入れる | 「全部直して」を配列のすべての番号にするため |
| 22 | 直さない番号を、直す番号から除く | 「全部直して。4 は直さない」の 4 を直さないため |
| 23 | 直す番号、直さない番号、案を選んだ番号のうち、配列にない番号を、小さい順に集める | 一覧にない番号を、中止の理由に書けるようにするため |
| 24 | 直す番号の選んだ案が、案の配列を持たないか、案の数の範囲の外なら、読み取れない文に入れる | ない案で直さないため |
| 25 | 一覧にない番号があれば、「一覧にない番号: 」の行を標準出力に出す | 親が中止の理由に番号を写せるようにするため |
| 26 | 読み取れない文があれば、「読み取れない返事: 」の行を標準出力に出す | 親が中止の理由に文を写せるようにするため |
| 27 | 一覧にない番号か読み取れない文があれば、終了コード 1 で終わる | 返事の誤りを終了コードで返すため |
| 28 | 重さが「直す」なら 0、ほかは 1 を返す関数を定める | 重さの重い順に並べるため |
| 29 | 直す番号を重さと番号の順に並べ、直さない番号を番号の順に並べ、直す番号の案だけを残した結果を作る | 決めた形と順で結果を返すため |
| 30 | 結果を 1 行の JSON で標準出力に出す | 親が結果を JSON として読めるようにするため |

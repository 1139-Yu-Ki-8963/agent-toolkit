# 判定基準

期待結果の種類ごとの、判定基準の文と、比べる記録の値の表。テストケースの表の「判定基準」と「比べる記録」の列は、この表から種類に対応する値を写す。

| 期待結果の種類 | 判定基準 | 比べる記録 |
|---|---|---|
| 通った step の並び | 記録の step の列(同じ番号が続くときは 1 つに数える)が、期待結果の並びと順に一致する | 行動の記録 |
| 止めた step | 記録の番号が、期待結果の番号と一致する | 止めた step と理由 |
| 表示の記録 | 期待結果の「」で囲んだ各行について、山かっこの部分を任意の文字列として、それ以外の文字列が記録に順に含まれる | 表示の記録 |
| 最後の表示 | 期待結果の「」で囲んだ各行について、山かっこの部分を任意の文字列として、それ以外の文字列が記録に順に含まれる | 最後の表示 |
| 書いたファイル | 記録のパスの一覧(そのシナリオの一時フォルダからの相対パス)が、期待結果の一覧と一致する。一時フォルダの外のパスが 1 つでもあれば不合格 | 書いたファイルのパス |
| 見本のファイルの状態 | 実行の前後で、見本のファイルの内容のハッシュがすべて一致する | 見本のファイルのハッシュ |

# 公開スキルの検査の状況

この表は、公開リポジトリに収録しているスキルごとに、4 つの検査を通ったかを持つ表です。正本は作者の作業用リポジトリにあり、publishing-skills-to-public-repo が公開のたびに公開リポジトリの `docs/` へ写します。丸の後ろの日付と hash は、検査した日付と、検査した時点の作業用リポジトリのコミットの短い hash です。

丸の値は、`○ <検査した日付> <検査した時点の作業用リポジトリの短い hash>`、`対象外`、空の 3 つのどれかです。

## 丸を付ける条件

| 列 | ○ にする条件 | 対象外にする条件 |
|---|---|---|
| 規約との照合 | checking-skill-with-template の指摘の一覧で、雛形の照合と規約の照合の違反の数がともに 0 件 | 雛形「スキルの雛形(phase と step)」で作ったスキルでない |
| テストシナリオの実施 | testing-skill-with-template の判定の記録で、実施したすべてのケースが合格。同じスキルの判定の記録が 2 件以上あるときは、実行日時が最新の 1 件で判定する | 雛形「スキルの雛形(phase と step)」で作ったスキルでない |
| ピンクの象の除去 | rewrite-pink-elephants が `SKILL.md` と `references/` の各ファイルを読み、出力した md が元のファイルと一字一句同じ | なし |
| 文章の書き方の規約との照合 | サブエージェントが `SKILL.md` と `references/` の全文を規約 text-writing-rule の全規則と照らし、違反が 0 件。手順の文の主語の省略は違反に含める | なし |

## 丸を消す条件

publishing-skills-to-public-repo は、写す前に、丸の hash より後に `skills/<スキルの名前>/` を変えたコミットがあるかを列ごとに確かめ、あればその丸を空にする。コミットしていない変更がスキルのフォルダにあるときは、publishing を中止する。

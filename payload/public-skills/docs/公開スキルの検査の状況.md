## 値の書き方

- 丸の値は、`○ <検査した日付> <検査した時点の作業用リポジトリの短い hash>`、`対象外`、空の 3 つのどれかです。
- 「最後に変えたコミット」の値は、スキルの行では `git log -1 --format=%h -- skills/<スキルの名前>` の出力、規約の行では `git log -1 --format=%h -- <規約のファイルのパス>` の出力です。検査の丸を書くときと、publishing-skills-to-public-repo が写す前に、書き換えます。

## 丸を付ける条件

### スキルの表

| 列 | ○ にする条件 | 対象外にする条件 |
|---|---|---|
| 規約との照合 | checking-skill-with-template の指摘の一覧で、雛形の照合と規約の照合の違反の数がともに 0 件 | 雛形「スキルの雛形(phase と step)」で作ったスキルでない |
| テストシナリオの実施 | testing-skill-with-template の判定の記録で、実施したすべてのケースが合格。同じスキルの判定の記録が 2 件以上あるときは、実行日時が最新の 1 件で判定する | 雛形「スキルの雛形(phase と step)」で作ったスキルでない |
| ピンクの象の除去 | rewrite-pink-elephants が `SKILL.md` と `references/` の各ファイルを読み、出力した md が元のファイルと一字一句同じ | なし |
| 文章の書き方の規約との照合 | サブエージェントが `SKILL.md` と `references/` の全文を規約 text-writing-rule の全規則と照らし、違反が 0 件。手順の文の主語の省略は違反に含める | なし |

### 規約の表

| 列 | ○ にする条件 | 対象外にする条件 |
|---|---|---|
| 規約の書き方の規約との照合 | サブエージェントが規約の全文を規約 rule-writing-rule の全規則と照らし、違反が 0 件 | 雛形と完成例 |
| ピンクの象の除去 | rewrite-pink-elephants がそのファイルを読み、出力した md が元のファイルと一字一句同じ | なし |
| 文章の書き方の規約との照合 | サブエージェントがそのファイルの全文を規約 text-writing-rule の全規則と照らし、違反が 0 件。規則の箇条書きの、成果物を主語にした文の主語の省略と、雛形の本文の手順の文の主語の省略は、違反に含めない | なし |

## 丸を消す条件

publishing-skills-to-public-repo は、写す前に、丸の hash より後にその行のファイル(スキルの行は `skills/<スキルの名前>/`、規約の行は規約のファイル)を変えたコミットがあるかを列ごとに確かめ、あればその丸を空にし、「最後に変えたコミット」を今の値に書き換える。コミットしていない変更がスキルのフォルダか規約のファイルにあるときは、publishing を中止する。

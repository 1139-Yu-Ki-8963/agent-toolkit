# エージェントの設定ファイルとプログラムの構成要素の対応表

## この文書について

この文書は、このリポジトリの `.claude/` の下にある規約、雛形、完成例、スキル、hook と、スキルの中の phase と step を、プログラムの構成要素に 1 つずつ対応させた表です。スキルの用語の表(規約 skill-writing-rule の章「用語」)は、スキル、phase、step、流れのパターン、受け渡す値、合格の条件の 6 語の対応を持ちます。この文書は、その 6 語の対応をそのまま使い、残りの行を決めます。

## この表の見方

- 表の行は、リポジトリの全体から step までの入れ子の順に並ぶ。型を定義するための型は、当たる型の規約の直後に置く。hook は、完成例の次に置く。
- 列「エージェントの設定ファイル」は、AI の振る舞いを決めるファイルとその中の単位を持つ。
- 列「プログラムの構成要素」は、プログラムを組み立てる要素のうち、その行のファイルか単位と同じ役割を持つものを持つ。

## 対応表

| エージェントの設定ファイル | プログラムの構成要素 |
|---|---|
| リポジトリの全体 | プログラムの一式 |
| 常に読み込まれる規約(text-writing、thinking) | 言語の文法と、コーディング規約(lint の設定) |
| `.claude/rules/` の 1 つのフォルダ(skill-writing、hook-writing など) | 1 つの型のモジュール(パッケージ) |
| 規約(skill-writing-rule、hook-writing-rule など) | 型の定義(スキーマ) |
| 規約の書き方の規約 | 型を定義するための型(メタモデル) |
| 雛形 | 型の既定の値を入れた骨格 |
| 完成例 | 型の値の見本 |
| hook | イベントハンドラ(ツールの呼び出しの前後に自動で走る処理) |
| スキル(SKILL.md) | 1 つのコマンド(実行の入り口になる main 関数) |
| スキルのリファレンス | ライブラリと定数の表 |
| スキルの `.tools/` | 依存パッケージ |
| テスト計画書 | テストコード |
| phase | 関数 |
| phase の合格の条件 | 関数の事後条件 |
| step | プログラムの 1 つの文(命令) |
| step の流れのパターン(直列、分岐、繰り返し、やり直し、ユーザー確認、委任) | 制御構文(順次、if、for、while、入力待ち、別のプロセスの呼び出し) |
| 受け渡す値 | 変数、引数、返り値 |

## この表から分かること

- このリポジトリでは、規約は、成果物の種類ごとに 1 本である。1 本の規約は、1 種類の成果物が満たす形と制約だけを持つ。
- このリポジトリには、クラスに当たる単位がない。クラスは、1 つの型のデータと、その型を扱う動作を 1 つの単位にまとめる。このリポジトリは、型を `.claude/rules/` に、動作を `.claude/skills/` に別々に置く。

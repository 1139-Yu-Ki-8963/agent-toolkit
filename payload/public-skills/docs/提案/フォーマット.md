# 提案のフォーマット

提案の文書は、次の見出しだけを持つ。規則が複数あるときは、「対象」から「置き換えの文」までを規則ごとに繰り返し、「決めること」は先頭に 1 か所だけ置く。

```text
# <提案の題名>

## 決めること

## <規則の番号>. <対象の名前>
### 対象
### 今の文
### 問題
### 置き換えの文
```

| 見出し | 書くこと |
|---|---|
| 決めること | ユーザーが選ぶ点ごとに、選択肢と推奨を 1 つ。選ぶ点がなければ「なし」 |
| 対象 | 規約のファイルの名前と、節と規則の名前 |
| 今の文 | 規則の現在の文を、そのまま引用する |
| 問題 | 今の文のままだと実際に何が起きているかを、1 件につき 1 文で書く。実例があればファイル名を 1 つ添える |
| 置き換えの文 | そのまま規約に貼れる文で書く |

前置き、総論、反映の順、採用後の作業は書かない。

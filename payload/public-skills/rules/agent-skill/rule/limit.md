# 数の上限

## 適用する場面

`SKILL.md`、リファレンス、スクリプト、委任の数や長さを決めるとき。

## 守ること

1. `SKILL.md` の本文(フロントマターを除く)は 200 行以内。
2. phase は 5 個まで、1 つの phase の step は 5 個まで。ちょうど 5 個は収まる側とする。
3. リファレンスは 5 個まで、各 200 行以内。スクリプトの説明書は、この件数と行数のどちらにも数えない。
4. スクリプトは 3 本まで、各 50 行以内(空行とコメント行を除いて数える)、引数は 3 個まで。
5. 委任は 1 つの phase に 1 つ、1 つのスキルに 3 つまで。同時に起動する数は委任の step に書いた数まで。
6. 上限を超えるときは、分けるか、削るか、作らない。

## 理由

`SKILL.md` とリファレンスは発動のたびに文脈へ入るので、長さがそのまま毎回の費用になる。phase と step の数は、読む AI が全体を 1 度に把握できる大きさの目安である。

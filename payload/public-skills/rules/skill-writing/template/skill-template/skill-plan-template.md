# 雛形: 構成の案の形

## 適用する場面

`SKILL.md` を書く前に、ユーザーの承認を得る構成の案を作るとき。埋め方は `template/skill-template-writing/skill-plan-template.md` にある。

## 形

```markdown
# 構成の案: <スキルの名前>

## フロントマターと題名

- name: <スキルの名前>
- 日本語名: <日本語名>
- description: <description>

## 出力先のフォルダ

<出力先のフォルダ>

## 開始時の入力

| 項目 | 種類 | 必須か任意か | 受け取り方 | 読み取れないときの動作 |
|---|---|---|---|---|
| <項目> | <種類> | <必須か任意か> | <受け取り方> | <読み取れないときの動作> |

## 最終出力

| 名前 | 種類 | 特定の仕方 | 0 件でもよいか |
|---|---|---|---|
| <名前> | <種類> | <特定の仕方> | <0 件でもよいか> |
| 完了の報告 | チャットへの表示(完了の報告) | 最終出力の一覧と、それぞれのパス | いいえ |

## 前提ツール

| ツール | 確認に使うコマンド | そのツールのコマンドを実行する step |
|---|---|---|
| <ツール> | <コマンド> | <step> |

## phase と step の一覧

| step | パターン | 種別 | 内容 | 入力 | 出力 | 中止する条件 | 判断の観点 |
|---|---|---|---|---|---|---|---|
| phase 1 前提ツールの確認 | | | | | | | |
| 1-1 | 直列 | 固定の手順 | ツールを探す | なし | 受け渡し値「不足しているツールの一覧」 | なし | なし |
| 1-2 | 分岐 | 固定の手順 | 不足があるかを見る | 受け渡し値「不足しているツールの一覧」 | なし | なし | なし |
| 1-3 | ユーザー確認 | 固定の手順 | インストールの意思を聞く | 受け渡し値「不足しているツールの一覧」 | なし | 「インストールしない」が選ばれた | なし |
| 1-4 | 直列 | 固定の手順 | インストールする | 受け渡し値「不足しているツールの一覧」 | なし | OS が表にない。インストールの終了コードが 0 でない | なし |
| <phase の番号と名前> | | | | | | | |
| <step の番号> | <パターン> | <種別> | <内容> | <入力> | <出力> | <中止する条件> | <判断の観点> |
| <最後の phase の番号> 完了の確認 | | | | | | | |
| <番号>-1 | 直列 | 固定の手順 | 最終出力を照らす | <最終出力の名前の一覧> | 受け渡し値「照合の結果」 | なし | なし |
| <番号>-2 | 直列 | 固定の手順 | 完了を報告する | 受け渡し値「照合の結果」 | 最終出力「完了の報告」 | なし | なし |

## スクリプト

| パス | 役割 | 使用する step | 説明書のパス | テストのパス |
|---|---|---|---|---|
| <scripts/ファイル名> | <役割> | <step> | <references/scripts/ファイル名.md> | <scripts/tests/ファイル名> |

## リファレンス

| パス | 種類 | 内容 | 読み込む step |
|---|---|---|---|
| <references/ファイル名> | <種類> | <内容> | <step> |

## 数の上限との照合

- phase の数: <数>(上限 5)
- 1 つの phase の step の数の最大: <数>(上限 5)
- スクリプトの数: <数>(上限 3)
- リファレンスの数: <数>(上限 5。スクリプトの説明書と委任の指示文は除く)
- 委任の step の数: <数>(上限は、1 つの phase に 1 つ、スキル全体で 3 つ)

## AI が案を作った点

- <AI が決めた内容と、その解釈>
```

# スキルの書き方で使う語の定義

## 適用する場面

skill-writing の規約、雛形、雛形の書き方を読むとき、書くとき。

## 守ること

規則 1: 語は、次の定義の意味で使う
- 判定の仕方: 機械的
- skill-writing の規約、雛形、完成例の中では、次の表の語を、表の意味で使う。同じものを別の語で呼ばない。

| 用語 | 意味 |
|---|---|
| 最終出力 | スキルが終わったときに残る成果物。ファイルか、チャットに表示した成果物 |
| 受け渡し値 | step が出し、後の step の入力になる値。ファイルには残らない |
| 中間成果物 | step の間を流れるもの。受け渡し値と、途中でだけ使うファイル |
| 本作業 | 固定の phase(前提ツールの確認、完了の確認)を除いた、そのスキル固有の phase |
| 前提ツール | スキルの step が実行するコマンドのうち、OS に標準で入っていないもの |
| step の種別 | 固定の手順(毎回同じ結果になる作業)か、AI による推論(判断を含む作業)のどちらか |
| 委任 | 作業をサブエージェント(別の文脈で動く AI)に行わせること |
| ユーザー確認 | 選択肢を出し、ユーザーが選ぶまで止まる step |
| 聞き取り | 自由な回答を求める質問 |
| 中止 | スキルを途中で終えること。中止の表示だけを出す |

## 理由

語の意味が 1 か所にあれば、ほかの規約は語を使うだけでよく、同じ定義を何度も書かずに済む。

# スキルの書き方で使う語の辞書

## 適用する場面

skill-writing の規約、雛形、雛形の書き方を読むとき、書くとき。

## 守ること

規則 1: 語は、この辞書の意味で使う
- 判定の仕方: 機械的(有無、順、名前、数の一致を見る)
- skill-writing の文書の中では、次の表の語を、表の意味で使う。同じものを別の語で呼ばない。

| 用語 | 意味 |
|---|---|
| スキル | ユーザーが呼んで実行させる、決められた手順。`SKILL.md` と、その付属のファイル |
| SKILL.md | スキルの本体のファイル。全体像、前提ツール、使用するスクリプト、使用するリファレンス、phase と step の節を持つ |
| 全体像 | `SKILL.md` の最初の節。目的、開始時の入力、最終出力、流れの 4 項目 |
| 目的 | このスキルが何をするかを書いた 1 文 |
| 開始時の入力 | スキルを始めるときに受け取るもの。ユーザーの発言、既存のファイル、コマンドの結果のどれか |
| 最終出力 | スキルが終わったときに残る成果物。ファイルか、チャットに表示した成果物 |
| 流れ | phase と step の一覧 |
| phase | step をまとめた作業の段階。番号は 1 から |
| step | スキルが行う作業の最小の単位。「step 2-1」のように phase の番号と step の番号で呼ぶ |
| step の種別 | 固定の手順(毎回同じ結果になる作業)か、AI による推論(判断を含む作業)のどちらか |
| 受け渡し値 | step が出し、後の step の入力になる値。ファイルには残らない |
| 前提ツール | スキルの step が実行するコマンドのうち、OS に標準で入っていないもの |
| リファレンス | `SKILL.md` の外に出した資料。`references/` に置く |
| スクリプト | step が実行する同梱のプログラム。`scripts/` に置く |
| 委任 | 作業をサブエージェント(別の文脈で動く AI)に行わせること |
| 流れのパターン | step の並び方。直列、分岐、繰り返し、やり直し、ユーザー確認、中止、委任の 7 つ |
| ユーザー確認 | 選択肢を出し、ユーザーが選ぶまで止まる step |
| 聞き取り | 自由な回答を求める質問 |
| 中止 | スキルを途中で終えること。中止の表示だけを出す |

## 理由

語の意味が 1 か所にあれば、ほかの規約は語を使うだけでよく、同じ定義を何度も書かずに済む。

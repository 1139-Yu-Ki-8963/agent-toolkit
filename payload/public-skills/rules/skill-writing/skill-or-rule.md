# スキルか規約か

## 適用する場面

スキルを新しく作るか、既存のスキルの範囲を変えるとき。

## 守ること

1. スキルは、特定の場面で繰り返し必要になる 1 つの作業の手順であり、ユーザーがその場面で呼んで実行させるものである。
2. 常に守らせたいことと、条件付きであってもユーザーが呼ばずに守られることを期待する方針(「〜のときは必ず〜する」)は、規約(`.claude/rules`)にする。
3. 1 回しか行わない作業は、その場で依頼する。
4. 見分ける問いは「その場面が来たとき、ユーザーはこれを呼ぶか、呼ばずに守られることを期待するか」である。呼ぶならスキル、呼ばずに守られることを期待するなら規約。
5. 1 つのスキルは、1 つの場面と 1 つの目的だけを扱う。

## 理由

スキルは呼ばれたときだけ文脈に入る。呼ばれることを前提にできない方針をスキルにすると、守られるかどうかが運に左右される。場面と目的を 1 つに絞ると、名前と description から発動の判断が一意になる。

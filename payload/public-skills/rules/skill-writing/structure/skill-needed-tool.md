# 前提ツール

## 適用する場面

スキルが OS に標準で入っていないコマンドを使うとき。

## 守ること

規則 1: 前提ツールの表に挙げるコマンド
- 判定の仕方: AI の推論(書いた内容の根拠と理由を読む)
- 前提ツールの表に挙げるのは、step が実行するコマンドのうち、OS に標準で入っていないもの。
- そのスキルを使う場面にすでにあるツールは挙げない。例: コミットの直前に使うスキルの git。

## 理由

前提ツールが表にあれば、スキルは本作業の前にそれを確かめ、本作業を最後まで進められる。前提ツールの確認の phase は skill-phase の規則 2、表の形は雛形にある。

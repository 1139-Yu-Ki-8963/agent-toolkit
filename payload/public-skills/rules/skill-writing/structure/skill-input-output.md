# 入力と出力と表示

## 適用する場面

step の入力と出力、ファイルの読み書き、チャットへの表示を書くとき。

## 守ること

規則 1: step の入力と出力になるもの
- 判定の仕方: 機械的
- step の入力になるのは、次の 3 つのどれか。開始時の入力。前の step が出した受け渡し値。前の step が書いた最終出力。
- step の出力になるのは、次の 2 つのどれか。受け渡し値。最終出力(全体像の表にある成果物のうち、この step が書くもの)。
- 受け渡し値と途中でだけ使うファイルは、全体像の「中間成果物」の表にあり、表の「出す step」は「使う step」より前にある。

規則 2: 対象の件数が実行のたびに変わる step が書くこと
- 判定の仕方: AI の推論
- ファイルを探す、件数を数える、見つかったものを 1 件ずつ処理する、のように対象の件数が実行のたびに変わる step は、対象の範囲を書く。範囲とは、どのフォルダか、どの種類のファイルか、直下だけか全階層か、何を除くか。
- その step は、対象がないとき、0 件のとき、想定より多いときに何をするかも書く。その場合が起こり得ないなら、起こり得ない理由を書く。

規則 3: スキルが終わったときに残るファイル
- 判定の仕方: 機械的
- スキルが終わった時点で、新しく作られたファイルと変更されたファイルは、全体像の最終出力の表にあるものと完全に一致する。

規則 4: 途中でだけ使うファイルの置き場所と消し方
- 判定の仕方: 機械的
- 実行の途中でだけ使うファイル(検証で実行者に書かせる成果物など)は、OS の一時フォルダの中に置く。スキルが終わる前と、中止する前に消す。置き場所と、消す step を、全体像の「中間成果物」の表に書く。

規則 5: スキルがチャットに表示する 8 種類
- 判定の仕方: 機械的
- スキルがチャットに表示するのは、次の表の 8 種類だけ。どの step で何を表示するかは、その step に書く。
- 中止するときに表示するのは、中止の表示だけ。
- ユーザーから質問を受けたときの回答は、この 8 種類に含めず、いつでも行う。

| 種類 | いつ | 必ず含める内容 |
|---|---|---|
| 開始の表示 | 最初の step | スキルの名前、何をするか、最後に何を出力するか |
| phase の表示 | 各 phase の最初 | phase の番号と名前 |
| 前提ツールの表示 | ツールを探すとき、不足が分かったとき | ツールの名前、インストールが必要であること |
| ユーザー確認 | ユーザー確認の step | 質問の文と選択肢 |
| 聞き取り | 自由な回答を求めるとき | 質問の文と、答えの候補(推奨を先頭に置き、理由を添える)。パスや ID のように固有の値しか答えようがない項目は、質問の文だけ |
| 中止の表示 | 中止するとき | 理由、止まった step、次にすること |
| 成果物の表示 | 最終出力をチャットに出すとき | 最終出力の名前と中身 |
| 完了の報告 | 最後の step | 最終出力の一覧とパス(パスがなければ「チャットに表示」、0 件なら「0 件」) |

## 理由

読むもの、書くもの、表示するものが `SKILL.md` に列挙されていれば、実行の結果を列挙と突き合わせるだけで確かめられる。

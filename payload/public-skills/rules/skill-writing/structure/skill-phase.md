# phase の書き方

## 適用する場面

スキルの流れを phase に分けるとき。

## 守ること

規則 1: phase の番号
- 判定の仕方: 機械的
- phase の番号は、1 から始まる整数。
- 合格の例: phase 1。違反の例: phase 0、phase 1.5。

規則 2: 先頭と最後に置く固定の phase
- 判定の仕方: 機械的
- 前提ツールが 1 つ以上あるスキルは、phase 1 を「前提ツールの確認」とし、雛形の固定の文のとおりに置く。
- すべてのスキルは、最後の phase を「完了の確認」とし、雛形の固定の文のとおりに置く。

規則 3: 本作業の phase の分け方
- 判定の仕方: AI の推論
- 本作業は、終わりの状態が変わるところで phase を分ける。1 つの phase は、1 つ以上の step を持つ。

規則 4: 雛形の省ける部分を省いたあとの番号
- 判定の仕方: 機械的
- 雛形の省ける部分を省いたあと、phase は 1 から、各 phase の step は 1 から空きなく振り直し、流れの表、行き先、中止の文面の中の番号も合わせる。完了の確認は常に最後の phase。

## 理由

phase の形と、先頭と最後の固定の phase が決まっていれば、どのスキルも同じ骨格になり、読む AI はどこから始まりどこで終わるかで迷わない。数の上限は skill-limits の規則 2、phase の表示は skill-input-output の規則 5 にある。

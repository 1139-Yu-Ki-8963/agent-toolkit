# 各規約の要件

この文書は、skill-factory の `.claude/rules/` にある規約ごとに、責務、使える場所、読み込まれる条件、範囲外を書いた文書です。各規約のファイルが守ることを持つのに対して、この文書は、規約が受け持つ範囲と、規約の間の分担を持ちます。新しい決まりを足す人は、章 1 の表で受け持つ規約を探し、どの規約の責務にも当たらないときは、新しい規約の要件をこの文書に足してから規約を作ります。

## 目次

1. 規約の一覧
2. 規約ごとの要件

## 1. 規約の一覧

「使える場所」は、規約を単独で配ってほかのフォルダで使えるかを、「どのフォルダでも」か「skill-factory だけ」で書きます。「読み込まれる条件」は、規約の先頭の `paths` から決まる条件です。

| 規約 | 責務 | 使える場所 | 読み込まれる条件 |
|---|---|---|---|
| text-writing-rule | 文書とチャットに書く日本語の文と名前の書き方を決める | どのフォルダでも | 常に |
| thinking-rule | 判定の決め方、直す範囲、作業を終える条件のような、作業の進め方を決める | どのフォルダでも | 常に |
| skill-or-rule | 依頼をスキルにするか規約にするかの見分け方を決める | どのフォルダでも | 常に |
| skill-making-flow-rule | skill-factory でスキルを作る 8 段階の順と、段階が使うスキルと、段階の間の進み方を決める | skill-factory だけ | 常に |
| skill-factory-skill-naming-rule | skill-factory の `.claude/skills/` に置くスキルの名前の最初の語を、スキルの役割ごとに決める | skill-factory だけ | `.claude/skills/*/SKILL.md` を読むか書くとき |
| skill-writing-rule | どの雛形で作ったスキルにも当てはまる、スキルの書き方を決める | どのフォルダでも | スキルの `SKILL.md`、`references/`、`scripts/` を読むか書くとき |
| skill-template と skill-completed-example | スキルの雛形「スキルの雛形(phase と step)」の形と、その形で書いた完成例を持つ | どのフォルダでも | スキルの `SKILL.md` か `references/` を読むか書くとき |
| skill-test-design-rule | スキルのテストの分け方と、テストケース 1 件に書く項目を決める | どのフォルダでも | `tests/` の下か、テストのスキルのフォルダの下を読むか書くとき |

## 2. 規約ごとの要件

節は、章 1 の表の順に並ぶ。新しい決まりを足す人は、範囲外の表で受け持つ規約が「なし」の行のことを、その場で依頼します。

### text-writing-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| 回答とファイルが持つ中身を決める | behavior-rule(`~/.claude/CLAUDE.md` が読み込む規約) |
| 規約の章と規則の形を決める | rule-writing-rule |

### thinking-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| 判定の人数のような数を決める | なし(その作業を行うスキルが持つ) |
| 文の書き方を決める | text-writing-rule |

### skill-or-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| スキルの書き方を決める | skill-writing-rule |
| 規約の書き方を決める | rule-writing-rule |

### skill-making-flow-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| 段階のスキルの手順を決める | なし(各スキルの `SKILL.md` が持つ) |
| skill-factory の `.claude/skills/` に置くスキルの名前の最初の語を決める | skill-factory-skill-naming-rule |

### skill-factory-skill-naming-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| ユーザーが skill-factory で作るスキル(`output/` の下)の名前を決める | なし(ユーザーが決める) |
| スキルの書き方を決める | skill-writing-rule |

### skill-writing-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| スキルの名前の最初の語を決める | skill-factory-skill-naming-rule(skill-factory の `.claude/skills/` に置くスキルだけ) |
| 雛形の構造に依存する決まりを持つ | skill-template |
| テストの書き方を決める | skill-test-design-rule |

### skill-template と skill-completed-example

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| どの雛形にも当てはまる決まりを持つ | skill-writing-rule |

### skill-test-design-rule

**範囲外**

| しないこと | 受け持つ規約 |
|---|---|
| スキルの書き方を決める | skill-writing-rule |
| テストを流す手順を決める | なし(testing-skill-with-template の `SKILL.md` が持つ) |

# skill-factory

skill-factory は、Claude Code のスキルを、段階を踏んで作成できるツールです。段階ごとに、AI が作った文書を右に表示し、ユーザーは左の会話の欄で承認するか、直す点を伝えます。

## 依頼の例

左の入力欄に、次の表の例のように依頼を書いて送ってください。スキルの名前は、`output/` の下のフォルダの名前です。

| したいこと | 依頼の例 | 始める段階 |
|---|---|---|
| 新しいスキルを作る | 「<作業>をするスキルを作って」 | 1 |
| 途中の文書から続ける | 「`output/<スキルの名前>/要件定義書.md` ができたから続きをやって」(分割設計書、構成の案も同じ形) | 2(要件定義書)、3(分割設計書)、4(構成の案) |
| 既存のスキルを照合する | 「<スキルの名前> を照合して」 | 5(指摘の一覧を見せ、直すかを聞いて止まる) |
| 既存のスキルを直す | 「<スキルの名前> の <直す内容> を直して」 | 5(先に修正、次に照合) |
| 既存のスキルのテストを作る | 「`output/<スキルの名前>/` のテストを作って」 | 5(指摘なしなら 6 へ) |
| テストを実施する範囲を決める | 「`<テスト計画書のパス>` の実施する範囲は <正常系だけ か 1 回の実行で終わるすべてのケース か 全件>」 | 7 |
| 既存のスキルのテストを流す | 「`<テスト計画書のパス>` のテストを流して」 | 8 |
| 不合格のテストからスキルを直す | 判定の記録のパス | 5 |

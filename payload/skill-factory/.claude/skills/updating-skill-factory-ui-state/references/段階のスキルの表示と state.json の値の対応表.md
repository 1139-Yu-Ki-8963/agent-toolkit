# 段階のスキルの表示と state.json の値の対応表

## 段階のスキルの表示と state.json の値の対応表

この章は、対応表である。実行者は、step 2-1 で、開始時の入力の「段階のスキルの最後の表示の文」から state.json の値を作るときに、この章を読む。この章の「表示の行の形」は、skill-factory の段階のスキル 10 本(規約 skill-making-flow の規則「スキルだけで動く 8 段階の流れ」の表のスキル)の `SKILL.md` の「ユーザーに見せる文面」と、`references/全スキル共通の決まり.md` の「チャットへの表示の書式」から写した行の形である。

実行者は、表示の文の「- 目的:」の行の文と、「**<題名> が完了しました**」の行の題名を、次の表で段階の番号に対応させる。

### 表示の行の形と state.json の値の作り方

実行者は、表示の文の行を上から順に見て、次の表の「表示の行の形」と同じ形の行ごとに、「state.json のキー」の値を「値の作り方」のとおりに作る。表のどの形にも当たらない行は、読み飛ばす。表の山かっこは、表示の中の実行のたびに変わる値である。「いまの段階の要素」は、`artifacts` の `stage` が `stage` の値と同じ要素である。表示の文が `stage` の値を作らないときの `stage` は、依頼の文面のいまの段階の番号である。表示の文が `questions` の行を 1 行も持たないときの `questions` は、依頼の文面の質問の一覧(ないときは `null`)である。表示の文が `screen`、`summary`、`research`、`factCheck`、`approvalSheet`、`draftReview` の行を持たないときの、そのキーの値は、依頼の文面の値(ないときは `null`)である。表で「聞き取りの画面のキー」と呼ぶものは、この 6 つのキーである。表で「段階 2 から 8 で足すキー」と呼ぶものは、リファレンス `references/画面の状態のファイルの形.md` の章「段階 2 から 8 で足すキー」の表のキーである。表示の文が段階 2 から 8 で足すキーの行を持たないときの、そのキーの値は、依頼の文面の値(ないときは `null`)である。段階 2 から 8 の `screen` の値は、同じ章の表の画面の名前(「始める段階の知らせ」「成果物の承認」など)である。表で「聞き返し」と呼ぶ `askBack` が `true` の `decision` は、`screen` が段階 1 の聞き取りの画面の 9 つの値のどれかのときだけ使う。

# 画面の状態のファイルの形

## キーの名前と型の対応表

この章は、対応表である。state.json は、次の表の 9 つのキーだけを、表の順に持つ。表の「パス」は、作業のフォルダからの相対パスで、区切りを `/` とする。作業のフォルダは、規約 skill-making-flow の規則「作業のフォルダとスキルのフォルダ」の `output/<開始日時>/` で、出力先のフォルダ `<作業のフォルダ>/ui/` の親のフォルダである。

| 値 | キー | 型 | 値の決まり |
|---|---|---|---|
| 作業の名前 | `workName` | 文字列 | 1 文字以上 |
| いまのスキルの名前と作る順 | `currentSkill` | オブジェクト `{"name": 文字列, "order": 整数, "total": 整数}` か `null` | `order` は 1 以上 `total` 以下。分割設計書の承認の前は `null` |
| いまの段階の番号 | `stage` | 整数 | 1 から 8 |
| 成果物の状態 | `artifacts` | オブジェクト `{"stage": 整数, "name": 文字列, "status": 文字列}` の配列 | 8 件。`stage` は 1 から 8 の順。`status` は「未着手」「下書き」「承認待ち」「済み」のどれか |
| 図のタブの一覧 | `figures` | オブジェクト `{"tab": 文字列, "path": 文字列}` の配列 | 0 件でもよい。`path` は `ui/figures/` で始まり、`.svg` で終わる。drawing-skill-factory-figure が書く図のファイルのパスは、`ui/figures/<段階の番号>-<作る順の番号>-<図の種類>.svg` である |
| 文書のパス | `documentPath` | 文字列 | `.md` で終わるパス |
| 決めてもらうこと | `decision` | オブジェクト `{"question": 文字列, "choices": 文字列の配列, "replies": 文字列の配列}` か `null` | `choices` は 0 件でもよい。0 件のときは、自由に答える問いとする。`replies` は、自由に答える問いの答えの候補で、0 件から 4 件とし、`choices` が 1 件以上のときは空の配列とする。決めてもらうことがないときは `null` |
| 質問の一覧 | `questions` | オブジェクト `{"title": 文字列, "added": 整数, "removed": 整数, "items": 配列}` か `null`。`items` の要素は、オブジェクト `{"number": 整数, "text": 文字列, "choices": 文字列の配列, "answer": 文字列か null}` | 段階のスキルが 2 問以上をまとめて聞くときの一覧とし、まとめて聞く質問がないときは `null`。`title` は一覧の見出し。`added` と `removed` は、前の答えで増えた問数と減った問数で、1 回目は 0。`items` は、段階のスキルがチャットに出した質問の番号と質問の文を、番号の小さい順に持つ。要素の `choices` は答えの候補で、0 件から 4 件。`answer` は答えた問いの答えで、まだ答えていない問いは `null` |
| ダウンロードできるファイルの一覧 | `downloads` | 文字列の配列 | 0 件でもよい。1 件ずつがパス |

## state.json の雛形

この章は、雛形である。実行者は、山かっこを、キーの名前と型の対応表に合った値で埋め、UTF-8 で、字下げを空白 2 つにした JSON を書く。実行者は、`artifacts` の要素だけを 1 件 1 行にし、ほかの配列の要素を、雛形のとおり 1 行に「, 」で区切って並べる。

````json
{
  "workName": "<作業の名前>",
  "currentSkill": {"name": "<いまのスキルの名前>", "order": <作る順>, "total": <スキルの本数>},
  "stage": <いまの段階の番号>,
  "artifacts": [
    {"stage": 1, "name": "要件定義書", "status": "<状態>"},
    {"stage": 2, "name": "分割設計書", "status": "<状態>"},
    {"stage": 3, "name": "構成の案", "status": "<状態>"},
    {"stage": 4, "name": "SKILL.md", "status": "<状態>"},
    {"stage": 5, "name": "照合の指摘の一覧", "status": "<状態>"},
    {"stage": 6, "name": "テスト計画書", "status": "<状態>"},
    {"stage": 7, "name": "シナリオテストの表", "status": "<状態>"},
    {"stage": 8, "name": "判定の記録", "status": "<状態>"}
  ],
  "figures": [{"tab": "<タブの名前>", "path": "ui/figures/<段階の番号>-<作る順の番号>-<図の種類>.svg"}],
  "documentPath": "<文書のパス>",
  "decision": {"question": "<問いの文>", "choices": ["<選択肢の文>"], "replies": ["<答えの候補>"]},
  "questions": {"title": "<一覧の見出し>", "added": <増えた問数>, "removed": <減った問数>, "items": [{"number": <質問の番号>, "text": "<質問の文>", "choices": ["<答えの候補>"], "answer": "<答え>"}]},
  "downloads": ["<ファイルのパス>"]
}
````

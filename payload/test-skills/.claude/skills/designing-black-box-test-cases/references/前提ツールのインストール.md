# 前提ツールのインストール

このファイルは、step 1-5 で、不足している前提ツールをインストールするときに使う対応表を持つ。

## インストールの方法

この章は、対応表である。step 1-5 で、不足している前提ツールをインストールするときに読む。

### OS の見分け方

セッションの環境の情報の Platform の値を、次の表で OS に対応させる。

| Platform の値 | OS |
|---|---|
| `darwin` | macOS |
| `linux` | Linux(WSL を含む) |
| `win32` | Windows |

### OS ごとのインストールのコマンド

パッケージマネージャだけを使い、一般ユーザーの権限で実行できるコマンドだけを書く。

| OS | ツール | インストールのコマンド | 先に書くファイル |
|---|---|---|---|
| macOS | node | `brew --version && brew install node` | なし |
| Linux | node | `brew --version && brew install node` | なし |
| Windows | node | `winget install OpenJS.NodeJS.LTS` | なし |

テストケースの例

このファイルは、工程ごとのテストケースの md の見本を持つ。

3 つの見本は、次の内容のテストベース `docs/会員登録の仕様.md`(AI が作った例)から作った md である。

このテストベースは 17 行で、1 行目は見出し「# 会員登録の仕様」、節 1 は 3〜6 行、節 2 は 8〜12 行、節 3 は 14〜17 行にある。

- 節 1 画面定義書(3〜6 行): 会員登録の入力画面の項目「年齢」は、必須の整数で、18 以上 120 以下とする。範囲の外の値には、「年齢は 18〜120 で入力してください」を出す。項目「メールアドレス」は、必須で、254 文字以下とする。

- 節 2 登録 API のインターフェースの仕様(8〜12 行): 入力画面は、登録のボタンを押すと、会員情報を登録 API に渡す。登録 API は、入力チェックが不合格なら入力エラーを返し、メールアドレスの重複を調べない。入力チェックが合格でメールアドレスが登録済みなら重複エラーを返し、入力画面は「登録済みです」を出す。入力チェックが合格でメールアドレスが登録済みでないなら会員番号を返し、入力画面は登録完了の画面に移る。

- 節 3 要件定義書(14〜17 行): 会員が入力画面で登録すると、会員の状態は仮登録になり、確認メールが届く。確認メールのリンクを 24 時間以内に押すと、会員の状態は本登録になる。24 時間が過ぎると、会員の状態は期限切れになり、期限切れのリンクを押すと「期限が切れました」を出す。

見本のセルの「仮-<番号>」は、テストベースにない値を仮に決めた点の番号を指す。

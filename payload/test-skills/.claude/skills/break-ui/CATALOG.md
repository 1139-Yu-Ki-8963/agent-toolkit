# 最悪の場合のカタログ

このカタログは、UI を壊す現実的な値を、部品が描く値の種類ごとにまとめたものである。AI は、段階 1 の表の項目に当たる行を使う。どの値も、実在の利用者が作り出しうる値であり、注記は、その値がよく壊すものを書く。

AI は、メールアドレスと URL に、`example.com`、`example.org`、`.test` のドメインを使い、fixture が実在の受信箱やサイトを指さないようにする。

## メールアドレス、URL、識別子

これらは、折り返せない文字列である。空白を持たないので、ブラウザは折り返す場所を持たない。

| 値 | 壊すもの |
| --- | --- |
| `bartholomew.fitzgerald@northwind-industries-holdings.example.com` | 定番。`overflow-wrap: anywhere` がないと、行の兄弟の要素をすべて押し出す |
| `a@b.co` | 現実的な最短。長いメールアドレスを前提にしたレイアウトが空っぽに見える |
| `first.last+billing-notifications@example.com` | プラスのアドレス。`+` を拒む検証、意味のある部分を切り詰める表示 |
| `ops@sub.department.region.example.co.uk` | 多くのサブドメインと 2 つの部分のトップレベルドメイン。「ドメイン」を取り出す処理 |
| `https://example.com/workspaces/acme/projects/q3-launch/docs/9f8e7d6c5b4a?tab=comments&filter=unresolved` | 長い URL。はみ出し、末尾の切り詰めが違う部分を隠す |

## データから来るラベル、題、文

| 値 | 壊すもの |
| --- | --- |
| `Senior Product Design Engineer, Platform Infrastructure` | 長い役職。二次的な場所で 3 行に折り返す |
| `Invitation expired 12 days ago` | 長い状態のバッジ。バッジが折り返すか、名前の列を押しつぶす |
| `Benachrichtigungseinstellungen` | ドイツ語の複合語(30 字、空白なし)。ラベルがはみ出し、折り返せない |
| `Paramètres de confidentialité et de sécurité` | 「Privacy & security」のフランス語訳で伸びた文。UI の文は、翻訳で約 30% 長くなる |
| 1 つの項目に 12 個のタグ: `design`、`frontend`、`q3`、`urgent`、`needs-review`、… | タグの行が折り返して壁になる。`+8` のあふれの表示が要る |
| `customer-feedback-from-enterprise-onboarding` という名前のタグ | 1 つのタグが入れ物より広い |
| `Untitled` / 空の文字列 / `   ` | 題が欠ける。見出しがつぶれ、行の高さが 0 になる |
| `<script>alert(1)</script>` / `&amp;` / `**bold**` | エスケープ。文字どおりの文字として描かなければならない |
| `Line one` + 改行 + `Line two` | 1 行の項目の中の改行。行の高さが倍になるか、黙って消される |
| 貼り付けられた 2,000 字の説明 | 行数の区切り、「もっと見る」、テキストエリアの伸び |

## 数と金額

| 値 | 壊すもの |
| --- | --- |
| `0` | 0 の状態: 「0 members」、空の進み具合のバー、割合での 0 の割り算 |
| `1` | 複数形: 「1 members」「1 days ago」 |
| `1284` | 桁区切りが要る: `1,284` |
| `1000000` | 数のバッジの幅。精度が要らない所では、短い形 `1M` を考える |
| 通貨としての `12345678.9` | `$12,345,678.90`。合計の列からはみ出す |
| `-42.5` | 負の符号、赤い色にする処理、会計の形式の括弧 |
| `0.1 + 0.2` | `0.30000000000000004` がそのまま描かれる |
| `142%` / `-3%` | 範囲を越えた、進み具合のバーとメーター |
| `null` / `undefined` / `NaN` | 文字どおりに描かれる |
| `de-DE` の `1.284` と `en-US` の `1,284` | locale の書式。固定で書いた区切りは、世界の半分で間違う |
| その場で変わる値(`99` → `100`) | `tabular-nums` がないと、幅が跳び、揺れる |

## 集まり

| 値 | 壊すもの |
| --- | --- |
| 0 件 | 空の状態と、空の状態がそもそもあるか |
| 1 件 | カード 1 枚で壊れて見えるグリッド。「1 of 1」 |
| ちょうど 1 ページの件数と、1 ページの件数 + 1 | 「Showing 40 of 40」の 1 つずれ、空の 2 ページ目を出すページ送り |
| ページ送りのない 1,000 件以上 | スクロールの性能、描く時間、メモリ。「Showing 40 of 1,284」の文も |
| ほかの 10 倍の大きさの項目が 1 つ | 一番高い項目に引き伸ばされる、石積みのレイアウトとグリッドの行 |
| 同じ名前の項目 | 名前だけが見分ける項目である一覧 |

## 時刻

| 値 | 壊すもの |
| --- | --- |
| 今 | 「just now」でなく「0 seconds ago」 |
| 12 日前、11 か月前、3 年前 | 相対の時刻のしきい値。1 週間ほど過ぎたら、絶対の日付に切り替える |
| 未来の日付 | 「in 3 days」と「-3 days ago」 |
| `1970-01-01` | 0 の時刻が、本物の日付として出る |
| `2025-12-31T23:30:00-08:00` | UTC と利用者のタイムゾーンで、違う日として出る |
| とても長い期間(`1,284 hours`) | 日にまとめ上げない期間の書式 |

AI は、手で組み立てた文字列でなく、`Intl.RelativeTimeFormat` と `Intl.DateTimeFormat` を使う。

## 画像とメディア

| 値 | 壊すもの |
| --- | --- |
| 404 を返すアバターの URL | 頭文字への切り替えでなく、壊れた画像のアイコン |
| アバターがまったくない | 切り替えの表示そのもの: 頭文字、色、本物のアバターとの大きさのそろい |
| アバターかカバーとしての 4000×200 のパノラマ | `object-fit: cover` がないと、ゆがむ |
| 200×4000 の縦長の画像 | 同じことの、もう一方の軸。カードの高さを吹き飛ばすこともある |
| 透明な PNG のロゴ、ダークモードの上の暗いロゴ | 背景の上で見えない |
| 読み込みの遅い画像 | 決まった大きさか `aspect-ratio` がないと、レイアウトがずれる |

## 状態

| 値 | 壊すもの |
| --- | --- |
| 読み込み中 | 最後のレイアウトに合わないスケルトン、中身をずらすスピナー |
| API からのエラー | エラーの状態がないか、生のエラーのメッセージ(`TypeError: Cannot read properties of undefined`) |
| 一部だけのデータ | 同じ一覧の中で、省略できる項目のいくつかが埋まり、ほかが空。行がずれる |
| すべての状態を一度に | 1 つの一覧の中の、すべての enum の値(`active`、`invited`、`expired`、`suspended`)。バッジの幅が変わる |
| 権限がない | 押せない操作。行は同じレイアウトのままか |
| 一覧の中の今の利用者 | 「You」のラベル、自分には当てはまらないはずの操作 |

## 環境

環境は、データではないが、同じやり方で確かめる。AI は、最悪の場合に切り替えてから、これらを変える。

| 条件 | 壊すもの |
| --- | --- |
| 320px の入れ物 | 上のはみ出しのすべてが、一度に |
| 狭いサイドバーに置く | 全幅で設計され、280px の列で使い回された部品 |
| 2560px の幅 | 読むには長すぎる行、片側に取り残された中身 |
| ブラウザの拡大 200% / 大きな文字の設定 | 伸びる文字を切る、決まった高さ |
| ダークモード | 固定で書いた色、見えない枠線とロゴ |
| `dir="rtl"` | アイコン、山形の矢印、余白、末尾の操作の順 |
| タッチの機器 | ホバーだけで出る操作(ホバーで出る •••)に届かない |

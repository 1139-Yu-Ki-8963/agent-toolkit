# 保守できない内容を載せない決まり

## 概要

ポータルと設計書に、対象コードへの参照・レビュー記録・社内資料の出典・対象コードの中身を残さない取り決め。

これらは対象コードの変更のたびに追従が必要になり、保守できない内容として残り続ける。検証の証跡はポータル保守設計が定める検証記録へ分離する。

## 規則

| 規則 | 内容 | 検査 |
|---|---|---|
| 保守できない参照を載せない | ポータルと設計書には、対象コードへの参照、レビュー記録、社内資料の出典を載せない。検証の証跡はポータル保守設計が定める検証記録へ分離する | 静的解析: check-portal-unmaintainable-content.sh --strict が廃止した「根拠」「根拠パス」の列見出しを検出する |
| 対象コードの中身を写さない | ポータルと設計書には、長さや記載形式を問わず対象コードの中身を写さない。日本語の分岐と繰り返しだけで書く疑似コードは対象外とする | 静的解析: check-portal-unmaintainable-content.sh --strict がコード柵、HTML の `pre code`、演算子を含むインラインまたは表セル内の断片を検出する。実装識別子だけの断片はレビューでも確認する |

## 違反時の手順

書き込みが止められた場合、対象コードへの参照・レビュー記録・社内資料の出典を取り除く。対象コードの中身を写した箇所は、日本語の分岐と繰り返しだけで書く疑似コードへ書き直す。

# 作業指示書の書き方の決まり

## 概要

`ai-work/todo/` へ置く作業指示書に、対象プロジェクトの固有名や実装識別子を直書きせず、配布物が定める語彙で書く取り決め。

対象プロジェクト名は `.claude/rules/always/project-context/rule.md` の設定行から読む。この名前を指示書の地の文へ直接書くと、対象プロジェクトが変わるたびに指示書を書き直す必要が生じる。

## 規則

| 規則 | 内容 | 検査 |
|---|---|---|
| 対象プロジェクトの固有名を指示書へ直書きしない | 対象プロジェクトの名前を含む固有名・識別子・パスを、指示書の地の文へ直接書かない | 静的解析: check-instruction-writing.sh が対象プロジェクト名を含む語を走査する |
| 実装識別子を指示書の地の文へ直書きしない | `<名前空間>::<モジュール>` 形の実装識別子を、指示書の地の文へ直接書かない | 静的解析: check-instruction-writing.sh が実装識別子の形を走査する |
| 配布物が定める語彙と引用表記を使う | グローバル辞書が禁止する表記を使わず、配布物の語彙一覧が定めるカタカナ音写は避け、テンプレートの章名を引用符なしで地の文に書かない | 静的解析: check-instruction-writing.sh がグローバル辞書・語彙一覧と本文を突き合わせ、禁止表記とカタカナ音写・未引用の章名を走査する |

## 違反時の手順

書き込みが止められた場合、対象プロジェクトの固有名・実装識別子を、配布物が定める一般的な語彙へ書き直す。テンプレートの章名を地の文で使う場合は、引用符で囲んで区別する。

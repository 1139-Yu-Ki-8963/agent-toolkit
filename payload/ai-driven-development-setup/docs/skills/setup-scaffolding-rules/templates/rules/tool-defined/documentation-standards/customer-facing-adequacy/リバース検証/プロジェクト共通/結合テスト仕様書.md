本書は、複数の画面・機能・API・テーブル・バッチ・帳票・外部連携をまたぐ連携だけを扱う。単位内の外部契約と関数単位の検証は、各設計単位のテスト設計書を参照する。

| 節 | 内容 | 読み手へのお願い |
|---|---|---|
| 対象範囲 | 試験する設計単位間の連携 | 起点と終点、共通機能、由来する設計書を確認する。 |
| テストケース一覧 | 連携ごとの操作手順と期待結果 | 前提条件から期待結果までを順に確認する。 |
| データと状態 | 試験前後のデータと後片付け | 初期状態、入力、実行後の状態が再現可能か確認する。 |
| 連携障害と回復 | 障害時の通知と回復後の状態 | 障害の発生条件と回復手順を確認する。 |
| 実行環境 | 試験環境と外部連携の代替方法 | 実行前に環境と実行順序を確認する。 |
| 関連資料 | 参照資料と未確定事項 | 参照先と確認が必要な事項を確認する。 |

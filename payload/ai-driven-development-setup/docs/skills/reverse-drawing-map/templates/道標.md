## 4. 単位の見つけ方

検出条件の形の制約: 正規表現は行単位の拡張正規表現（ERE）である。先読み・後読み・複数行の一致は使えない。`一致` の複数の要素は「すべて満たすファイル」の絞り込みである。複数の単位が 1 行にある場合は `分割: 一致` と `単位: true` の要素で表す。`識別子` の `元` は `ファイルパス` か `一致の捕捉` のいずれかである。`一致の捕捉` は正規表現の 1 番目の捕捉を指す。`名前` の `元` は `内容`・`ファイル名`・`識別子` のいずれかである。表の削除を辿るときは `除外の一致` を使い、捕捉した名前と同じ識別子の単位を結果から除く。例は走査で実際に拾われるファイルのパスを書く。

除外の一致の例: `{"対象": "内容", "正規表現": "DROP TABLE[[:space:]]+(IF EXISTS[[:space:]]+)?([a-z_]+)", "捕捉": 2}`

# 対象と出力の一覧

この表が対象と出力の正である。置き場の定義（output-layout.json）と様式のファイル名から起こしたもので、変えるときは両方を直す。

## 対象

種別ごとに、単位として1つと数える対象・一覧のフォルダ名・設計書のフォルダを示す。定義の詳細は `reverse-writing-survey-definition/SKILL.md` の種別の定義に従う。

| 種別 | 単位の定義（1つと数えるもの） | 一覧のフォルダ名 | 設計書のフォルダ |
|---|---|---|---|
| 画面 | 経路（ルーティング）に対応するページ。再利用される部品・専用ファイルを持たない経路も含む | screens | docs/design/screens/ |
| 接続窓口 | 経路とHTTPメソッドの組 | apis | docs/design/apis/ |
| 表 | 現在存在する表（削除された表は除く） | tables | docs/design/tables/ |
| バッチ | 業務のデータを処理する定期処理・取り込み処理 | batches | docs/design/batches/ |
| 帳票 | 各手順の様式に従う | reports | docs/design/reports/ |
| 外部連携 | 他システムとの通信の実装（呼び出し1か所） | externals | docs/design/externals/ |
| 機能 | 業務の単位。調査と検出条件の定義書の機能のまとめ方に従う | features | docs/design/features/ |

## 種別ごとの出力

各列は「ファイル名 → 置き場」の形で書く。単位のフォルダは `<種別のフォルダ>/<単位>/` である。

| 種別 | 一覧 | 読み取り結果 | 基本設計 | 単体テスト設計 | 詳細設計 |
|---|---|---|---|---|---|
| 画面 | 画面.md・画面.json → docs/design/lists/ | 画面.json → code-readings/screen/ | 画面基本設計書.md → docs/design/screens/<単位>/画面/基本設計/ | 画面単体テスト設計書.md → docs/design/screens/<単位>/画面/テスト設計/ | 画面詳細設計書.md → docs/design/screens/<単位>/画面/詳細設計/ |
| 接続窓口 | 接続窓口.md・接続窓口.json → docs/design/lists/ | 接続窓口.json → code-readings/api/ | API基本設計書.md → docs/design/apis/<単位>/ | API単体テスト設計書.md → docs/design/apis/<単位>/ | API詳細設計書.md → docs/design/apis/<単位>/ |
| 表 | 表.md・表.json → docs/design/lists/ | 表.json → code-readings/table/ | 論理データモデル.md → docs/design/tables/<単位>/ | テーブル単体テスト設計書.md → docs/design/tables/<単位>/ | テーブル定義書.md → docs/design/tables/<単位>/ |
| バッチ | バッチ.md・バッチ.json → docs/design/lists/ | バッチ.json → code-readings/batch/ | バッチ基本設計書.md → docs/design/batches/<単位>/ | バッチ単体テスト設計書.md → docs/design/batches/<単位>/ | バッチ詳細設計書.md → docs/design/batches/<単位>/ |
| 帳票 | 帳票.md・帳票.json → docs/design/lists/ | 帳票.json → code-readings/report/ | 帳票基本設計書.md → docs/design/reports/<単位>/ | 帳票単体テスト設計書.md → docs/design/reports/<単位>/ | 帳票詳細設計書.md → docs/design/reports/<単位>/ |
| 外部連携 | 外部連携.md・外部連携.json → docs/design/lists/ | 外部連携.json → code-readings/external/ | `外部連携基本設計書.md` → docs/design/externals/<単位>/ | 外部連携単体テスト設計書.md → docs/design/externals/<単位>/ | `外部連携詳細設計書.md` → docs/design/externals/<単位>/ |
| 機能 | 機能.md・機能.json → docs/design/lists/ | 機能.json → code-readings/feature/ | 機能設計書.md → docs/design/features/<単位>/ | 機能単体テスト設計書.md → docs/design/features/<単位>/ | 無し（機能の詳細設計は作らない） |

表（テーブル）は論理データモデルとテーブル定義書を持つため、他種別の基本設計書・詳細設計書とは名前の形が異なる。この2つが表の正規の出力である。

## 置き場の2つの使い方

出力の先頭は展開先の使い方で変わる。

| 使い方 | docs/design配下の先頭 | ai-work/records配下の先頭 |
|---|---|---|
| 対象プロジェクトのフォルダへ展開する場合 | 対象プロジェクトのフォルダのルート直下のdocs/design/ | 対象プロジェクトのフォルダのルート直下のai-work/records/ |
| 作業場所だけの場合（既定） | <実行フォルダ>/design/docs/design/ | <実行フォルダ>/design/ai-work/records/ |
